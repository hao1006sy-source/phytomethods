# 模拟群体基因型：PCA 与多样性

此目录包含人为构造的教学数据：8 个二倍体样本、6 个双等位位点，分为 A 和 B 两组。数据不来自真实植物，不能用于生物学结论。每个单元格为备选等位基因拷贝数 0、1 或 2；示例要求所有基因型完整。

## 环境与执行

2026-11-21 本机实际运行：Python 3.13.9、NumPy 2.5.2、Matplotlib 3.11.1。创建隔离环境并安装兼容版本后，在项目根目录执行：

```bash
python examples/population/analyze.py --output work/population-example
```

输出目录必须是不存在的新目录，脚本会拒绝覆盖。`--input` 可指定相同格式的 TSV。脚本按位点均值中心化，**不按等位基因频率缩放**，通过奇异值分解计算 PCA；PC 符号按载荷确定，符号翻转不会改变样本距离。每组在每个位点按二倍体数据计算频率，并采用有限样本修正的成对差异估计，再对这六个给定位点取均值；观察杂合度是杂合基因型的比例。这里的均值是示例位点统计，不是按全基因组可检测碱基计算的核苷酸多样性。

生成 `pca.csv`、`diversity.csv`、`pca.png` 和 `run.json`。实际运行得到 PC1、PC2 解释比例约为 72.27%、17.19%；两组示例位点平均成对差异均为 0.345238，观察杂合度均为 0.416667。单独检查了样本数、位点数、上述统计量及图像文件。运行平台的线性代数库可能造成微小数值差异。

正式群体研究还需处理样本亲缘、缺失值、分型错误、位点选择、连锁和倍性，并根据研究问题决定标准化及可检测区域。该示例没有运行 PLINK 或 ADMIXTURE，也没有计算模型祖先成分。
