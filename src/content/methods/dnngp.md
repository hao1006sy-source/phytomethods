## 软件定位与研究问题
DNNGP 是用于植物基因组预测的深度神经网络方法，研究目标是在训练材料中学习基因型、可选组学特征与表型之间的预测关系。方法论文发表于 *Molecular Plant*，报告了多个数据集上的模型比较；性能结论应限定于论文所用材料、性状、数据和验证设计。[Wang 等，2023](https://doi.org/10.1016/j.molp.2022.11.004)；[官方代码库](https://github.com/AIBreeding/DNNGP)。

## 计算原理与分析步骤
神经网络通过多层参数化变换拟合输入特征与训练表型之间的非线性映射，并以损失函数优化权重。基因型编码、特征标准化、缺失处理、网络结构、正则化、优化器及早停策略会影响模型。严谨流程需先按育种部署目标划分训练、验证与测试数据，再仅用训练部分拟合预处理步骤和模型，并在未参与选择的测试数据上评估。

多组学输入可能包含表达、环境或其他分子特征，但各组数据必须按样本和试验时间正确配对。若表达数据来自预测时不可获取的组织或时期，模型将产生部署信息泄漏。特征筛选、超参数调优和归一化都应限制在训练折内；跨家系、地点和年份验证可检验模型迁移能力。

## 输入、输出与应用解释
输入通常包括标记基因型、对应表型及可选组学矩阵；输出为连续性状预测值及模型评估结果。应报告数据集划分、重复次数、随机种子、基线模型、评价指标和置信区间或变异范围。深度模型在特定数据集胜出不构成普遍优于线性基线的证据；需与 GBLUP、rrBLUP 等方法在相同划分和调参预算下比较。

## 版本、环境与复现状态
官方仓库的发布记录提供 v3.1；仓库说明其环境依赖包括 Python 3.9 与 TensorFlow 2.6.0。具体平台安装方式、数据格式和运行命令以对应版本 README 与手册为准。本项目未安装或运行 DNNGP，页面所述为方法和官方资料整理，未声称本地复现成功。
