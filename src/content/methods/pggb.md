## 软件定位与核心科学问题

现有的绝大多数泛基因组构建工具（如 Minigraph、早期 Cactus 等）都属于“参考引导型（Reference-guided）”架构。这类方法强制挑选一个人为指定的参考基因组作为整个图的主干骨架，其余样本的变异仅能作为挂载在主干上的旁路气泡。

然而，在植物演化与育种学研究中，参考引导架构存在深刻的局限：
1. **参考序列选择偏倚（Reference Bias）**：若参考基因组存在组装缺口、着丝粒错误组装或大片段缺失，所有输入样本在该区间的拓扑解析都将发生系统性扭曲；
2. **缺乏真正的拓扑对称性**：将样本 $A$ 设为主参考与将样本 $B$ 设为主参考，生成的变异图在节点结构和分支关系上存在显著差异；
3. **野生植物与非模式种质无可用优质参考**：在探索古代地方品种或野生近缘种时，研究人员需要一种不偏向任何单一基因组的、真正民主平等的构图范式。

为了实现真正的“参考无偏性”，Erik Garrison、Andrea Guarracino 等国际学者联合开发了 **PGGB（PanGenome Graph Builder）**（发表于 *Nature Methods*, 2024）。

PGGB 是一种**全无偏、无参考（Reference-free / All-to-all）**的全碱基分辨率泛基因组图构建全自动流水线。它将所有输入的单倍型基因组置于完全平等的数学地位，通过全对全长序列波前比对、图论等价类诱导、拓扑排序与局部多序列比对（SPOA）平滑重构，生成能够完整表达所有单倍型微观 SNP/Indel 与宏观倒位易位的标准 GFA 变异图。

## 核心算法架构与流水线流水设计

```
   [多样本单倍型染色体组装 FASTA] (遵循 PanSN 规范: Sample#Haplotype#Chromosome)
                                │
                                ▼
       阶段 1: 全对全长序列波前比对 (wfmash)
       └─ 基于波前对齐算法 (WFA) 计算所有单倍型之间的局部同源映射 (保留 Identity >= p)
                                │
                                ▼
       阶段 2: 比对诱导变异图生成 (seqwish)
       └─ 将局部对齐无缝折叠为同值等价类，构建包含所有序列与分叉的原始 GFA 图
                                │
                                ▼
       阶段 3: 局部拓扑平滑与规范化 (smoothxg)
       └─ 1D-SGD 拓扑排序 + 滑动窗口局部多重比对 (SPOA)，消除人造微小自环与杂乱回环
                                │
                                ▼
       阶段 4: 冗余节点塌陷与图压缩 (gfaffix)
       └─ 识别无分支连续线性链，合并哑节点，输出紧凑标准化 GFAv1 图
                                │
                                ├─────────────────────────────────────────┐
                                ▼                                         ▼
         图多尺度拓扑分析与切片 (ODGI)                     变异矩阵导出与可视化 (vg deconstruct)
         └─ 一维全局流形排序、染色体宏观平铺图像           └─ 以任意指定单倍型为主干导出群体 VCF
```

### 1. 四大核心算法引擎协同机制

PGGB 将极其复杂的图构建过程模块化解耦为四个严密串联的底层算法组件：

#### (1) wfmash：无偏全对全波前比对
- 将输入的全部单倍型序列切分为长度为 $s$（通常 $s = 5\text{ kb} \sim 10\text{ kb}$）的重叠滑动片段；
- 利用基于最小哈希（Mash distance）的快速过滤器评估片段间的同源可能性；
- 采用突破性的**波前对齐算法（Wavefront Alignment Algorithm, WFA）**，以 $\mathcal{O}(N \cdot s)$ 的极高时间与显存效率执行双向局部比对，严格保留平均核苷酸相似度 $\ge p$（例如 $p=90\%$ 或 $95\%$）的所有有效同源映射，彻底消除了单向比对的参考偏倚。

#### (2) seqwish：比对诱导变异图诱导
- 传统多重序列比对难以转化为图。seqwish 从图论底层将比对对偶化：
- 序列中的每一个核苷酸作为一个节点候选。若两段序列在 wfmash 中被比对到一起，seqwish 将其认定为同一个等价类并合并为一个统一的图节点；相邻连续碱基则建立有向连接边；
- 产出完全保真的初始变异图，严格无损地保留了所有输入单倍型在图中的完整穿行轨迹（Paths）。

#### (3) smoothxg：变异图局部拓扑平滑
- 原始诱导图因测序错误、微小串联重复或局部微倒位，往往包含数以万计无生物学意义的局部小发夹环与自环（Self-loops）；
- smoothxg 首先调用一维随机梯度下降（1D-SGD）对全图节点进行全局拓扑排序；
- 随后沿排序后的图以滑动窗口（Block size）切取局部子图，调用 **SPOA（Partial Order Alignment）**算法在局部重新执行多序列对齐与拓扑规约，消除人造结构假象，输出高度平滑的生物学变异拓扑。

#### (4) gfaffix：图简并压缩
- 扫描图中的单进单出（Single-input single-output）线性节点链，将多余的切分节点塌陷合并为单一长序列节点；
- 识别并清理由于微小测序错配形成的冗余双胞气泡，最终产出体积紧凑、可直接用于下游比对与分型的 GFAv1 标准文件。

### 2. PanSN 统一单倍型命名标准 (Pan-genome Sequence Naming)

为了在全无偏的变异图中精准追踪任意特定单倍型的真实穿行路径，PGGB 强制推行并依赖 **PanSN 命名规范**：
输入 FASTA 序列的头部必须严格格式化为三个由 `#` 分隔的字段：
```
>[Sample_ID]#[Haplotype_ID]#[Contig/Chromosome_ID]
```
例如：
- `B73#1#Chr1`：表示玉米 B73 品种第 1 套单倍型第 1 号染色体；
- `Mo17#1#Chr1`：表示玉米 Mo17 品种第 1 套单倍型第 1 号染色体。
这一规范使 PGGB 构图后，ODGI 和 vg 能够瞬间根据样本标签提取出任意样本的特异子图，或将全图变异以任意样本为主干投影为标准 VCF 矩阵。

## 植物应用评估与技术考量

| 植物基因组挑战 | 潜在算力瓶颈与风险 | PGGB 规范应对策略 |
| :--- | :--- | :--- |
| **全对全计算复杂度 $\mathcal{O}(N^2)$ 与全染色体混合爆炸** | 植物通常具有 10~20 条庞大的染色体（如玉米 10 条染色体，总长 2.4 Gb）。若将全基因组所有染色体混合成单个文件运行 PGGB，全对全比对将跨染色体发生海量转座子假比对，导致内存暴增至 TB 级别。 | **严禁全基因组全染色体混合构图**：**必须按同源染色体拆分（Per-chromosome partition）**。分别对 Chr1, Chr2, ..., Chr10 独立运行 PGGB 流水线，最后利用 ODGI 或 vg 拼接或独立管理各染色体图。 |
| **植物不同亲缘分化度参数调优** | 参数 `-p`（最小相似度）与 `-s`（片段跨度）直接决定图的拓扑分辨率。 | - **同物种不同自交系/品种**（如玉米自交系）：设 `-p 95 -s 5k`（相似度 $\ge 95\%$，窗口 5 kb）；<br>- **近缘种或跨亚种**（如水稻籼粳比较、栽培稻与野生稻）：放宽至 `-p 85 -s 10k` 或 `-p 90 -s 5k`，防止高发散区对齐断裂。 |
| **高重复着丝粒区域的拓扑缠绕** | 植物着丝粒富含兆碱基级别的串联卫星重复（Satellite repeats），会导致局部平滑算法算力超时。 | PGGB 提供 `-G` 参数限制最大节点度数，并可在 smoothxg 阶段设置最大步长限制，防止着丝粒卫星重复过度聚合形成密集死结。 |

## 典型分析命令与标准操作流

以下为在 Linux 高性能计算节点上针对植物单条同源染色体运行 PGGB 的标准工作流：

```bash
# 1. 准备遵循 PanSN 规范的多样本单倍型染色体 FASTA 并建立索引
# 输入包含 8 个代表性水稻品种的第 1 号染色体: rice_chr1_all_haplotypes.fa.gz
samtools faidx rice_chr1_all_haplotypes.fa.gz

# 2. 执行端到端全自动无参考泛基因组图构建流水线 (PGGB)
# -i: 输入多序列 FASTA; -o: 输出工作目录; -t 32: 32 核心并发
# -n 8: 输入单倍型总数为 8; -p 95: 局部比对最小相似度 95%
# -s 5k: 比对片段窗口大小 5,000 bp; -V "Nipponbare#1#Chr1": 指定参考路径用于导出 VCF
pggb \
    -i rice_chr1_all_haplotypes.fa.gz \
    -o ./pggb_rice_chr1_output/ \
    -n 8 \
    -t 32 \
    -p 95 \
    -s 5000 \
    -V "Nipponbare#1#Chr1:" \
    -m

# 3. 检查核心产物
# 目录将输出:
# - *.gfa: 最终全碱基高分辨率变异图
# - *.vcf.gz: 以为 Nipponbare 为主干投影生成的全群体变异 VCF
# - *.og: ODGI 紧凑二进制图
# - *.draw.png: 全景平铺拓扑可视化图

# 4. 随后调用 ODGI 提取全染色体拓扑结构统计指标
odgi stats -i ./pggb_rice_chr1_output/*.og -S -l
```

## 科学研究案例与上下游分析协同

- **高粱染色体泛基因组图多尺度基准案例**：在 Kopalli 等（*GigaScience*, 2024）的作物图泛基因组权威横向评测中，研究团队深入评估了 PGGB 在真实高粱 6 个代表性基因组上的构图表现。PGGB 在没有任何单一骨架偏置的前提下，成功将包括着丝粒在内的复杂非同源重排完整诱导为高密度拓扑图（最终图大小约 4.7 Gb），完整捕获了微观点突变与宏观倒位。研究指出，PGGB 能够输出最忠实于原始基因组间客观亲缘演化关系的变异图；
- **分析工具流转与协作边界**：
  - **硬件要求准备**：由于全对全比对包含 $\frac{N(N-1)}{2}$ 对比对计算，建议单条染色体配置 32~64 线程与 64~128 GB 内存；
  - **下游分析承接**：PGGB 产出的 GFA 图天然兼容 **ODGI**（用于一维平铺可视化与子图切取）和 **vg**（用于单倍型图索引构建与变异分型）。
