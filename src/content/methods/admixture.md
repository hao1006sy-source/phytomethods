## 生物学问题与定位

在植物驯化、种质资源演化与物种分化研究中，由于存在广泛的花粉扩散、古代渐渗杂交（Introgression）以及人工引种杂交，现实中的个体往往不是纯粹单一谱系的后裔，而是多个历史祖先群体的复杂遗传嵌合体。

**ADMIXTURE** 由加州大学洛杉矶分校 David Alexander、John Novembre 和 Kenneth Lange 于 2009 年发表在 *Genome Research* 上，是群体遗传学中用于推断**样本祖先成分比例（Ancestry Proportions, Q 矩阵）与祖先群体等位基因频率（Allele Frequencies, P 矩阵）**的黄金标准软件。

经典的 STRUCTURE 软件采用贝叶斯马尔可夫链蒙特卡洛（MCMC）抽样，在面对全基因组重测序产生的数千样本与数百万标记时，通常需要数周甚至数月才能收敛。ADMIXTURE 采用与 STRUCTURE 相同的对数似然模型，但巧妙地将统计推断转化为受约束的数值最优化问题。通过**块松弛算法（Block Relaxation）**结合**序列二次规划（SQP）**与**拟牛顿加速（Quasi-Newton Acceleration）**，ADMIXTURE 将计算速度提升了两个数量级，使得在全基因组水平快速探索不同 $K$ 值与重复运行成为常规可能。

## 核心算法数学原理与推导

ADMIXTURE 的数学推导与优化架构包含以下关键环节：

### 1. 混合二项分布极大似然模型

设分析群体包含 $N$ 个二倍体个体和 $M$ 个双等位未连锁 SNP 位点。令 $g_{ij} \in \{0, 1, 2\}$ 为个体 $i$ 在位点 $j$ 携带的次要等位基因拷贝数。假定群体源自 $K$ 个历史假想祖先成分：

- $q_{ik}$：个体 $i$ 的基因组中源自祖先成分 $k$ 的比例，满足非负与和为 1 约束：
  $$\sum_{k=1}^K q_{ik} = 1, \qquad q_{ik} \ge 0$$
- $p_{kj}$：祖先成分 $k$ 在位点 $j$ 上的次要等位基因频率，满足频率边界约束：
  $$0 \le p_{kj} \le 1$$

在给定祖先比例 $Q \in \mathbb{R}^{N \times K}$ 与频率矩阵 $P \in \mathbb{R}^{K \times M}$ 的前提下，个体 $i$ 在位点 $j$ 的混合等位基因期望频率 $\theta_{ij}$ 为各成分的加权和：

$$\theta_{ij} = \sum_{k=1}^K q_{ik} p_{kj}$$

假定在给定成分划分下各位点服从哈代-温伯格平衡（HWE）与连锁平衡（LE），则基因型 $g_{ij}$ 的条件概率满足二项分布：

$$P(g_{ij} \mid Q, P) = \binom{2}{g_{ij}} \theta_{ij}^{g_{ij}} (1 - \theta_{ij})^{2 - g_{ij}}$$

忽略与优化参数无关的二项式系数常数后，全基因组对数似然函数为：

$$\ln L(Q, P) = \sum_{i=1}^N \sum_{j=1}^M \left[ g_{ij} \ln(\theta_{ij}) + (2 - g_{ij}) \ln(1 - \theta_{ij}) \right]$$

ADMIXTURE 的核心计算目标是寻找满足约束的参数估计 $(\hat{Q}, \hat{P})$，使得对数似然函数最大化。

### 2. 块松弛（Block Relaxation）与序列二次规划（SQP）

由于目标函数关于联合参数 $(Q, P)$ 是非凸的，直接联合求解极易发散。ADMIXTURE 采用块坐标下降法（Block Coordinate Descent）：

1. **固定 $P$ 求解 $Q$**：此时目标函数对每个个体 $i$ 是严格凹函数（最大化凹函数等价于凸优化），且各样本之间相互独立，可天然在多核 CPU 上高度并行求解；
2. **固定 $Q$ 求解 $P$**：目标函数对各位点 $j$ 亦为严格凹函数，各位点之间完全独立，同样支持大规模并行优化；
3. **序列二次规划与拟牛顿加速**：在每一次块更新中，利用目标函数的二阶泰勒展开构建约束二次规划子问题，并采用秩一/秩二拟牛顿法（Secant conditions）更新 Hessian 矩阵近似逆，通过 Armijo 条件回溯线性搜索保证每步严格单调增加似然值。

### 3. 交叉验证（Cross-Validation Error）与模型选择

为了科学评估最合适的祖先成分数 $K$，ADMIXTURE 引入了 $V$-折交叉验证机制（参数 `--cv`，默认 $V=5$）：
1. 将基因型矩阵中的观测数据随机划分为 $V$ 个等份；
2. 每次将其中的一份作为测试集并掩蔽为缺失值（Masked），使用剩余的训练集数据估计最优参数 $(\hat{Q}, \hat{P})$；
3. 计算被掩蔽测试集位点的预测残差平方和（Prediction Error）：
   $$\text{CV Error}(K) = \sqrt{\frac{1}{|\Omega|} \sum_{(i,j) \in \Omega} \left( g_{ij} - 2\hat{\theta}_{ij} \right)^2}$$
4. 遍历候选 $K$ 值，通常预测误差最小或曲线出现明显拐点（Elbow point）的 $K$ 值代表统计学预测能力最佳的模型。

## 生产环境标准流水线

以下展示对经过严格质控与 LD 剪枝的植物基因型执行多 $K$ 值循环探索、独立随机种子重复、交叉验证误差提取与 Q 矩阵可视化的生产级流程：

```bash
# 步骤 1：准备经过 PLINK 严格 LD 剪枝后的 BED 文件集（例如 plant_pruned.bed）

# 步骤 2：对 K = 2 至 8 分别执行 5 折交叉验证，每个 K 运行 5 次独立重复以应对多峰性
mkdir -p admixture_runs log_cv

for K in $(seq 2 8); do
  for REP in $(seq 1 5); do
    SEED=$((1000 + REP * 17))
    echo "Running ADMIXTURE: K=${K}, Rep=${REP}, Seed=${SEED}..."
    admixture --cv=5 -j8 -s ${SEED} plant_pruned.bed ${K} > log_cv/log_K${K}_rep${REP}.out
    # 归档输出文件
    mv plant_pruned.${K}.Q admixture_runs/plant_K${K}_rep${REP}.Q
    mv plant_pruned.${K}.P admixture_runs/plant_K${K}_rep${REP}.P
  done
done

# 步骤 3：自动提取各运行的交叉验证误差（CV Error）并筛选最优重复
grep -h "CV error" log_cv/log_K*.out | awk '{print $3, $4}' | tr -d '():' | sort -k1,1n > cv_summary.txt

# 步骤 4：在 R 或 Python 中结合样本元数据（品种、地理分布）绘制堆叠柱状图
# 使用 Pong 或 CLUMPP 对相同 K 的不同重复进行置换对齐，消除标签切换（Label switching）
```

## 核心参数科学解析与植物调优指南

| 参数指令 | 推荐取值 | 物理含义与植物科研注意事项 |
| :--- | :--- | :--- |
| `K` | `2` ~ `10` | **祖先成分数**；必须设置探索区间，严禁仅跑单一固定 $K$ 值；植物亚群分化通常在 $K=2 \sim 8$ 间获得清晰生物学解释。 |
| `--cv[=V]` | `--cv=5` 或 `10` | **交叉验证折数**；计算留出预测误差；对于样本量较小（$< 100$）的珍稀植物群体，推荐采用 10 折交叉验证。 |
| `-j<int>` | `8` ~ `32` | **多线程并行数**；块松弛算法中样本与位点的并行更新，可显著缩短全基因组扫描时间。 |
| `-s <int>` | 随机正整数 | **随机数发生器种子**；由于极大似然目标函数存在多峰性，必须显式指定不同种子进行独立重复运行。 |
| `-B[=M]` | `100` ~ `200` | **区块自助法（Block Bootstrap）**；计算祖先比例的标准误（输出 `.Q_se`）；计算开销较大，适合最终选定 $K$ 值后的精度评估。 |
| `--supervised` | 配合 `.ind` 使用 | **有监督学习模式**；当有明确已知的原始野生祖先或核心种质标签时，固定参考样本的 $Q$，对未知杂交系进行投影推断。 |

## 植物基因组特有挑战与避坑指南

### 1. 纯合度极高引发的“假性极端祖先成分”陷阱
- **机制与风险**：ADMIXTURE 的似然函数天然假设祖先群体内处于 HWE 平衡，杂合子期望比例为 $2\theta(1-\theta)$。然而，水稻、拟南芥等自交植物在长期的繁育中近交系数 $F \approx 1$，全基因组几乎全为纯合位点（$0$ 或 $2$），几乎没有杂合子（$1$）。
- **严重后果**：模型在惩罚偏离 HWE 的似然项时，会倾向于把极端纯合的近交系强行拟合为具有独立等位基因频率的“特异纯系祖先成分”。当 $K$ 值逐渐增加时，柱状图上往往会凭空出现仅属于某几个近交品种的“专属单一颜色条”，这并非真实的地质历史祖先群体，而是自交纯合导致的统计过拟合。
- **避坑准则**：在解释高 $K$ 值结果时，必须对照样本近交系数与系谱记录；若某个祖先成分仅出现在某一个家系内部且无地理群体代表性，不可轻易将其解读为“古老祖先分支”。

### 2. $K$ 值选择的科学误区：CV 曲线并非绝对金标准
- 在很多植物研究中，随着 $K$ 值的持续递增，CV error 曲线可能持续缓慢下降而不出现明显的极小值点，或者在非常高的 $K$（如 $K=15$）处才达到最低点。
- **原因解析**：现实中的野生植物种群常常存在连续的地理渐变模式（Isolation by Distance, IBD）。当群体间不存在绝对的地理隔离屏障，而是基因流沿地理距离连续衰减时，离散的混合模型本身不完全贴合实际。
- **科学处置**：不可盲目追求最低 CV error。必须结合主成分分析（PCA）、系统发育树（NJ Tree/Treemix）以及植物收集地的地理空间分布进行多重证据交叉验证，选择生物学可解释性最强、与地理生态型吻合度最高的最小合理 $K$ 值。

### 3. 多峰性（Multimodality）与标签切换（Label Switching）
- 在相同的 $K$ 值下，由于初值随机敏感性，不同种子运行可能收敛到不同的局部极大似然点（Local optima）。此外，各成分在输出中的列顺序（如成分 1 与成分 2）是任意排列的。
- **解决方案**：对每个 $K$ 必须运行 10~20 次独立重复；在绘制堆叠图前，**必须使用 Pong 或 CLUMPP 软件**对多次重复的 $Q$ 矩阵执行贪心对齐与聚类合并，绝不可随意抽取单次运行的结果代表该 $K$ 值的全部形态。

## 输出结果深度解析

对于设定的成分数 $K$，ADMIXTURE 生成以下关键产物：

```text
admixture_runs/
├── plant_K3_rep1.Q       # 个体祖先成分比例矩阵 (行对应样本, 列对应 K 个祖先成分, 每一行数值之和严格为 1.0)
└── plant_K3_rep1.P       # 祖先成分等位基因频率矩阵 (行对应 K 个祖先成分, 列对应输入位点, 数值范围 [0, 1])
```

- **Q 矩阵可视化**：在 R 语言中使用 `barplot` 或 `ggplot2::geom_col`，将每个个体的 $Q$ 矩阵行拆分为堆叠条形，不同祖先成分赋予不同色块。样本沿横轴按亚群分类或地理纬度顺序排列，可清晰呈现纯系祖先、杂交渗入比例与地理过渡带的渐变过渡。

## 植物应用案例与真实文献证据

1. **3,010 份水稻基因组群体结构与杂交渗入格局**：
   在亚洲栽培稻核心种质研究中（Wang et al., *Nature*, 2018），研究人员在对 100 万个非连锁 SNP 运行 ADMIXTURE 时，系统评估了 $K=2$ 至 $K=12$ 的模型。在 $K=2$ 时，群体清晰切分为籼稻（xian/indica）与粳稻（geng/japonica）两大主干；在 $K=9$ 时，精准识别出 aus、basmati、芳香稻（aromatic）以及热带粳稻、温带粳稻等细分生态亚群，并通过多轮重复的 $Q$ 矩阵揭示了大量具有杂交渗入背景的农家种（[Wang et al., *Nature*, 2018](https://doi.org/10.1038/s41586-018-0063-9)）。
2. **玉米野生祖先大刍草（Teosinte）与现代栽培玉米的驯化渗入**：
   在玉米驯化基因组学经典研究中，Hufford 等人利用 ADMIXTURE 解析了墨西哥大刍草亚种（*Zea mays* ssp. *parviglumis* 和 ssp. *mexicana*）向高海拔玉米地方品种的适应性渐渗，通过 $Q$ 矩阵的成分定量证实了现代高地玉米中抗寒抗紫外线基因位点主要源自 mexicana 的渐渗杂交（[Hufford et al., *Nature Genetics*, 2012](https://doi.org/10.1038/ng.2309)）。

## 实践排错与质控规范

- **错误 1：程序运行瞬间报错 `Error: could not open plant.fam` 或位点数不匹配**
  - *排查原因*：ADMIXTURE 读取 `.bed` 文件时，要求同目录下必须存在同名的 `.bim` 和 `.fam` 文件，且染色体命名与位点计数必须严格一致。
  - *解决方案*：确保当前目录下 `.bed`、`.bim`、`.fam` 三者前缀完全相同；若染色体名称包含字符（如 `Chr01`），ADMIXTURE 会尝试解析，但某些旧版本可能要求纯数字染色体编号，可预先使用 `plink --allow-extra-chr` 处理。
- **错误 2：某些个体的 Q 矩阵各列数值全为 `NaN` 或全是均等分（如 $1/K$）**
  - *排查原因*：该个体的位点缺失率过高（例如缺失率 $> 50\%$），或者输入的变异数据未做 MAF 过滤，包含大量在所有样本中全为纯合的无效位点。
  - *解决方案*：在 PLINK 中执行严苛的个体质控（`--mind 0.1`）与位点过滤（`--geno 0.05 --maf 0.05`），重新生成干净的 BED 文件集后再运行 ADMIXTURE。
