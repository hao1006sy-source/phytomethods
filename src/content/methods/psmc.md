## 生物学问题与定位

在植物演化生物学与群体基因组学中，重建植物物种在第四纪冰期-间冰期气候波动、地质剧变及人类驯化早期的历史有效群体大小（Effective Population Size, $N_e$）动态，对于揭示物种演化历程、濒危机制和气候适应性具有至关重要的学术价值。

传统的群体历史推断方法（如基于位点频率谱 SFS 或溯祖模拟）通常需要收集几十乃至上百个个体的全基因组重测序数据，这在面对野生珍稀濒危植物、野生物种或测序预算有限时面临巨大挑战。

**PSMC（Pairwise Sequentially Markovian Coalescent）**由著名生物信息学学者 Heng Li（李恒）与 Richard Durbin 于 2011 年发表在 *Nature* 上。该方法颠覆性地确立了一个基本原理：**单个个体的二倍体全基因组序列本身就是一部完整的群体演化史书！**因为在一个二倍体个体内，来自父本与母本的两条同源染色体在全基因组不同位置具有不同的最近共同祖先时间（TMRCA）。减数分裂中的同源重组将染色体切割为成千上万个具有独立共祖历史的微小区段。通过隐马尔可夫模型（HMM）扫描全基因组杂合位点的空间密度分布，即可逆向重构跨越数十万年乃至数百万年的群体历史有效种群规模波动。

## 核心算法数学原理与推导

PSMC 的统计推断基于顺序马尔可夫共祖（SMC/SMC'）理论与离散隐状态马尔可夫模型：

### 1. 空间共祖过程与时间离散化

设参考基因组被等距切分为长度为 $s$（默认 $s = 100\text{ bp}$）的无重叠连续窗口（Binned intervals）。在第 $i$ 个窗口中，两条同源序列的真实最近共同祖先时间为连续随机变量 $T_i \in (0, \infty)$。

由于连续时间状态在计算上无法直接构建转移矩阵，PSMC 将时间轴从距今 $0$ 到远古划分为 $K$ 个离散时间区间（默认 $K = 64$ 个时间步长）：

$$0 = t_0 < t_1 < t_2 < \dots < t_K = \infty$$

离散隐状态定义为 $S_i \in \{0, 1, \dots, K-1\}$，表示第 $i$ 个窗口的共祖时间落在区间 $[t_k, t_{k+1})$ 内。时间分割点通常按照指数级递增分布：

$$t_k = \frac{1}{\beta} \left( e^{\frac{k}{K} \ln(1 + \beta T_{\max})} - 1 \right)$$

这种分布保证了在距今年代较近的时期时间切分细致，而在远古时期区间适当放宽。

### 2. 杂合发射概率（Emission Probability）

在窗口 $i$ 处，模型仅观测其是否包含杂合位点。设两个同源区段在时间 $\tau_k$ 共祖，中性突变沿两条谱系以恒定速率 $\mu$（每位点每代突变率）独立累积。两单倍型之间的总分支长度为 $2\tau_k$。在一个长度为 $s$ 的区间内，突变位点数服从泊松分布：

- **纯合状态（状态符号 `T`）**：该 $100\text{ bp}$ 区间内完全没有杂合位点：
  $$P(O_i = \text{纯合} \mid S_i = k) = e^{-2 \mu s \tau_k}$$
- **杂合状态（状态符号 `K`）**：该 $100\text{ bp}$ 区间内至少观测到 1 个杂合位点：
  $$P(O_i = \text{杂合} \mid S_i = k) = 1 - e^{-2 \mu s \tau_k}$$

### 3. 顺序重组驱动的状态转移概率（Transition Probability）

相邻两个窗口 $i$ 与 $i+1$ 之间的物理距离为 $s$。重组事件以每位点每代速率 $r$ 发生。在 SMC' 近似下，状态转移概率矩阵元素 $A_{kl} = P(S_{i+1} = l \mid S_i = k)$ 由两部分决定：
1. 在谱系历史到达共祖时间 $\tau_k$ 之前未发生重组，则两窗口共享相同祖先区段，状态保持不变；
2. 在时间 $t < \tau_k$ 发生重组，脱离的原谱系在新的共祖时间 $\tau_l$ 重新与主种群谱系结合。其转移概率解析式由有效群体大小变化函数 $\lambda(t) = N_e(t) / N_0$ 调控。

### 4. Baum-Welch 算法与参数求解

PSMC 采用标准 Baum-Welch 期望最大化（EM）算法迭代估计：
1. **E 步（前向-后向算法）**：计算在当前群体规模参数 $\boldsymbol{\lambda} = \{\lambda_0, \dots, \lambda_{K-1}\}$ 下，全染色体观测序列在各时间区间的后验概率；
2. **M 步**：通过更新各区间的相对群体大小参数 $\lambda_k$，最大化全基因组观测序列的边际对数似然：
   $$\ln L(\boldsymbol{\lambda}, \theta, \rho) = \sum_{\text{chromosomes}} \ln P(\mathbf{O} \mid \boldsymbol{\lambda}, \theta, \rho)$$
3. 重复迭代（通常设置 `-N 25` 或 30 次迭代），直至似然值收敛。

### 5. 物理尺度换算（标定年代与真实有效种群规模）

PSMC 输出的参数是以突变单位尺度化的无量纲数值。必须结合物种真实的**每代每位点突变率 $\mu$**和**世代时间 $g$（年/代）**换算为绝对物理量：

- **历史时间轴（横坐标，单位：年前 / Years Ago）**：
  $$\text{Years} = 2 N_0 \tau_k \times g = 2 \left( \frac{\theta_0}{4 \mu s} \right) \tau_k \times g$$
- **有效种群规模（纵坐标，单位：个体数 / $N_e$）**：
  $$N_e(t) = N_0 \lambda_k = \left( \frac{\theta_0}{4 \mu s} \right) \lambda_k$$

## 生产环境标准流水线

以下展示从单个植物高深度重测序 BAM 文件（推荐测序覆盖度 $\ge 20\times$）生成 PSMCFA 输入、运行 PSMC 拟合、执行区块 Bootstrap 重抽样并生成物种定标曲线的完整流水线：

```bash
# 步骤 1：使用 BCFtools 生成二倍体全基因组共识 FASTQ 序列
# 过滤深度过低（< 10×，易漏调杂合）或过高（> 2× 平均深度，易为重复区伪杂合）
bcftools mpileup -Ou -f ref_genome.fa sample_sorted.bam | \
  bcftools call -c -Ov | \
  vcfutils.pl vcf2fq -d 10 -D 60 -Q 20 | gzip > sample.diploid.fq.gz

# 步骤 2：将共识序列转换为 PSMCFA 格式（每个字符代表 100 bp 窗口）
# -q20 表示只采纳比对质量分 >= 20 的位点
fq2psmcfa -q 20 sample.diploid.fq.gz > sample.psmcfa

# 步骤 3：切分长染色体以准备执行区块重抽样（Bootstrap）
splitfa sample.psmcfa > sample.split.psmcfa

# 步骤 4：主模型参数拟合（以常见时间区间绑定方案 "4+25*2+4+6" 为例）
psmc -N 25 -t 15 -r 5 -p "4+25*2+4+6" -o sample.psmc sample.psmcfa

# 步骤 5：并行执行 100 次 Bootstrap 以评估推断置信区间
for i in $(seq 1 100); do
  psmc -N 25 -t 15 -r 5 -p "4+25*2+4+6" \
    -b -o bootstrap/round_${i}.psmc sample.split.psmcfa &
done
wait

# 步骤 6：利用突变率（如水稻 6.5e-9）与世代时间（1年/代）绘制物理尺度曲线
psmc_plot.pl -u 6.5e-9 -g 1 -R -p \
  sample_final_plot \
  sample.psmc \
  bootstrap/round_*.psmc
```

## 核心参数科学解析与植物调优指南

| 参数指令 | 推荐设置 | 物理含义与植物科研注意事项 |
| :--- | :--- | :--- |
| `-p <pattern>` | `"4+25*2+4+6"` 或 `"4+30*2"` | **时间区间绑定方案**；总和必须等于时间区间数 $K$（通常为 64）。`25*2` 表示将 50 个连续区间每 2 个绑定共享一个 $\lambda$ 参数，降低过拟合风险。 |
| `-t <float>` | `15` | **最大 TMRCA 比例上限**；控制推断时间窗口向远古延伸的边界；过大易使远古估计产生数值振荡。 |
| `-r <float>` | `5` | **初始重组率与突变率比值 $\rho/\theta$**；为 EM 迭代提供合理的初始搜索空间。 |
| `-N <int>` | `25` ~ `30` | **EM 迭代轮数**；对于高杂合或数据量大的植物基因组，25 轮迭代通常足以确保对数似然充分收敛。 |
| `-u <float>` | 物种特异值 | **每代每位点自发突变率 $\mu$**；必须引用可靠文献测定值（如拟南芥 $7 \times 10^{-9}$、水稻 $6.5 \times 10^{-9}$、玉米 $3 \times 10^{-8}$）。 |
| `-g <float>` | 物种特异值 | **世代时间（年/代）**；草本一年生作物通常为 1；多年生木本林木（如杨树、柑橘）可为 5~15 年。 |

## 植物基因组特有挑战与避坑指南

### 1. 自交植物的“全纯合致命瘫痪”与“伪二倍体策略”
- **机制与风险**：水稻、拟南芥、大豆等高度自交植物，其自然种质材料几乎是完全纯合的近交系，全基因组杂合率极低（常低于 $0.01\%$）。若将单一纯系样本直接输入 PSMC，程序将因为全基因组几乎全为 `T` 字符而判定共祖时间极近，输出完全失真的崩溃曲线。
- **解决方案（伪二倍体构建法 / Pseudo-diploid Strategy）**：
  选取同一亚种或不同地理来源的**两份高纯度纯系样本**（例如籼稻样本 A 与籼稻样本 B）。将样本 A 的纯合基因型视为单倍型 1，样本 B 的纯合基因型视为单倍型 2，将二者人工合并为一个“人工伪二倍体”。由于两样本在历史分化节点之前共享共同祖先历史，该伪二倍体的 PSMC 曲线能够极其准确地重建两个谱系在分化合并前的古代有效群体动态。

### 2. 近期历史（$< 2 \sim 5$ 万年前）的分辨率盲区
- **原理局限**：单个个体的 2 条同源染色体在距今较近的近代（如几千年前的农业驯化时期）发生共祖的概率极低。因此，PSMC 在横坐标 $< 2 \times 10^4$ 年前的曲线段具有极大的随机误差与人工伪影。
- **避坑准则**：**严禁使用 PSMC 曲线推断末次冰期盛期（LGM）之后或新石器时代农业驯化的近期瓶颈**！推断近 1 万年内的群体历史必须改用 MSMC2、SMC++ 或基于 SFS 的专业工具。

### 3. 古多倍化残余与重复序列未掩蔽引起的远古“假性群体暴涨”
- 植物基因组中广泛存在古代全基因组加倍（WGD）残留与高拷贝转座子（TE）。若在变异调用时未过滤多拷贝旁系同源区域，旁系同源基因的比对碰撞会产生大面积假杂合位点。
- 假杂合位点被 PSMC 误解为极端深远的古代共祖事件，导致曲线在距今 100 万年前以上的时间尺度上呈现出急剧的“虚假种群大爆发”。
- **对策**：必须使用严格的 RepeatMasker BED 掩蔽区与测序深度上限过滤（例如剔除深度 $> 2\times$ 均值的位点）。

## 输出结果深度解析

```text
sample.psmc
├── RD: 迭代轮数与对数似然值记录 (Log-likelihood progression)
├── TR: 各时间区间更新后的重组率与突变率参数
└── MM: 最终收敛模型各时间区间的 λ 参数与对应物理尺度因子
```

通过 `psmc_plot.pl -R` 解析后，可获得标准的 `sample.psmc.0.txt` 纯文本表格：
- 第一列：历史年代（Years Before Present）；
- 第二列：有效种群规模（$N_e \times 10^4$）；
- 结合各轮 Bootstrap 曲线重叠绘制，若置信带紧密收敛，则表明该时期群体规模收缩或扩张的信号高度可信。

## 植物应用案例与真实文献证据

1. **非洲栽培稻与其野生祖先历史有效群体动态重建**：
   在非洲栽培稻（*Oryza glaberrima*）与其野生祖先（*Oryza barthii*）的起源研究中（Cubry et al., *Nature Plants*, 2018），研究人员针对水稻高度自交纯合的特点，设计了严格的伪二倍体策略，利用 PSMC 成功重建了两物种在过去 100 万年间的演化动态，精准捕获了二者在更新世晚期遭遇的剧烈瓶颈（[Cubry et al., *Nature Plants*, 2018](https://doi.org/10.1038/s41477-018-0245-7)）。
2. **胡杨基因组与第四纪冰期响应**：
   在极端抗旱抗盐碱树种胡杨（*Populus euphratica*）全基因组演化研究中，研究团队利用 PSMC 分析了单个高深度测序个体的杂合模式，证实胡杨在距今约 10 万年前的第四纪末次冰期经历过剧烈的有效群体规模收缩，并在随后的间冰期迅速扩张（[Ma et al., *Nature Communications*, 2013](https://doi.org/10.1038/ncomms3797)）。

## 实践排错与质控规范

- **错误 1：`psmc` 运行瞬间报错 `Floating point exception` 或在第 0 轮迭代直接终止**
  - *排查原因*：`sample.psmcfa` 中有效染色体长度太短，或者由于质控参数过于严苛，导致文件中全是缺失标记（`N`）而没有足够的观测字符。
  - *解决方案*：检查共识序列转换日志，确保全基因组有效长度覆盖度达到 $50\%$ 以上；检查染色体 ID 是否正确映射。
- **错误 2：输出曲线呈现极其剧烈、锯齿状的非生理性上下振荡**
  - *排查原因*：参数 `-p` 中未进行区间绑定（例如错误地使用了独立无绑定的 `64*1`），导致模型自由度过高产生严重过拟合。
  - *解决方案*：采用经典的参数绑定模式，例如 `-p "4+25*2+4+6"`，强制要求相邻的时间区间共享相同的 $\lambda$ 参数，使历史轨迹平滑连续。
