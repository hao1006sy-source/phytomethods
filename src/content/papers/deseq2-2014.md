# Moderated estimation of fold change and dispersion for RNA-seq data with DESeq2

## 1. 研究背景与算法贡献

高通量转录组测序（RNA-seq）读段计数数据天然表现出显著的**过度离散性（Over-dispersion）**，即基因在生物学重复样本之间的方差显著大于由于泊松抽样过程决定的泊松均值。在常规植物逆境胁迫或发育生物学实验中，受限于测序成本与生物材料获取难度，实验往往仅包含 2 至 4 次生物学重复。在极小样本量下独立估计每个基因的方差极不可靠：
1. 低表达或高噪声基因的样本方差极易被低估，导致虚假的高显著性假阳性；
2. 表达量极低的基因会产生极不稳定的夸大倍数变化（Fold Change, FC），严重误导后续的通路富集与分子功能注释。

2014 年，EMBL 欧洲分子生物学实验室与哈佛大学的 Michael I. Love、Wolfgang Huber 与 Simon Anders 在 *Genome Biology* 上推出了 **DESeq2**。DESeq2 的核心理论与算法创新在于：
- 构建了基于负二项分布的广义线性模型（Negative Binomial Generalized Linear Model, NB-GLM），灵活支持多因素复杂实验设计；
- 创新性地引入了**经验贝叶斯离散度平滑收缩（Empirical Bayes Dispersion Shrinkage）**，通过全基因组信息共享稳定单基因离散度估计；
- 提出了**对数倍数变化收缩（LFC Shrinkage）** 算法，有效压制低表达高噪声基因的效应量波动，确立了全球转录组差异分析的黄金标准。

## 2. 核心数学模型与数据结构

### 2.1 负二项分布与均值-方差关系

设基因 $i$ 在文库样本 $j$ 中的原始比对读段计数为 $K_{ij}$，模型假定其服从负二项分布：
$$K_{ij} \sim \text{NegativeBinomial}\left(\mu_{ij}, \alpha_i\right)$$

其数学期望与方差分别为：
$$E[K_{ij}] = \mu_{ij} = q_{ij} s_{ij}$$
$$\text{Var}(K_{ij}) = \mu_{ij} + \alpha_i \mu_{ij}^2$$

其中：
- $s_{ij}$ 为文库大小归一化因子（Size Factor），默认采用抗极值干扰的**中位数比值法（Median-of-ratios）** 进行稳健估计：
  $$s_j = \text{median}_i \frac{K_{ij}}{\left(\prod_{v=1}^m K_{iv}\right)^{1/m}}$$
- $q_{ij}$ 为样本中真实的基因相对丰度，通过对数连接函数与设计矩阵关联：$\log_2 q_{ij} = \sum_r x_{jr} \beta_{ir}$；
- $\alpha_i$ 为基因特定的离散度参数，刻画生物学重复之间的超额方差。

### 2.2 经验贝叶斯离散度收缩（Dispersion Shrinkage）

DESeq2 采用三步法稳定离散度：
1. **极大似然估计（MLE）**：首先对每个基因独立求解初始极大似然离散度 $\alpha_i^{\text{MLE}}$；
2. **拟合均值-离散度趋势曲线**：利用非线性参数回归拟合全基因组所有基因在平均表达水平下的整体离散度期望趋势 $\alpha_{\text{trend}}(\mu_i)$；
3. **经验贝叶斯最大后验估计（MAP）**：假定对数离散度服从以趋势曲线为中心的正态先验分布，通过经验贝叶斯收缩求解最大后验估计值 $\alpha_i^{\text{MAP}}$。对于样本方差异常膨胀的极端离群基因，算法自动检测并停止收缩以保护真实的生物学异质性。

### 2.3 效应量收缩（LFC Shrinkage）与 Wald 检验

在完成 GLM 参数拟合后：
- 使用 Wald 检验计算差异表达系数 $\beta_{ir}$ 的统计显著性 $p$ 值，并通过 Benjamini-Hochberg 过程转换为假发现率（FDR / $q$-value）；
- 结合 `apeglm` 或正态先验对数倍数变化收缩，对低计数或高方差基因的 $\log_2(\text{Fold Change})$ 进行后验收缩，输出可靠、适于直接绘图与基因排序的真实生物学效应量。

## 3. 算法复杂度与计算性能

1. **核心计算优化**：DESeq2 底层的坐标下降（Coordinate Descent）与牛顿-拉夫逊（Newton-Raphson）迭代优化采用 C++（Rcpp）编写，计算性能卓越。
2. **多核并行支持**：通过 `BiocParallel` 原生支持按染色体或基因切片的多线程并行加速。处理常规植物转录组（3 万至 4 万个基因，12 个生物学重复）在 8 核计算机上仅需 1–3 分钟。
3. **内置异常值诊断**：集成 Cook's 距离诊断机制，自动检测单个样本中的离群奇异计数点并进行温和校正，确保推断结果的强健性。

## 4. 植物基因组学应用场景与科研价值

植物转录组受昼夜节律、生长发育时期与多重非生物胁迫（干旱、盐碱、高低温）的严密多维调控：
- **复杂多因素实验设计（Multi-factor Design）**：例如在水稻耐逆实验中，同时包含“品种基因型（耐逆品系 vs 敏感品系）”、“处理条件（干旱 vs 对照）”以及“处理时序（0h, 2h, 6h, 24h）”。DESeq2 的 GLM 框架支持公式 `~ Genotype + Condition + Genotype:Condition`，能够精确分离出耐逆品种特异性响应的交互作用基因（Interaction Terms）；
- **异源多倍体同源基因表达不对称性（Homoeolog Expression Bias）**：在小麦（AABBDD）或甘蓝型油菜（AACC）中，定量分析同源基因对（Homoeologs）在各亚基因组间的表达偏好；
- **全基因组下游分析标准接口**：输出的方差稳定变换矩阵（Variance Stabilizing Transformation, VST）是后续 WGCNA 共表达网络构建、PCA 降维与热图聚类的黄金标准输入。

## 5. 输入输出规范与关键参数指南

### 5.1 核心分析流程与执行代码 (R / Bioconductor)
```R
library(DESeq2)

# 1. 构建 DESeqDataSet 对象 (必须使用原始未归一化的整数 Counts)
# colData 包含样本分组元数据
dds <- DESeqDataSetFromMatrix(
  countData = count_matrix,
  colData = col_data,
  design = ~ Treatment
)

# 2. 预过滤低表达噪声基因 (如在至少 3 个样本中计数 >= 10)
keep <- rowSums(counts(dds) >= 10) >= 3
dds <- dds[keep, ]

# 3. 运行端到端 DESeq 差异表达分析管线
dds <- DESeq(dds)

# 4. 提取差异检验结果 (设定对比组合与 FDR 阈值)
res <- results(dds, contrast = c("Treatment", "Drought", "Control"), alpha = 0.05)

# 5. 执行效应量收缩 (LFC Shrinkage, 推荐 apeglm 算法)
res_shrink <- lfcShrink(dds, coef = "Treatment_Drought_vs_Control", type = "apeglm")

# 6. 生成适用于 PCA 与聚类的方差稳定转换表达矩阵 (VST)
vsd <- vst(dds, blind = FALSE)
```

### 5.2 关键参数说明
- `design = ~ Treatment`：广义线性模型设计公式。如包含批次效应可设定为 `~ Batch + Treatment`。
- `type = "apeglm"`：自适应先验收缩算法，优于经典的 `normal` 收缩，能够完美保留显著高表达基因的真实高倍数变化，同时准确收缩背景噪声。
- `blind = FALSE`：在执行 VST 转换时考虑设计矩阵实验变量，避免组间生物学方差被过度平滑消除。
