## 目标与验证状态
本教程按 CAFE5 官方仓库示例组织，帮助检查输入表、物种树、根分布和家族间速率假设。命令依据官方 README 和发行说明核对，尚未在本机执行；教程状态为“命令已核对、真实数据待验证”。官方示例为哺乳动物数据，不代表植物分析结果。应用于植物时应替换为质量一致的植物基因家族计数和对应物种树。

## 环境与数据
CAFE5 官方仓库提供源码、安装说明、教程及示例数据；可从[官方仓库](https://github.com/hahnlab/CAFE5)获取，或使用其 README 列出的 Bioconda 包。安装后记录软件版本、环境文件、输入哈希和运行日志，并以实际版本 `cafe5 -h` 核实参数。

输入包括制表符分隔的家族计数文件，以及 Newick 格式的有根物种树，分支长度应为可解释的时间尺度。计数文件的物种列名必须和树叶名称完全一致，家族 ID 应唯一，计数为非负整数；进入模型前检查注释流程、代表转录本规则和不同物种基因集完整度。示例文件以官方仓库教程对应版本的 `data/` 文件为准，避免混用不同分支的旧版文件。

## 基础命令
在准备好与当前仓库教程相匹配的计数表和树文件后，可按官方 README 格式运行：

```bash
cafe5 -t data/mammals_integral_tree.txt \
  -i data/filtered_cafe_input.txt \
  -p -k 2 -c 4 -o cafe5_results
```

`-t` 指定 Newick 树，`-i` 指定家族 × 物种计数表，`-p` 采用 Poisson 根分布，`-k 2` 设定两个离散 Gamma 速率类别，`-c 4` 设置线程数，`-o` 指定输出目录。`-k` 会改变模型设定；采用前应确认研究设计支持家族间速率差异并检查拟合结果。官方 README 的 `-e` 参数用于估计或载入误差模型，具体写法以安装版本帮助为准。

这里的 `-k 2` 是便于理解参数位置的教学值，不替代模型比较。官方数据文件名和目录可能随发行版调整；先按对应版本教程定位树与过滤后计数表，再执行命令。本教程未在本机运行，未生成或预期任何结果数值。

## 输出检查与解释
CAFE5 1.1 会生成 `Base_report.cafe` 或 `Gamma_report.cafe` 等报告，并按模型写出家族结果、分支概率、λ、模型参数、节点概率和 p 值等表格。核对运行日志、模型类型、输入列顺序、树叶标签及输出报告；随后按官方报告格式或绘图程序检查候选家族。家族扩张/收缩是给定计数和模型下的统计推断，需要结合家族注释、基因树、基因组共线性和注释质量解读。

## 常见错误
- **物种名称不匹配**：逐字符比较树叶名称与计数表列名，包括空格、下划线和大小写。
- **计数异常**：统一每个物种的基因预测、剪接异构体和家族聚类规则，检查极大或缺失家族。
- **误差模型不可用**：确认文件由兼容版本生成，并依据当前 README 的 `-e` 参数格式传入。
- **优化未完成**：检查最大迭代数、树枝长度、根分布与输入；增加迭代前先确认数据和模型设置。
- **过度解释显著家族**：用独立的序列、位置和功能证据进一步验证候选。
