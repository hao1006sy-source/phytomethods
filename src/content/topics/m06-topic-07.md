## 核心科学问题：基因型在动态气候环境中的非线性响应

“良种还需良法配，良种良法生良田”。在作物农业生产中，最优的作物品种往往表现出强烈的地域适应性与年份波动性。同一玉米杂交种在东北早熟春玉米区表现高产稳产，而在黄淮海夏玉米区可能因高温伏旱导致结实率骤降；这种由于基因型在不同环境中表型表现发生非平行变化甚至等级颠倒（Crossover Interaction）的生物学现象，称为**基因型×环境互作（Genotype-by-Environment Interaction, G×E）**。

传统的全基因组选择（GS）模型通常假设标记效应跨环境恒定，这在单一温室或局域单点试验中表现良好，但在面对气候变化加剧、多生态区引种推广与跨年份育种预测时，预测准确度会发生断崖式下跌。

现代智慧育种融合了**环境型组学**（Envirotyping）、**反应规范模型**（Norm of Reaction）与**多组学深度学习**（如 DNNGP），将气候传感器监测的积温、降雨、太阳辐射与土壤理化性质等环境协变量直接纳入模型，从根本上实现了作物在未知未来年份与全新地理生态区的表型精准推演。

## 算法数学推导：多环境混合模型与 Kronecker 积

### 1. 经典多环境 GBLUP 混合模型与 Kronecker 积协方差结构

设育种试验包含 $n$ 个植物基因型，在 $E$ 个不同试验地点或年份进行种植鉴定。总观测样本数为 $N = n \times E$。

建立整合主效应与 G×E 互作效应的多环境混合线性模型：

$$\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \mathbf{Z}_g \mathbf{u}_g + \mathbf{Z}_{ge} \mathbf{u}_{ge} + \boldsymbol{\epsilon}$$

其中：
- $\mathbf{X}\boldsymbol{\beta}$：包含各环境的均值、试验区组等固定效应；
- $\mathbf{u}_g \in \mathbb{R}^n$：跨环境均一的主加性遗传效应向量，$\mathbf{u}_g \sim N(\mathbf{0}, \mathbf{G}\sigma_g^2)$；
- $\mathbf{u}_{ge} \in \mathbb{R}^{nE}$：特定环境下的基因型互作随机效应向量；
- $\boldsymbol{\epsilon} \sim N(\mathbf{0}, \mathbf{R})$：残差向量，$\mathbf{R} = \text{diag}(\mathbf{I}_n \sigma_{e_1}^2, \dots, \mathbf{I}_n \sigma_{e_E}^2)$ 允许不同环境拥有异质残差方差。

**Kronecker 积方差-协方差矩阵**：
Jarquín 等（2014）将环境相似性矩阵 $\boldsymbol{\Omega}_E \in \mathbb{R}^{E \times E}$ 引入模型。互作随机效应 $\mathbf{u}_{ge}$ 的先验方差协方差矩阵服从矩阵克罗内克积（Kronecker Product, $\otimes$）：

$$\text{Var}(\mathbf{u}_{ge}) = (\boldsymbol{\Omega}_E \otimes \mathbf{G}) \sigma_{ge}^2$$

- $\mathbf{G} \in \mathbb{R}^{n \times n}$：基于全基因组 SNP 构建的个体遗传亲缘矩阵；
- $\boldsymbol{\Omega}_E \in \mathbb{R}^{E \times E}$：基于环境气象指标（生长季各生育时期的日均温、积温、累积降水、光合有效辐射 PAR、干旱指数 SPEI 等）构建的环境相似度矩阵：
  $$\boldsymbol{\Omega}_E = \frac{\mathbf{W}\mathbf{W}^T}{p}$$
  其中 $\mathbf{W} \in \mathbb{R}^{E \times p}$ 为标准化的环境协变量矩阵。

通过这一数学构造，模型不仅能够借由 $\mathbf{G}$ 在近缘个体间传递信息，更能借由 $\boldsymbol{\Omega}_E$ 将气候相似地点之间的表型信息进行双向借调，显著提高了极端气候年份的预测能力。

### 2. 深度神经网络多组学基因组预测（DNNGP）

线性混合模型（GBLUP）基于加性遗传假说，难以直接捕捉基因间复杂的高阶上位性互作（High-order Epistasis）以及转录因子非线性调控网络。

DNNGP（Kelin Wang et al., 2023, *Molecular Plant*）提出了一种整合基因组与转录组等多组学数据的深度学习网络架构：
1. **多组学独立输入分支**：
   输入包含全基因组高密度 SNP 矩阵 $\mathbf{X}_{\text{SNP}}$ 与关键组织基因表达谱矩阵 $\mathbf{X}_{\text{RNA}}$，分别送入独立特征提取子网络；
2. **三层一维卷积特征提取（3-layer 1D-CNN）**：
   - 采用 3 层一维卷积（1D-CNN）逐层提取局域特征表示；
   - 卷积层后紧随批量归一化（Batch Normalization）稳定隐层分布，并结合 Dropout 随机失活策略防止高维小样本过拟合；
3. **特征拼接与回归输出**：
   各分支特征展开后经全连接层映射并在融合层进行通道拼接，最终由单神经元线性输出连续型表型预测标量；
4. **软件实现与评估**：
   官方实现基于 Python 3.9 与 TensorFlow 2.6.0，使用 MSE 损失函数与 Adam 优化器，在小麦杂交种产量、玉米自交系性状及拟南芥代谢物等公开数据集上通过十折交叉验证评估预测性能。

## 植物 G×E 育种预测的三大交叉验证范式

在评估考虑 G×E 的基因组预测模型时，必须根据实际育种部署场景严格设计验证分割策略，严防数据泄漏：

```
作物多环境预测三大交叉验证设计：

   验证方案                  训练集构成 (Train)                    测试集目标 (Test)                  育种实际业务场景
─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
   CV1 (新材料预测)         部分材料在所有环境中的表型            全新未测材料在所有环境中的表现      选系早期世代筛选，预测新创制系在各地的表现
   CV2 (未测环境表现)       所有材料在部分环境已测                已知材料在尚未测定环境中的表现      由于旱涝冰雹导致个别测试点绝收，插补缺失数据
   CV0 / CV00 (完全外推)    历史材料在历史环境中的表型            全新未知材料在全新未来环境中的表现  智能设计育种终极考验：预测新组合在未来年份的表现
```

## 经典植物科研案例与前沿进展

1. **玉米全美多环境试验环境设计预测（Genomes to Fields, G2F 计划）**：
   - 在美国覆盖数十个州、横跨 5 年的 G2F 玉米全基因组测试中，研究者利用安装在田间的气象传感器，记录了播种至散粉期、散粉至灌浆期的积温与土壤持水量。在整合了 $G \otimes \Omega_E$ 的反应规范模型后，CV2（预测因故缺失点）的预测准确度由传统 GBLUP 的 $r=0.38$ 跃升至 $r=0.68$。
2. **水稻跨生态区光温反应规范建模**：
   - 水稻作为典型的短日照作物，感光性与感温性基因（如 *Hd1*, *Ghd7*, *DTH8*）在不同纬度日照长度与积温下表达迥异。结合基因型与发育期气温动态模拟，实现了水稻品种北移或南引抽穗期的天级别精准预测。
