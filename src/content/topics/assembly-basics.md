## 研究背景和生物学问题
从头组装（de novo assembly）直接利用样本测序片段推断基因组序列。植物的转座子、相似重复、杂合差异和多倍性会增加候选连接，研究目标决定应保留哪些单倍型及拷贝。

## Reads、contig 和 scaffold
Read 是测序仪读取的片段；contig 是由重叠片段形成的连续序列；scaffold 根据长程证据连接、排序和定向多个 contig，可以包含间隙。染色体级 scaffold 是染色体尺度的序列表示，端粒和着丝粒是否完整需要独立检查。

## 计算思想和步骤
重叠—布局—一致序列（OLC）先查找 reads 间重叠，再确定布局并生成 consensus。de Bruijn 图利用 k-mer 邻接关系表达序列；string graph 精简 reads 的重叠关系。组装器在纠错、图清理和路径选择后生成 contig，Hi-C 等数据可提供跨 contig 的长距离线索。

## 评价与方法比较
N50 与 L50 描述长度分布；BUSCO 使用保守基因集合评估基因空间；k-mer 完整度、QV 和长 reads 回贴提供其他证据。连续性高的结果仍需检查错接、塌缩和碱基错误。Hifiasm 利用高准确度 reads 的相位感知组装图；Verkko 使用多重 de Bruijn 图并可整合超长 reads。

## 植物案例和阅读
[四倍体马铃薯组装](https://doi.org/10.1038/s41588-022-01015-0)展示了多倍体单倍型组装的研究背景。[Hifiasm](https://doi.org/10.1038/s41592-020-01056-5)、[Verkko](https://doi.org/10.1038/s41587-023-01662-6)和[Merqury](https://doi.org/10.1186/s13059-020-02134-9)论文提供方法细节。

## 从序列读段到染色体级表示
组装的基本输入是同一遗传材料中抽样得到的 reads。Contig 表示由读段或其压缩图路径支持的连续碱基序列；Scaffold 在 contig 之间利用 Hi-C、遗传图谱、光学图谱或超长 reads 的跨越证据确定顺序和方向，未知间距常以若干 `N` 表示。染色体级表示描述大尺度排序，不能单独证明所有间隙已关闭。T2T 则通常要求单条染色体从一端端粒连续至另一端，并需要端粒基序、着丝粒及重复区域的独立证据。

常见计算主线可拆成五类决策：读段校正或错误容忍比对；构建重叠图或 k-mer 图；删除错误分支并压缩非分叉路径；依据读段路径、相位信号或长程证据选择图路径；以共识碱基调用形成 contig，再通过长程信息生成 scaffold。实际软件常交替执行图构建、清理和路径解析，而不是单向流水线；中间 GFA 图应保留用于检查被丢弃或歧义的路径。

## OLC、de Bruijn 图与 String Graph
Overlap–Layout–Consensus（OLC）中，overlap 阶段寻找 reads 的可靠后缀—前缀重叠，layout 阶段求取相容的读取顺序，consensus 阶段根据多条 reads 的碱基证据形成共识。传统 OLC 在短读段、高覆盖数据中可能产生庞大重叠集合；索引、种子和过滤策略用于降低候选比对成本。

de Bruijn 图将序列编码为长度为 $k$ 的 k-mer，并以共享 $k-1$ 个碱基形成邻接关系。不同组装器对节点或边的定义不同，判断软件内部算法时需要阅读对应方法论文。小 $k$ 提高低覆盖下的连接性，却容易合并重复；大 $k$ 增强区分能力，却对测序错误和覆盖不足更敏感。String Graph 从读段重叠图出发，压缩传递性冗余边，力求保留必要连接；它并不等同于简单把 reads 首尾相接。现代长读段组装器也会采用混合图或分阶段图算法。

## 连续性指标与常见误读
设 contig 长度降序为 $L_1,\ldots,L_n$，总长 $S=\sum_i L_i$，N50 是使前缀和首次达到或超过 $S/2$ 的 contig 长度；L50 是达到该长度所需的 contig 数。NG50 改用估计基因组大小的一半为阈值。N50 只描述长度分布，错误连接也会提高 N50。BUSCO 评估保守基因是否完整，k-mer 完整度和 QV 提供序列层面的独立证据，Hi-C 与长 reads 可辅助检查结构。报告时应注明 contig/scaffold 层级、过滤规则和分母。

## 植物组装决策示例
对高杂合二倍体，若研究问题涉及等位特异表达或结构变异，保留两套相位路径通常比单一折叠序列更合适；对高自交品系，可侧重高连续性单倍体共识；对异源多倍体，应关注不同亚基因组之间的区分和同源塌缩。四倍体马铃薯工作以多个单倍型组装资源展示了多倍体参考的价值，也说明单一线性参考难以覆盖材料内的等位与结构差异。参见 [Nature Genetics 原文](https://doi.org/10.1038/s41588-022-01015-0)。这些是目标定义的示例，不是物种间通用默认。

## 方法比较与学习路径
短读段 de Bruijn 图在高通量短片段数据上计算效率较高；长读段 OLC/string graph 可直接利用跨越更长重复的分子；HiFi 主导的组装兼顾单分子准确度，HiFi+ONT 的混合方法可利用超长跨越能力。选型时需同时对照 reads 长度和质量、目标倍性、是否要求单倍型分离、计算资源及输出图可解释性。接续阅读[组装图与核心算法](../assembly-graphs/)、[单倍型解析](../haplotype-resolution/)和[组装质量评估](../assembly-quality/)。
