## 核心科学问题：复杂数量性状的变异来源与可遗传度量

在作物科学与植物演化生物学中，大多数具有重要农艺经济价值的性状（如玉米穗行数与株高、水稻千粒重与抽穗期、大豆油分含量与抗旱指数）均表现为受微效多基因调控的连续数量变异（Continuous Quantitative Variation）。

数量遗传学（Quantitative Genetics）的核心使命，在于通过数学建模将宏观可测的表型变异（Phenotypic Variance）严格解构为由不同生物学机制决定的遗传方差（Genetic Variance）、环境方差（Environmental Variance）及其互作分量，并据此估计性状的**遗传力**（Heritability）与**个体基因组估计育种值**（Estimated Breeding Value, EBV），为后续的双亲连锁 QTL 作图、GWAS 关联分析与全基因组育种选择（GS）奠定统计学基石。

## 算法数学推导：方差分解与遗传力推导

### 1. 表型方差的层次正交分解

在经典多环境多重复植物育种田间试验中，个体表型值 $y_{ijkm}$ 可线性分解为：

$$y_{ijkm} = \mu + G_i + E_j + (GE)_{ij} + B_{k(j)} + \epsilon_{ijkm}$$

其中 $\mu$ 为总体均值，$G_i$ 为第 $i$ 个基因型的总遗传效应，$E_j$ 为第 $j$ 个环境（地点或年份）的固定/随机效应，$(GE)_{ij}$ 为基因型与环境互作效应（G×E），$B_{k(j)}$ 为环境 $j$ 内第 $k$ 区组（Block）效应，$\epsilon_{ijkm}$ 为随机田间误差。

在随机化区组设计下，各项效应假定相互独立，全群体表型方差 $V_P$ 满足完全加和性：

$$V_P = V_G + V_E + V_{GE} + V_e$$

### 2. 遗传方差的生物学细分：加性、显性与上位性

根据 Fisher（1918）建立的经典无穷小模型（Infinitesimal Model），基因型总效应 $G$ 可以进一步正交投影至线性加性效应、等位基因内互作（显性）与非等位基因间互作（上位性）：

$$G = A + D + I = A + D + (AA + AD + DD + \dots)$$

$$V_G = V_A + V_D + V_I$$

- **加性遗传方差**（Additive Variance, $V_A$）：等位基因替代对表型的平均线性效应（Average Effect of Allele Substitution, $\alpha$），是亲代向子代直接稳定遗传的核心分量，直接决定了个体的**育种值（Breeding Value, $A$）**；
- **显性遗传方差**（Dominance Variance, $V_D$）：同源染色体上相同位点等位基因间的非线性互作（杂合态偏离纯合态中点值），在减数分裂配子形成中被拆散，不能稳定遗传至下一代；
- **上位性方差**（Epistatic Variance, $V_I$）：不同基因组位点间的非线性互作。

对于双等位位点（等位基因 $A$ 与 $a$ 频率分别为 $p$ 与 $q$），纯合子 $A_1A_1$、杂合子 $A_1A_2$ 与纯合子 $A_2A_2$ 的基因型值分别为 $a$、$d$、$-a$。等位基因替代效应定义为：

$$\alpha = a + d(q - p)$$

单标记的加性方差与显性方差解析式为：

$$V_A = 2pq\alpha^2 = 2pq [a + d(q - p)]^2$$

$$V_D = (2pqd)^2$$

### 3. 广义遗传力与狭义遗传力

基于上述方差分量，定义两大核心遗传度量：

- **广义遗传力**（Broad-sense Heritability, $H^2$）：全部遗传因素在表型变异中所占的比例：
  $$H^2 = \frac{V_G}{V_P} = \frac{V_A + V_D + V_I}{V_P}$$
- **狭义遗传力**（Narrow-sense Heritability, $h^2$）：仅加性遗传方差在表型变异中所占的比例：
  $$h^2 = \frac{V_A}{V_P}$$

**育种响应预测（育种家方程, Breeder's Equation）**：在定向人工表型选择中，选择响应 $R$（下一代平均表型相比亲本群体的增益）由选择差 $S$ 与狭义遗传力直接决定：

$$R = h^2 \cdot S = h^2 (\bar{y}_{selected} - \bar{y}_{population})$$

### 4. 植物自交系统对加性遗传方差的倍增效应

植物中普遍存在自花授粉（如水稻、大豆、拟南芥、小麦）。连续自交导致杂合子比例以 $1/2^t$ 迅速趋于零，群体完全纯合化。

在完全纯合的近交系群体中，显性方差 $V_D \to 0$。设纯合系由初始随机交配群体经无重组单粒传衍生而来，其自交系群体间的加性遗传方差翻倍：

$$V_{A(inbred)} = 2 V_{A(random)}$$

**数学证明简述**：纯合系仅包含 $A_1A_1$（频数 $p$，效应 $a$）与 $A_2A_2$（频数 $q$，效应 $-a$），均值为 $(p-q)a$。其方差为 $p[a - (p-q)a]^2 + q[-a - (p-q)a]^2 = 4pq a^2$。而在原始随机群体中 $d=0$ 时 $V_{A(random)} = 2pq a^2$，故 $V_{A(inbred)} = 2 V_{A(random)}$。这意味着自交作物培育纯系能显著放大加性遗传变异并提高选择效率。

### 5. 品系均值遗传力（Entry-Mean Heritability）

在作物多地点（$L$ 地点）、多年份（$Y$ 年份）及 $r$ 次重复田间试验中，育种家通常以**品系均值**（Entry-mean）作为选择单位。此时随机田间残差被均值平均化缩小，品系均值广义遗传力表达式为：

$$H^2_{entry} = \frac{\sigma_g^2}{\sigma_g^2 + \frac{\sigma_{gl}^2}{L} + \frac{\sigma_{gy}^2}{Y} + \frac{\sigma_{gly}^2}{L \cdot Y} + \frac{\sigma_e^2}{r \cdot L \cdot Y}}$$

## 植物育种数据分析实践：BLUE 与 BLUP 的抉择

在基于混合线性模型（LMM）处理不平衡田间表型数据时，存在两种截然不同的核心估计量：

```
表型数据分析策略抉择：

                        表型观测数据 y
                              │
               ┌──────────────┴──────────────┐
               ▼                             ▼
       固定效应模型 (Fixed)          随机效应模型 (Random)
               │                             │
    求解加权最小二乘法 (GLS)        求解混合模型方程组 (MME)
               │                             │
               ▼                             ▼
    最佳线性无偏估计 (BLUE)        最佳线性无偏预测 (BLUP)
    • 无任何遗传方差先验收缩       • 向总体均值发生经验贝叶斯收缩
    • 保留真实品种间绝对水平       • 降低大方差与小样本极端误差
    • 【下游场景】：GWAS 表型输入   • 【下游场景】：育种值排名与 GS 候选淘汰
```

## 经典植物科研案例与文献证据

1. **玉米穗位高与株高经典数量遗传学分析**：
   - Hallauer 等在长期玉米杂交育种试验中，系统测定了北美玉米群体的方差分量。在完全自交系中，玉米株高的狭义遗传力通常可达 $h^2 \approx 0.70 \sim 0.85$，而单株籽粒产量的狭义遗传力往往仅为 $h^2 \approx 0.20 \sim 0.35$，主要受显著的显性杂种优势与强烈 G×E 互作稀释。
2. **水稻 517 份地方品种与遗传力评估实践**：
   - Huang 等（2010, Nature Genetics）对 517 份中国水稻地方品种进行基因组重测序，对千粒重（Grain Weight）、落粒性（Seed Shattering）等性状开展全基因组方差分解，证实千粒重在不同环境下具有极高的遗传力（$H^2 > 0.80$），因而能在随后的 GWAS 中精准定位到主效基因 *GW5* 与 *GS3*。
