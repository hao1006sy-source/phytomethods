## 核心科学问题：从单点随机波动到功能调控区域

在全基因组重亚硫酸氢盐测序（WGBS）数据分析中，研究者常常获得数千万个胞嘧啶位点的单碱基甲基化水平。然而，单个胞嘧啶位点由于测序深度的局部随机抽样波动，其甲基化读数存在极大的统计噪音，孤立的单个差异位点（Differentially Methylated Cytosine, DMC）往往不具备稳定的生物学转录调控功能。

真正主导植物顺式元件激活、转录因子结合位点封闭以及转座子可逆沉默的，是染色体局部物理空间上由数十至数百个胞嘧啶构成的**差异甲基化区域（Differentially Methylated Region, DMR）**。

如何在生物学重复有限（通常仅 2~3 个重复）、测序深度严重不均匀以及相邻胞嘧啶存在强烈空间自相关的真实实验约束下，严谨识别出统计可信的生物学 DMR，是表观基因组学的核心挑战。

## 算法数学推导：Beta-二项经验贝叶斯与 DSS 算法

### 1. 经典二项分布的局限与过离散（Over-dispersion）现象

在单样本中，第 $i$ 个胞嘧啶位点的甲基化 Reads 数 $Y_i$ 理论上服从以总覆盖深度 $N_i$ 和真实甲基化概率 $p_i$ 为参数的二项分布：$Y_i \sim \text{Binomial}(N_i, p_i)$。此时方差完全由均值决定：$\text{Var}(Y_i) = N_i p_i (1 - p_i)$。

但在包含多个生物学重复个体的真实试验中，由于植株个体间微环境差异、细胞异质性以及生理状态波动，不同重复样本之间的真实甲基化概率 $p_{ij}$ 本身就是一个随机变量。若机械采用二项检验或 Fisher 精确检验，会完全忽略样本间的生物学变异（Biological Variance），导致方差被严重低估，产生极其严重的**过离散（Over-dispersion）假阳性**。

### 2. Beta-二项分布分层模型（Beta-Binomial Hierarchical Model）

DSS（Feng, Conneely & Wu, 2014, Nucleic Acids Research）采用了分层贝叶斯架构解决过离散问题：

设第 $i$ 个位点在处理组/对照组的第 $j$ 个生物学重复样本中，总覆盖 Reads 为 $N_{ij}$，甲基化 Reads 为 $Y_{ij}$。
1. **第一层（测序抽样误差）**：给定该样本的真实甲基化概率 $p_{ij}$，甲基化计数服从二项分布：
   $$Y_{ij} \mid p_{ij} \sim \text{Binomial}(N_{ij}, p_{ij})$$
2. **第二层（生物学重复间变异）**：真实甲基化概率 $p_{ij}$ 在群体中服从 Beta 分布：
   $$p_{ij} \sim \text{Beta}(\alpha_i, \beta_i)$$
   参数化为均值 $\mu_i = \frac{\alpha_i}{\alpha_i + \beta_i}$ 与**生物学离散度参数（Biological Dispersion, $\phi_i$）**：
   $$\phi_i = \frac{1}{\alpha_i + \beta_i + 1}$$

整合后的边际分布为 Beta-二项分布，其均值与方差解析式为：

$$E(Y_{ij}) = N_{ij} \mu_i$$

$$\text{Var}(Y_{ij}) = N_{ij} \mu_i (1 - \mu_i) \left[ 1 + (N_{ij} - 1)\phi_i \right]$$

项 $[1 + (N_{ij} - 1)\phi_i]$ 即为**过离散膨胀因子**。当生物学变异 $\phi_i = 0$ 时退化为标准二项分布；当生物学变异存在时，方差被合理放大，彻底排除了假阳性。

### 3. 经验贝叶斯离散度参数收缩（Empirical Bayes Dispersion Shrinkage）

在植物科研实践中，高成本的 WGBS 通常仅有 $n = 2 \sim 3$ 个生物学重复。在极小样本下，直接通过极大似然法（MLE）对单个位点估计离散度 $\phi_i$ 极度不稳定，方差极大。

DSS 引入了**经验贝叶斯收缩（Empirical Bayes Shrinkage）**：
- 假定全基因组数千万个位点的对数离散度 $\ln \phi_i$ 服从一个共同的正态先验分布：
  $$\ln \phi_i \sim N(\mu_0, \tau^2)$$
- 先验超参数 $\mu_0$ 与 $\tau^2$ 直接通过全基因组所有位点的数据通过边际最大似然经验估计；
- 计算每个位点的后验均值作为收缩后的离散度估值 $\tilde{\phi}_i$：将极端不稳定的大方差单点估计向全基因组的先验均值方向进行适度收缩（Shrinkage）；
- 这一数学处理赋予了小样本数据极高的统计稳健性，在仅有 2 个生物学重复时依然保持极高的检测功效（Statistical Power）。

### 4. 空间平滑移动窗口（Spatial Moving Average Smoothing）

真核生物染色体上的 DNA 甲基化呈现强烈的局部空间连续性（相邻相距几十碱基的胞嘧啶往往协同被同一个甲基转移酶催化）。

DSS 利用核加权空间平滑移动窗口（Spatial Smoothing），利用候选位点物理邻域内的相邻胞嘧啶 Reads 计数进行空间加权平均，进一步压制测序随机深度波动引入的局部单点噪音。

### 5. Wald 统计检验与 DMR 区域合并算法

在获得平滑后的组均值 $\hat{\mu}_{i, 1}$、$\hat{\mu}_{i, 2}$ 及其标准误后，构建两样本 **Wald 检验统计量**：

$$W_i = \frac{\hat{\mu}_{i, 1} - \hat{\mu}_{i, 2}}{\sqrt{\text{SE}(\hat{\mu}_{i, 1})^2 + \text{SE}(\hat{\mu}_{i, 2})^2}} \sim N(0, 1)$$

计算单点 $p$ 值并执行 FDR 校正。随后执行区域合并（DMR Calling）：
1. 筛选出单点显著且甲基化绝对差异超过阈值的候选位点；
2. 若相邻两个显著差异位点之间的物理距离小于预设步长（如植物中通常设为 $\le 100 \sim 200 \text{ bp}$），且差异方向严格一致（同为超甲基化 Hyper 或同为去甲基化 Hypo），则将二者合并为同一连续区域；
3. 计算该连续区间的加权平均甲基化差异与区间整合检验 $p$ 值。

## 植物特有三大序列环境 DMR 判定阈值标准

由于植物不同序列环境的基线甲基化水平悬殊，**绝不能套用动物单一的 CG 过滤标准**，必须按序列通道分别设定阈值：

```
植物三大序列环境 DMR 标准判定参数矩阵：

DMR 类别     基因组基线水平   最小绝对差异阈值 (ΔML)   最少包含位点数   推荐合并最大间距 (Gap)
─────────────────────────────────────────────────────────────────────────────────────────────
CG-DMR       ~ 20% ~ 40%      |ΔML| ≥ 40% (0.40)       ≥ 4~5 个 CpG     ≤ 100 bp
CHG-DMR      ~ 5% ~ 15%       |ΔML| ≥ 20% (0.20)       ≥ 3~4 个 CHG     ≤ 150 bp
CHH-DMR      ~ 1% ~ 5%        |ΔML| ≥ 10% (0.10)       ≥ 5~10 个 CHH    ≤ 200 bp (富集区滑动窗口)
```

## 经典植物科研案例与证据链

1. **六倍体普通小麦亚基因组特异性 DMR（Gardiner et al., 2015, Genome Biology）**：
   - 面对小麦高达 16 Gb 的超大异源六倍体基因组，研究者利用外显子捕获亚硫酸氢盐测序，结合 DSS 空间模型鉴定了 A、B、D 三个同源亚基因组间的上万个特异性 DMR。研究揭示转座子插入密集的同源基因启动子区出现剧烈的 CHG/CHH 超甲基化，与特定亚基因组同源拷贝（Homeolog）的长期转录表达沉默高度共分离。
2. **植物高温逆境胁迫下转座子去甲基化与激活**：
   - 拟南芥与水稻在经历持续高温胁迫后，全基因组水平出现数千个特异性的 CHH 低甲基化区域（Hypo-DMR）。这些 DMR 特异性富集在 Copia 类逆转录转座子（LTR-RT）的长末端重复序列区域，导致沉睡转座子发生瞬时转录爆发并产生大量染色体外染色体环状 DNA（eccDNA）。
