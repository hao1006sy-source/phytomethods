## 核心科学问题与图论建模本质

从头基因组组装（*De novo* genome assembly）的核心任务，是从海量带有测序误差、长度有限的重叠读段（reads）中，数学重构出生物体真实的染色体线性多聚核苷酸链。对于植物基因组学而言，这一任务尤为艰巨：被子植物广泛经历过单次或多次全基因组加倍事件（Whole-Genome Duplication, WGD），伴随着转座子（尤其是反转录转座子 LTR-RT）的爆发式扩增，导致基因组内充斥着海量高相似度旁系同源序列、串联卫星重复以及极高的杂合性。

在计算生物学中，线性序列的重构无法直接通过简单的逐一比对拼接实现，必须抽象为图论（Graph Theory）中的路径遍历问题。测序数据中的碱基序列被抽象为图的节点（Nodes）或边（Edges），序列间的物理重叠或 $k$-mer 共享关系被抽象为连接边，而最终的组装结果对应于图上满足特定生物学约束的连续遍历路径。

## 三大图论模型的数学推导与计算复杂性

在现代生物信息学的发展历程中，形成了三大主流的图装配范式，其底层数据结构、数学定义与计算复杂度各具鲜明边界：

### 1. 重叠—布局—共识图（OLC / Overlap Graph）

OLC 是长读段测序时代最为自然的直觉模型。

- **顶点与边定义**：每个测序 read 作为一个顶点 $v \in V$。若读段 $u$ 的后缀与读段 $v$ 的前缀存在长度大于等于设定阈值 $\theta$、且序列一致性高于阈值 $\sigma$ 的局部联配，则在 $u$ 与 $v$ 之间引入一条有向边 $e = (u, v) \in E$，边的权重通常赋予重叠长度或编辑距离。
- **目标路径遍历**：理想情况下，重组原染色体序列等价于在 OLC 图中寻找一条访问每个顶点恰好一次的有向路径，即**哈密顿路径（Hamiltonian Path）**。
- **计算瓶颈**：在理论计算机科学中，求取一般有向图中的哈密顿路径被证明为 **NP-完全问题（NP-complete）**。此外，若测序深度为 $C$、读段数为 $N$，两两比对的时间复杂度在朴素算法下高达 $O(N^2)$，在高覆盖短读段数据上计算代价极其昂贵。

### 2. 德布鲁因图（de Bruijn Graph, DBG）

为了克服 OLC 在短读段海量数据下的复杂度瓶颈，以 Pevzner 等人为代表的研究者引入了基于固定长度字串的 de Bruijn 图。

- **顶点与边定义**：将全部读段分解为长度为 $k$ 的连续子串（$k$-mer）。图中每个顶点 $v \in V$ 代表一个去重后的 $(k-1)$-mer；若某读段中出现 $k$-mer $s = a_1 a_2 \dots a_k$，则在顶点 $u = a_1 \dots a_{k-1}$ 与顶点 $v = a_2 \dots a_k$ 之间引入一条有向边 $e = (u, v) \in E$。
- **目标路径遍历**：与 OLC 恰恰相反，在 DBG 中重构序列等价于遍历图中每条边恰好一次，即寻找一条**欧拉路径（Eulerian Path）**。
- **计算优势与缺陷**：欧拉路径的存在性可通过检验图的入度与出度平衡（欧拉定理）在 **线性时间 $O(|V| + |E|)$** 内严格求解，计算效率极其优异。然而，DBG 的致命缺陷在于丢失了长分子的跨越长程关联：任何大于 $k-1$ 长度的重复序列都会导致图中的多条边汇聚至同一个顶点，引发路径拓扑歧义（Eulerian tours 组合爆炸）。

### 3. 极小弦图（String Graph）与传递边约简

2005 年，Gene Myers 提出了现代长读段组装图的理论基石——String Graph。它从根本上解决了传统 OLC 图中由于测序深度增加导致的边集合二次方膨胀问题。

#### Myers 传递边约简定理（Transitive Reduction）

设 $G = (V, E)$ 为一个有向无环或局部无环的读段重叠图。如果图中存在一条有向边 $(u, v) \in E$，同时存在一条长度大于等于 2 的替代路径 $P = (u, w_1, w_2, \dots, w_m, v)$（其中 $m \ge 1$ 且所有中间顶点 $w_i \in V$），并且重叠偏移量满足相容条件：

$$\text{shift}(u, v) = \text{shift}(u, w_1) + \sum_{i=1}^{m-1} \text{shift}(w_i, w_{i+1}) + \text{shift}(w_m, v)$$

则直接重叠边 $(u, v)$ 在拓扑与序列信息上是完全冗余的，可以且必须从图中严格消除。

约简后的 String Graph 具有如下关键性质：
1. **线性规模边数**：图中的边数上限直接降为与基因组大小和读段数目线性相关，彻底消除了冗余传递边；
2. **读段悬挂区（Overhang）保持**：每条边精确对应其后续读段超出前一读段的不可约非重叠碱基序列片段；
3. **无缝 Unitig 压缩**：所有入度为 1 且出度为 1 的内部线性非分叉节点链，均可被确定性折叠压缩为一个单一的 **Unitig**，大幅度简化了图拓扑。

## 典型图拓扑结构与生物学解歧算法

在实际植物测序构建的组装图中，由于测序误差、杂合位点与基因组固有重复，图拓扑会展现出若干经典子结构。现代组装算法必须运用严格的拓扑判据与统计检验进行决策：

### 1. 杂合气泡（Bubble）与等位分离检验

气泡是指图中由源节点 $S$ 发散、经过多条互不相交的局部内部路径后，重新汇聚于汇节点 $T$ 的闭合子图：

- **二项分布等位检验**：对于二倍体杂合植物，若分支 $P_1$ 与 $P_2$ 分别代表两条同源染色体上的真实等位变异（如 SNP 或 InDel），在测序无系统偏差时，覆盖在分支 $P_1$ 上的读段数 $n_1$ 与覆盖在 $P_2$ 上的读段数 $n_2$ 应服从参数 $p = 0.5$ 的二项分布：

$$P(n_1 \mid n_1 + n_2) = \binom{n_1 + n_2}{n_1} (0.5)^{n_1 + n_2}$$

若 $n_1$ 与 $n_2$ 的比例在置信区间内（通常均接近单倍体半测序深度，如 $15\times$），组装器（如 Hifiasm）将其标记为**等位气泡（Allelic Bubble）**，在输出单倍型感知图（GFA）中分别保留两条单倍型路径。

- **虚假测序错误气泡剪除**：若其中一条分支的覆盖深度极端低下（如 $n_1 \le 2$ 且仅由单条低质量读段支撑），则其显著偏离二项分布原假设，算法将其判定为由随机测序错误引起的虚假分支，执行路径剪枝（Popping）。

### 2. 盲端死枝（Tips）与剪除条件

死端分支是指仅在某一端与主图连通、另一端悬空的短分支。通常由读段末端的低质量碱基、嵌合体分子或覆盖断崖引起。算法设定阈值（如分支长度小于设定阈值 $L_{\text{tip}}$ 且覆盖度低于平均水平），直接将其从图中剪除。

### 3. 串联重复漩涡（Whirls）与同源塌陷

当基因组中存在串联重复序列（Tandem Repeats）或反向重复时，图中的边会形成自环或微回路。若读段分子无法完全跨越该重复阵列并锚定至两侧独特的纯合序列，算法无法解析出确切的串联拷贝数，往往造成组装序列的长度塌陷（Collapse）。此时必须引入跨越能力更强的超长读段（ONT Ultra-long reads）提供长程路径约束。

## 主流软件底层图算法对比：Hifiasm vs Verkko

| 比较维度 | Hifiasm (Cheng et al., 2021) | Verkko (Rautiainen et al., 2023) |
| :--- | :--- | :--- |
| **底层核心图模型** | 相位感知 String Graph（基于 HiFi 读段全联配） | 多重 de Bruijn 图（MBG）+ 读段对齐图 |
| **同聚物处理策略** | 同聚物压缩空间（Homopolymer-compressed space）联配 | 同聚物压缩 $k$-mer 图拓扑折叠 |
| **单倍型分相机制** | 内部构建气泡链，支持 Hi-C 物理互作与 Trio 亲本特异 $k$-mer | 图路径准联配（GraphAligner）+ Hi-C/Trio 分相 |
| **超长读段结合模式** | 主要面向 HiFi，最新版本实验性支持 ONT 辅助 | 专为 HiFi 与 ONT Ultra-long 混合深度设计 |
| **输出格式标准** | 标准 GFA1 格式（含 `S` 节点、`L` 边、`A` 单倍型路径标注） | GFA 拓扑图、Scaffold 路径与缺口闭合报告 |
| **植物科学首选场景** | 二倍体及多倍体高杂合作物首选（水稻、玉米、马铃薯等） | 着丝粒、端粒及 rDNA 复杂区段 T2T 闭合的首选工具 |

## 植物科研典型实战挑战

1. **超高转座子富集（如玉米 Zea mays）**：玉米 B73 基因组中转座子占比超过 75%，主要为数万至数十万拷贝的 Gypsy 和 Copia 家族 LTR-RT。短片段即使在 String Graph 中也会因完全一致的 LTR 末端产生极度密集的交叉错结。必须保证 HiFi 读长平均分布在 15~20 kb 以上，使单分子能够横跨一个完整的 5~10 kb LTR 单元并延伸至侧翼单拷贝基因区。
2. **同源异型多倍体亚基因组串扰（如六倍体小麦 Triticum aestivum）**：小麦包含 A、B、D 三个高度同源的亚基因组，其同源基因编码区的一致性常高达 95%~99%。组装器参数必须极其严格，防止将真实的亚基因组同源物（Homeologs）误判定为等位杂合气泡而强行折叠。
