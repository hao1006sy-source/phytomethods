## 研究问题
测序 reads 是基因组的片段，组装的目标是从这些片段推断连续序列。重复序列、测序错误与单倍型差异会使片段之间的连接出现歧义。

## 基本概念
Contig 是连续组装序列；scaffold 使用额外证据将 contig 排序定向。组装图表示序列及其可行连接，分叉对应多个候选路径。

## 核心原理
OLC 先寻找 reads 之间的重叠，再构建图并推断一致序列。de Bruijn 图把序列分割为长度为 k 的片段，用相邻关系表达连接；string graph 则通过精简重叠关系表示路径。图中路径的选择需要考虑覆盖度、序列一致性及长距离证据。

## 植物基因组挑战
植物基因组可能含有丰富转座子、近期复制和高杂合度，长而相似的重复区可形成难以判断的分叉。长 reads 可以连接部分重复区，多倍体同源序列仍需要专门的相位策略。

## 方法与阅读
[Hifiasm](../../../methods/hifiasm/) 使用相位感知组装图；[Verkko](../../../methods/verkko/) 综合不同长读长数据。请结合原始方法论文理解各工具的数据要求。

## 生物学背景与数据准备
一个 reads 集合包含同源染色体、重复片段与测序误差的混合信号。覆盖度是测序总碱基数与估计基因组大小之比；覆盖不足会造成断裂，覆盖异常也可能提示污染、重复或倍性差异。组装前应检查 reads 长度、准确率和样本来源。

## 三类图怎样构造
OLC 通过寻找 reads 之间的后缀—前缀重叠建立候选连接，布局后由多条 reads 形成一致序列。长 reads 能跨越较长的重复序列，寻找大量重叠需要高效的候选检索与比对。

de Bruijn 图将 reads 切分为 k-mer，通过共享 k−1 个碱基连接相邻片段；实际实现对节点和边的定义可能不同。k 较小时连接更稳健、重复更易合并；k 较大时区分能力提高，对覆盖和错误也更敏感。现代变体可使用不同长度的信息解析复杂结构。

String graph 从 reads 的重叠关系出发，去除可由其他路径解释的传递边，保留用于表达连接的信息。图简化后仍需依据序列、覆盖和跨越证据决定候选路径。测序错误与杂合差异都可能形成分叉，处理时需要区分错误、重复和真实变异。

## 方法差异与植物应用
Hifiasm 以 HiFi 数据构建相位感知的重叠组装图；Verkko 使用高准确度 reads 的多重 de Bruijn 图，并可用 ONT 超长 reads 逐步解析复杂连接。两者的数据要求和图结构不同，实际表现取决于数据质量和目标基因组，研究者应比较相同输入条件下的连续性、准确率与相位质量。

植物中重复转座子和近期全基因组复制可能产生相似路径。跨越重复区的超长 reads、Hi-C 与亲本数据可提供互补证据；组装图上的分叉需要结合比对和覆盖信息解读。[Macadamia jansenii 基因组研究](https://doi.org/10.1111/tpj.15583)提供植物长读长组装案例，请以原文方法为准。
