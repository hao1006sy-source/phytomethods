## 研究问题
测序 reads 是基因组的片段，组装的目标是从这些片段推断连续序列。重复序列、测序错误与单倍型差异会使片段之间的连接出现歧义。

## 基本概念
Contig 是连续组装序列；scaffold 使用额外证据将 contig 排序定向。组装图表示序列及其可行连接，分叉对应多个候选路径。

## 核心原理
OLC 先寻找 reads 之间的重叠，再构建图并推断一致序列。de Bruijn 图把序列分割为长度为 k 的片段，用相邻关系表达连接；string graph 则通过精简重叠关系表示路径。图中路径的选择需要考虑覆盖度、序列一致性及长距离证据。

## 植物基因组挑战
植物基因组可能含有丰富转座子、近期复制和高杂合度，长而相似的重复区可形成难以判断的分叉。长 reads 可以连接部分重复区，多倍体同源序列仍需要专门的相位策略。

## 生物学背景与数据准备
一个 reads 集合包含同源染色体、重复片段与测序误差的混合信号。覆盖度是测序总碱基数与估计基因组大小之比；覆盖不足会造成断裂，覆盖异常也可能提示污染、重复或倍性差异。组装前应检查 reads 长度、准确率和样本来源。

## 三类图怎样构造
OLC 通过寻找 reads 之间的后缀—前缀重叠建立候选连接，布局后由多条 reads 形成一致序列。长 reads 能跨越较长的重复序列，寻找大量重叠需要高效的候选检索与比对。

de Bruijn 图将 reads 切分为 k-mer，通过共享 k−1 个碱基连接相邻片段；实际实现对节点和边的定义可能不同。k 较小时连接更稳健、重复更易合并；k 较大时区分能力提高，对覆盖和错误也更敏感。现代变体可使用不同长度的信息解析复杂结构。

String graph 从 reads 的重叠关系出发，去除可由其他路径解释的传递边，保留用于表达连接的信息。图简化后仍需依据序列、覆盖和跨越证据决定候选路径。测序错误与杂合差异都可能形成分叉，处理时需要区分错误、重复和真实变异。

## 方法差异与植物应用
Hifiasm 以 HiFi 数据构建相位感知的重叠组装图；Verkko 使用高准确度 reads 的多重 de Bruijn 图，并可用 ONT 超长 reads 逐步解析复杂连接。两者的数据要求和图结构不同，实际表现取决于数据质量和目标基因组，研究者应比较相同输入条件下的连续性、准确率与相位质量。

植物中重复转座子和近期全基因组复制可能产生相似路径。跨越重复区的超长 reads、Hi-C 与亲本数据可提供互补证据；组装图上的分叉需要结合比对和覆盖信息解读。[Macadamia jansenii 基因组研究](https://doi.org/10.1111/tpj.15583)提供植物长读长组装案例，请以原文方法为准。

## 图的对象与数据含义
组装图将序列关系转成节点和边。节点可能是读段、k-mer、unitig 或经过压缩的序列片段；边表示允许的重叠、相邻 k-mer 或跨越关系。阅读图时先确认软件采用的图定义、节点方向、边重叠字段和路径命名，再解释分叉。GFA 中 `S` 记录片段，`L` 记录连接，`P` 记录路径；具体字段与版本遵循 GFA 规范和软件说明。

## 从 reads 到图路径的步骤
一个抽象的长读段流程包括：为 reads 建立种子索引并找候选重叠；比对并估计重叠方向、长度与一致性；把可靠重叠转为有向图边；压缩内部只有单一路径的节点为 unitig；针对低支持错误边、短 tips、bubble 和重复路径进行图清理；利用读段跨越关系、覆盖、亲本来源等证据挑选路径；在路径上汇集碱基证据生成共识。每一步都可能因过度清理而丢失真实等位路径，或因保留错误边而产生碎片。

de Bruijn 图的核心关系是相邻 k-mer：长度 $k+1$ 的片段产生两个相邻 $k$-mer，前一个的后缀与后一个的前缀重合 $k-1$ 个碱基。读段错误会生成低支持的旁支；真实杂合位点可形成两条被两侧序列共享的路径；重复序列则会使多个上下游路径共享同一图段。单看“气泡”不能决定它是变异还是错误，需要检查支持 reads、等位覆盖和长距离连接。

## 三种组装思想的技术边界
| 思路 | 主要建模对象 | 优势 | 主要风险与计算负担 |
| --- | --- | --- | --- |
| OLC | reads 间重叠 | 直接保留长分子连接关系 | 高覆盖时重叠候选和图规模大，错误重叠会产生复杂分叉 |
| de Bruijn 图 | k-mer 邻接 | 短读段高覆盖数据可紧凑表示 | k 选择影响重复解析，错误 k-mer 与重复压缩需处理 |
| String Graph | 去冗余的 reads 重叠关系 | 以路径保留必要连接并减少传递边 | 对重叠检测准确度与重复区路径判断敏感 |

实际软件会组合这些构件。Hifiasm 方法以 HiFi reads 解析相位感知的重叠图；Verkko 先从 HiFi 建立 multiplex de Bruijn graph，再将超长 ONT reads 的跨越信息映射到图结构中逐步解决复杂连接。二者都不是上述概念的纯教科书实现；请将图的理论表示与软件具体工作流区分。

## 图简化与路径选择
图简化通常先压缩非分叉线性路径，再依据支持度、序列相似性和读段一致性识别低可信边。Bubble 结构常由共享入口与出口之间的两条候选路径组成。若其变异由多个 reads 联合跨越，且每条路径获得一致支持，可能对应真实等位序列；若某支仅由单条低质量 read 支持，可能是错误分支；若分支包含长重复且两侧无唯一锚点，证据仍不足以唯一确定路径。算法参数会改变这些判断的灵敏度，需通过版本文档、图文件和覆盖轨迹解释。

## 植物研究中的图审阅
植物的近期全基因组复制、串联重复、转座子家族及多倍体同源关系会共同扩大图分支。对可疑断点，应结合 GFA 路径、read 回贴覆盖、k-mer copy number、亲本或 Hi-C 支持检查。Macadamia jansenii 项目报告了多个染色体由大 contig 表示，残余难点与重复区域相关，可作为真实植物长读段组装的上下文案例，但不应将其图结构直接外推到其他物种。[原论文](https://doi.org/10.1111/tpj.15583)。
