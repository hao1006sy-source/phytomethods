## 评价目标与数据层次

在植物基因组学研究中，“获得基因注释文件（GFF3/GTF）”仅仅是第一步。低质量的基因注释充斥着**假阳性基因模型**（如嵌合转座子、非编码转录噪声）、**假阴性缺失**（未预测出低表达或发育特异性基因）、**嵌合基因模型**（Chimeric Genes，将相邻的两个独立基因融合成一个）以及**截短断裂模型**（Fragmented Genes）。这些结构缺陷会直接扭曲后续的比较基因组学正交同源聚类、全基因组复制（WGD）推断、正选择压力检测（$K_a/K_s$ 分析）以及差异表达定量。

因此，**基因组注释质量评估**（Annotation Quality Assessment）必须在独立于预测流程的前提下，从结构准确性、转录/蛋白实验证据支持度、保守直系同源完整性及基因组学特征分布等多个正交维度开展系统审查。

## 核心评估指标与数学模型

评估基因组注释质量的指标可分为两大范畴：**有黄金参考标准下的分类准确度指标**，以及**无标准答案（De Novo 场景）下的证据驱动一致性指标**。

### 1. 结构预测准确性的金标准数学度量
在模式植物（如拟南芥 Col-0、水稻 Nipponbare）或具有高置信度人工校对（Manual Curation）金标准基因集的场景中，预测基因模型与真实模型的比较在不同层次（碱基、外显子、转录本）进行：

| 评估层次 | 真阳性 (TP) 定义 | 假阳性 (FP) 定义 | 假阴性 (FN) 定义 |
| :--- | :--- | :--- | :--- |
| **碱基级（Nucleotide）** | 预测为编码且参考确为编码的碱基数 | 预测为编码但参考为非编码的碱基数 | 参考为编码但预测为非编码的碱基数 |
| **外显子级（Exon）** | 起始与终止物理坐标**完全精确吻合**的外显子数 | 预测存在但参考中无坐标完全吻合的外显子数 | 参考中存在但预测未完全精确检出的外显子数 |
| **转录本级（Transcript）** | 全部内部剪接供体/受体位点完全一致的模型数 | 预测存在但内部剪接链与参考不符的模型数 | 参考中存在但未被完全正确重构的模型数 |

基于混淆矩阵，计算以下核心统计量：
- **敏感性（Sensitivity / Recall, $Sn$）**：
  
  $$Sn = \frac{TP}{TP + FN}$$

- **特异性 / 阳性预测值（Specificity / Precision, $Sp$）**：
  
  $$Sp = \frac{TP}{TP + FP}$$

- **调和平均数（$F_1$ Score）**：
  
  $$F_1 = \frac{2 \cdot Sn \cdot Sp}{Sn + Sp} = \frac{2 \cdot TP}{2 \cdot TP + FP + FN}$$

- **马修斯相关系数（Matthews Correlation Coefficient, $MCC$）**（特别适用于碱基级别评估，有效校正基因组中非编码区与编码区样本极度不平衡问题）：
  
  $$MCC = \frac{TP \cdot TN - FP \cdot FN}{\sqrt{(TP + FP)(TP + FN)(TN + FP)(TN + FN)}}$$

### 2. 注释编辑距离（Annotation Edit Distance, AED）
在绝大多数非模式植物全基因组测序中，并不存在已知的黄金标准基因集。此时，广泛使用由 Eilbeck 等人提出并在 MAKER 与 Mikado 流程中核心采用的**注释编辑距离（AED）**。

AED 综合度量了预测基因模型（Prediction, $P$）与所有外部同源蛋白比对及转录本比对重构证据（Evidence, $E$）在重叠与剪接边界上的一致性。设某个基因模型包含的外显子集合为 $E_{\text{pred}}$，支持该位点的外部转录/同源证据外显子集合为 $E_{\text{est}}$：

$$AED = 1 - \frac{1}{2} \left( \frac{|E_{\text{pred}} \cap E_{\text{est}}|}{|E_{\text{pred}}|} + \frac{|E_{\text{pred}} \cap E_{\text{est}}|}{|E_{\text{est}}|} \right)$$

其中：
- $\frac{|E_{\text{pred}} \cap E_{\text{est}}|}{|E_{\text{pred}}|}$ 为证据对预测模型的敏感度（Fraction of prediction covered by evidence）；
- $\frac{|E_{\text{pred}} \cap E_{\text{est}}|}{|E_{\text{est}}|}$ 为证据对预测模型的特异度（Fraction of evidence covered by prediction）；
- **AED 取值范围严格为 $[0, 1]$**：
  - $AED = 0$：预测的每一个外显子与外部转录本/蛋白证据发生**完美的物理坐标对齐**；
  - $AED < 0.2$：预测模型获得了极其充分且高度精确的外部实验证据支持（高质量黄金核心集合）；
  - $AED < 0.5$：预测模型至少有一半以上的外显子边界与外部证据吻合；
  - $AED = 1$：预测模型**完全缺乏任何外部转录或同源证据支持**（纯粹依靠 Ab Initio 算法预测，假阳性风险极高）。

**AED 累积频率分布曲线（Cumulative Fraction Plot）**：
在优秀的高质量植物注释集中，曲线应迅速陡峭上升——通常要求 **$AED < 0.5$ 的基因模型比例在全基因组中达到 80%~90% 以上**。

### 3. BUSCO 蛋白水平完整度评估
BUSCO（Benchmarking Universal Single-Copy Orthologs）通过在目标蛋白组中搜索系统发育谱系高度保守的单拷贝直系同源基因，评估基因集的完整性。对于植物研究，常用谱系库包括：
- `viridiplantae_odb10`（绿色植物广谱库，包含 425 个保守核心基因）；
- `embryophyta_odb10`（陆生植物库，包含 1,614 个基因）；
- `poales_odb10`（禾本科专项库，包含 4,896 个基因）；
- `eudicots_odb10`（真双子叶植物专项库，包含 2,326 个基因）。

BUSCO 最终输出的百分比包含四种状态：
- **Complete Single-copy (S)**：单拷贝完整检出（符合进化单拷贝预期）；
- **Complete Duplicated (D)**：多拷贝完整检出；
- **Fragmented (F)**：序列匹配但长度显著短于参考 HMM 截断阈值（提示组装断裂或剪接中断）；
- **Missing (M)**：未能检出有效同源模型。

#### 植物多倍体中 Duplicated BUSCO 的科学辨析
在植物学中，**Duplicated BUSCO (D) 偏高并不直接等同于“质量差”**，必须严谨区分生物学真象与技术假象：
1. **生物学演化真实复制（WGD / 多倍性）**：
   - 在近期经历过多倍化的物种（如异源六倍体小麦、四倍体油菜、同源四倍体紫花苜蓿）中，同源染色体亚基因组保留了大量同源基因（Homeologs）。此时 BUSCO (D) 往往高达 40%~80%，这完全是真实的演化结果；
   - 验证手段：检查重复基因对的同义替换率（$K_s$）分布谱，或利用亚基因组分相比对验证其位于不同同源染色体对应共线性区块上。
2. **技术性组装假阳性（未完全分相的单倍型冗余）**：
   - 在高杂合二倍体组装中，若分相算法未能合并两条同源染色单体，导致同一个等位基因在 Contig 中被拆分冗余组装，会虚假推高 (D) 值；
   - 验证手段：利用 Merqury 的 2-copy k-mer 峰形分析，或结合全基因组测序重比对深度（冗余区域读深通常仅为全基因组平均深度的 0.5×）。

### 4. OMArk 蛋白组正交同源与一致性评估
OMArk（Nature Biotechnology 2024）基于 OMA 数据库的层次化直系同源群（Hierarchical Orthologous Groups, HOGs），为植物蛋白组提供了比 BUSCO 更全面的系统发育上下文评估：
- **覆盖度（Conserved Portfolio Completeness）**：在目标分类阶元上评估祖先保守蛋白家族的完整检出比例；
- **谱系一致性（Consistency）**：检测蛋白质序列的谱系归属是否与目标物种分类地位吻合；
- **外源污染检出（Contamination）**：精准标记属于细菌、真菌或非植物内生生物来源的异常蛋白家族，防止微生物共生菌污染序列被误注释为植物基因。

## 严谨的注释质量审查清单（Checklist）

在正式发布植物基因组注释集之前，必须执行以下量化过滤与一致性检查：

```
┌──────────────────────────────────────────────────────────────┐
│                  植物基因组注释质量审查清单                    │
├──────────────────────────────────────────────────────────────┤
│ 1. 结构完整性审查                                            │
│    □ 所有 CDS 长度均为 3 的整数倍（严格无相差）                │
│    □ 所有 CDS 均具有规范起始密码子（ATG）和终止密码子（TAA/TAG/TGA）│
│    □ 内部无提前终止密码子（In-frame Premature Stop Codons）     │
│    □ 规范剪接供体/受体位点（GT-AG > 98%，允许极少数 GC-AG）     │
│                                                              │
│ 2. 证据充分性与模型分布审查                                  │
│    □ 全基因组基因模型 AED 累积分布中 AED < 0.5 占比 ≥ 85%      │
│    □ 外显子长度中位数吻合植物常规特征（约 150~250 bp）         │
│    □ 内含子长度呈单峰长尾分布（植物内含子长度中位数通常 100~300 bp）│
│    □ 单外显子基因（Single-exon Genes）占比处于合理区间（< 15%~20%）│
│                                                              │
│ 3. 假基因与转座子污染过滤                                    │
│    □ 过滤与完整转座子（LTR-RT / TIR / Helitron）完全重叠的模型 │
│    □ 标记并剔除无转录本支持且缺乏蛋白同源证据的截短短肽（< 50 aa）│
│                                                              │
│ 4. 进化保守性与系统评估                                      │
│    □ 运行对应植物纲目谱系的 BUSCO 评估并提供完整报告          │
│    □ 运行 OMArk 检验谱系一致性并排除潜在共生微生物污染         │
└──────────────────────────────────────────────────────────────┘
```

## 植物案例与参考文献

- **BRAKER3 植物基准评测**：Gabriel 等人在多物种基准测试中，使用包含拟南芥、番茄等植物的高质量 RNA-seq 与同源蛋白，系统评估了从外显子到转录本水平的 Sensitivity 和 Specificity，确立了新一代基因预测的精度基准。详见 [Gabriel et al., *Genome Res.*, 2024](https://doi.org/10.1101/gr.278090.123)。
- **芒果染色体级基因组注释质量实践**：在芒果参考基因组构建中，研究人员综合使用 BUSCO（Embryophyta 谱系库检出率 > 97%）、RNA-seq junction 比对支持度与 AED 累积分布曲线，严格过滤假阳性模型，确保了基因集的高可信度。[The Plant Genome, 2024](https://doi.org/10.1002/tpg2.20441)。
