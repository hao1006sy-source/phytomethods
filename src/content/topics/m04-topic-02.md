## 核心科学问题与演化驱动力

植物在定着生长（Sessile life）的生存压力下，无法通过移动规避病原菌侵袭、极端干旱、高盐碱等恶劣生境。为了应对外界胁迫，植物演化出高度动态的基因组结构，其中**基因家族的爆发式扩张与特化收缩**（Expansion & Contraction）是最重要的适应性创新源泉。

典型的植物特化基因家族（如识别病原菌效应蛋白的 NBS-LRR 抗病受体、负责次生代谢防御物质合成的细胞色素 P450 酶系、调控花器官分化的 MADS-box 转录因子）在不同植物谱系间呈现出数十倍甚至上百倍的拷贝数差异。然而，直接比较现存物种的基因计数极易受到中性漂变、全基因组多倍化以及基因组组装完整度差异的误导。因此，必须将基因家族计数置于具有绝对地质年代的系统发育物种树框架下，利用显式随机模型推断其演化动态。

## 算法数学推导：CAFE 5 随机生灭模型与极大似然估计

主流分析工具 [CAFE 5](../../../methods/cafe5/) 基于连续时间马尔可夫链（Continuous-Time Markov Chain, CTMC）构建了基因家族规模演化的出生-死亡（Birth-Death）概率框架：

### 1. 连续时间马尔可夫生灭过程

设基因家族在时间 $t=0$ 时的初始拷贝数为 $s$，经过演化时间跨度 $t$ 后，拷贝数变为 $c$ 的条件转移概率为 $P(X_t = c \mid X_0 = s)$。在恒定出生率 $\lambda$ 和死亡率 $\mu$ 假设下（通常在稳态假设中设 $\lambda = \mu$），该转移概率具有精确的解析解：

$$P(X_t = c \mid X_0 = s) = \sum_{j=0}^{\min(s,c)} \binom{s}{j} \binom{s+c-j-1}{s-1} \alpha^{s-j} \beta^{c-j} (1-\alpha-\beta)^j$$

其中转移参数 $\alpha$ 与 $\beta$ 完全由出生死亡率与时间乘积 $\lambda t$ 决定：

$$\alpha = \beta = \frac{\lambda t}{1 + \lambda t}$$

该公式定量刻画了：随着谱系分化时间 $t$ 的增加，家族规模偏离初始祖先拷贝数的方差线性增大；而在短时间尺度内，中性演化倾向于维持原拷贝数稳定。

### 2. 伽马分布速率异质性（Gamma Rate Heterogeneity）

经典生灭模型假设基因组内所有基因家族以统一的速率 $\lambda$ 演化。然而在实际植物基因组中，看家基因（如核糖体蛋白）极度保守，而免疫抗病家族演化极其剧烈。CAFE 5 引入了**离散伽马分布**（Discrete Gamma Distribution）来对家族演化速率建模：

$$f(\lambda; k, \theta) = \frac{\lambda^{k-1} e^{-\lambda/\theta}}{\theta^k \Gamma(k)}$$

通过将伽马分布划分为 $k$ 个均等概率的离散速率等级（通常设 $k=4$），每个基因家族属于特定速率等级的似然值被加权求和：

$$L(\text{Family}) = \sum_{m=1}^k \frac{1}{k} L(\text{Family} \mid \lambda_m)$$

极大似然估计能够自适应捕捉到那些演化速率高出平均水平数倍的特异适应性家族，有效避免了一刀切模型带来的假阴性。

### 3. 组装与注释误差修正模型（Error Model）

在植物基因组研究中，高杂合度或短读长拼接常导致串联重复基因塌缩，而不完全注释也会使拷贝数虚假偏低。CAFE 5 创新性地引入了误差转移矩阵 $\epsilon$：

$$P(Observed = j \mid True = i) = \epsilon_{ij}$$

通过将同属近缘物种或高质量参考基因组的实测分布进行极大似然拟合，先验估计出基因丢失和重复误注的技术误差率，在后续计算中修正实际观测计数，从根源上消除组装缺陷引起的虚假收缩结论。

### 4. 假设检验与 Viterbi 祖先状态重构

为判定某个家族在特定分支上是否显著扩张或收缩，CAFE 5 采用**似然比检验**（Likelihood Ratio Test, LRT）：

$$\Delta = 2 \left( \ln L_{\text{free}} - \ln L_{\text{global}} \right) \sim \chi^2(df)$$

- $H_0$（全局模型）：全树所有分支共享统一生灭率 $\lambda$；
- $H_1$（分支特异模型）：目标植物分支拥有独立的演化速率 $\lambda_{\text{foreground}}$。

计算 $p$ 值并经 Benjamini-Hochberg 多重检验校正（FDR $< 0.05$）后，调用 **Viterbi 算法**回溯动态规划矩阵，重构物种树上每个内部祖先节点的基因家族具体拷贝数，从而明确指出扩张或收缩发生的具体历史地质时期。

## 植物学典型案例与功能演化分析

### 1. 水稻与禾本科 NBS-LRR 抗病基因库的暴发扩增
禾本科植物（如水稻、玉米、小麦）面对稻瘟病菌、白叶枯病菌等病原体的长期协同演化，其 NBS-LRR 家族在祖先分支上经历了爆发式扩张。CAFE 5 检验显示其演化速率 $\lambda$ 显著高于基因组中位数，祖先节点重构证实该类扩增与多次串联复制事件直接偶联。

### 2. 水生与寄生植物特化基因的大规模收缩
在浮萍（*Spirodela polyrhiza*）或食虫植物狸藻（*Utricularia gibba*）中，为了适应水生微型化或极简基因组演化，涉及次生细胞壁合成（木质素合成酶系）、根系发育调控及某些光信号传导基因家族呈现全基因组维度的协同收缩。

## 实践规范与质控要点

| 分析环节 | 核心标准与参数建议 | 常见陷阱与科学纠正 |
| :--- | :--- | :--- |
| **物种树定年要求** | 必须输入具有绝对地质年代（Ma）的超度量树（Ultrametric tree） | 输入带有替代数分支长度的未定年树会导致生灭率 $\lambda$ 失去物理时间意义 |
| **超大基因家族过滤** | 过滤在单个物种中拷贝数 $> 100$ 或跨物种波动 $> 200$ 的异常大簇 | 超大簇常因非特异性逆转录转座子嵌合导致马尔可夫链计算溢出报错 |
| **全 0 家族与谱系新生** | 剔除在物种树根部所有现存物种均为 0 的衍生孤儿家族 | CAFE 假设根部至少存在一个拷贝，谱系特异新生成基因不满足传统生灭前提 |
| **误差模型参数** | 运行 `-e` 估计误差分布，并在最终推断中加载 `.errorfile` | 忽略测序质量差异会导致低质量组装物种在所有家族中被误判为全面收缩 |
