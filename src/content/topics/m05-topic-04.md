## 核心科学问题：群体遗传多态性的多维定量刻画

在植物演化生物学与作物驯化研究中，准确评估群体内部的多样性水平、群体间的分化程度以及染色体物理区间内的连锁关联，是定位驯化基因、评估种质资源变异潜力以及指导杂交育种的核心依据。

面对全基因组数千万个 SNP 标记，群体遗传学构建了一套严谨的统计指标体系：
- **核苷酸多样性**（$\pi$）与 **Watterson 估计量**（$\theta_W$）：刻画群体内等位基因的多态性丰度；
- **Tajima's $D$ 检验**：通过比较不同统计量之间的差异，区分自然选择与人口历史动态；
- **群体固定指数（$F_{ST}$）**：量化不同地理或生态亚群之间的遗传隔离程度；
- **连锁不平衡（Linkage Disequilibrium, LD）**：揭示重组事件在物理基因组上的历史印记，决定全基因组关联分析（GWAS）的定位分辨率。

## 算法数学推导：核心指标推导与物理意义

### 1. 核苷酸多样性（$\pi$）与 Watterson 估计量（$\theta_W$）

设从二倍体群体中随机抽取 $n$ 个单倍体样本（即 $n/2$ 个个体），序列有效比较长度为 $L$：
- **核苷酸多样性（Nei & Li, 1979）**：定义为样本中任意两个随机抽取的单倍体序列在单位位点上的平均成对差异数：
  $$\pi = \frac{n}{n - 1} \sum_{i=1}^m \frac{2p_i(1 - p_i)}{L}$$
  其中 $m$ 为该区间内多态位点数，$p_i$ 为第 $i$ 个位点的次等位基因频率，$\frac{n}{n-1}$ 为有限样本小样本无偏校正因子。
- **Watterson 估计量（Watterson, 1975）**：仅基于多态位点总数 $S$ 估计中性群体突变参数 $\theta = 4N_e\mu$：
  $$\theta_W = \frac{S}{a_n \cdot L}, \quad a_n = \sum_{i=1}^{n-1} \frac{1}{i}$$

在中性平衡群体中，理论上 $E(\pi) = E(\theta_W) = 4N_e\mu$。

### 2. Tajima's $D$ 中性检验统计量

Tajima（1989）通过比较两个期望相同但对等位基因频率谱敏感度迥异的估计量构建检验统计量：

$$D = \frac{\pi - \theta_W}{\sqrt{\text{Var}(\pi - \theta_W)}}$$

- **$D = 0$**：符合中性突变-漂变平衡假说；
- **$D < 0$**（$\pi < \theta_W$）：群体中低频稀有变异过多。生物学机制对应：**近期正向选择清除**（Selective Sweep）导致多样性骤降，或**近期群体经历瓶颈后发生快速人口膨胀**；
- **$D > 0$**（$\pi > \theta_W$）：中等频率等位基因过多。生物学机制对应：**平衡选择**（Balancing Selection）长期维持杂合状态（如植物自交不亲和 S-位点），或**两个经历深度隔离分化的亚群发生混合（Admixture）**。

### 3. 群体分化指数（Weir & Cockerham $F_{ST}$）

经典的 Wright $F_{ST} = \frac{H_T - H_S}{H_T}$ 未考虑有限样本量和样本量不均衡引起的抽样方差。Weir & Cockerham（1984）提出了基于方差分量分解的**无偏估计量**：

$$\theta = \frac{\text{MSB} - \text{MSW}}{\text{MSB} + (n_c - 1)\text{MSW}}$$

其中 $\text{MSB}$ 为群体间均方差，$\text{MSW}$ 为群体内均方差，$n_c$ 为有效平均样本量。在多位点全基因组计算中，必须采用“分子求和除以分母求和”（Ratio of averages），严禁先求单点比值再求平均，以防小分母位点引入严重数值失真。

### 4. 连锁不平衡（LD）度量与衰减拟合

对于两个双等位 SNP 位点（等位基因为 $A/a$ 与 $B/b$），其非随机关联程度由单倍型频率决定：

$$D = P_{AB} - p_A p_B, \quad r^2 = \frac{D^2}{p_A (1 - p_A) p_B (1 - p_B)}$$

随着物理距离 $d$（碱基对 bp）的增加，重组事件使得 $r^2$ 逐步衰减至背景水平。采用 **Hill & Weir（1988）非线性理论模型**拟合衰减曲线：

$$E(r^2) = \left[ \frac{10 + C}{(2 + C)(11 + C)} \right] \left[ 1 + \frac{(3 + C)(12 + 12C + C^2)}{n(2 + C)(11 + C)} \right]$$

其中 $C = 4N_e \rho \cdot d$ 为复合重组参数。通常以 **$r^2$ 衰减至最大值的一半**（Half-decay distance）或衰减至基准阈值（如 $r^2 = 0.2$）对应的物理距离，作为该作物的有效 LD 衰减跨度。

## 植物交配系统对 LD 衰减与多样性的深远影响

```
植物不同交配系统的群体遗传学特征对比：
┌──────────────────────────┬──────────────────────────┐
│  自花授粉植物 (自交, S~1)  │  异花授粉植物 (异交, T~1)  │
│  典型作物: 拟南芥, 水稻, 大豆│  典型作物: 玉米, 黑麦, 向日葵│
├──────────────────────────┼──────────────────────────┤
│ 1. 实际杂合度极低 (F -> 1) │ 1. 杂合度极高, HWE 拟合优良 │
│ 2. 有效重组率显著降低      │ 2. 重组事件频繁打破单倍型    │
│ 3. LD 衰减极慢 (100~300 kb)│ 3. LD 衰减极快 (1~5 kb)     │
│ 4. GWAS 候选区间宽, 标记需求低│ 4. GWAS 定位精确至基因内部  │
└──────────────────────────┴──────────────────────────┘
```

自交植物（如栽培水稻）由于杂合子极度匮乏，同源重组主要发生在相同序列的纯合染色单体之间，无法有效打碎单倍型，导致选择性清除的波及范围长达数百 kb；而异交植物（如玉米）重组频繁，单倍型块高度细碎，GWAS 定位可直接精确到单碱基，但需要更高密度的 SNP 标记覆盖。

## 生产环境实操命令行指南

```bash
# 1. 利用 VCFtools 计算群体内多态性 π 与 Tajima's D (100 kb 滑动窗口)
vcftools --gzvcf cohort.vcf.gz --keep pop_indica.txt \
  --window-pi 100000 --window-pi-step 10000 --out pi_indica
vcftools --gzvcf cohort.vcf.gz --keep pop_indica.txt \
  --TajimaD 100000 --out tajima_indica

# 2. 利用 VCFtools 计算两群体间的加权滑动窗口 FST (Weir-Cockerham)
vcftools --gzvcf cohort.vcf.gz \
  --weir-fst-pop pop_wild.txt --weir-fst-pop pop_cultivated.txt \
  --fst-window-size 100000 --fst-window-step 10000 \
  --out fst_wild_cult

# 3. 利用 PLINK 估计成对连锁不平衡 (LD, r^2) 并输出距离表
plink \
  --vcf cohort.vcf.gz \
  --r2-window-kb 1000 \
  --r2-window 1000 \
  --r2-window-r2 0.05 \
  --r2 \
  --out ld_decay_pop
```

## 实践规范与质控要点

| 分析环节 | 核心标准与参数建议 | 常见陷阱与科学纠正 |
| :--- | :--- | :--- |
| **π 窗口分母标准化** | 分母必须采用该窗口内“所有有效覆盖位点总数”（包含单态位点） | 分母仅计算“多态 SNP 数”，导致不同窗口间多样性数值彻底失去物理可比性 |
| **FST 负值处理** | 在单个 SNP 位点上出现微小负值时，代表样本间方差低于期望 | 严禁强行将负值设为 0，多位点聚合计算必须保留分子分母累加 |
| **LD 计算频率截断** | 计算 LD 前必须过滤极低频等位基因（`--maf 0.05`） | 包含单态或稀有突变会导致 $r^2$ 分母接近 0，产生人工极端偶联点 |
| **滑动窗口步长** | 推荐窗口大小 50 ~ 100 kb，步长 10 ~ 20 kb | 窗口过小受随机噪声主导；窗口过大会平滑掩盖局部尖锐的演化信号 |
