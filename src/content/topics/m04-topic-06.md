## 核心科学问题：植物基因组的古多倍化本质

全基因组加倍（Whole-Genome Duplication, WGD / Polyploidization）是被子植物演化创新的主导引擎。几乎所有现代显花植物的祖先都在白垩纪-古近纪（K-Pg）灭绝事件前后或更久远的地质历史中经历过一至数轮全基因组加倍。多倍化为植物提供了海量的功能冗余基因，使其能够承受剧烈的环境变迁并分化出全新的形态特征。

然而，在漫长的地质演化中，多倍体基因组会迅速经历**二倍化**（Diploidization）过程：染色体发生大规模断裂与融合重排，冗余的亚基因组基因发生不对称假基因化丢失（Fractionation）。现存二倍体植物的外观染色体数目（如水稻 $2n=24$、葡萄 $2n=38$）无法直接反映其远古真实倍性。

为了精确揭示远古加倍事件发生的地质时代及其对物种分化的贡献，比较基因组学必须构建集**同义替换率（$K_s$）时间谱**、**跨染色体共线性倍性深度**与**多基因树演化节点调和**于一体的三维证据链。

## 算法数学推导：同义替换率时钟与高斯混合解卷积模型

### 1. 同义替换率（$K_s$）的生物学本质与分子钟换算

密码子发生突变但不改变编码氨基酸的突变称为**同义突变（Synonymous substitution）**。由于同义位点通常不改变蛋白质二级结构与生化活性，受到的自然选择净化选择相对微弱，其突变累积速率可近似作为分子进化时钟的参考。

通过 Nei-Gojobori（NG86）或最大似然密码子模型（YN00 / Goldman-Yang）计算每同义位点的平均替换数 $K_s$。设两个旁系同源基因自复制事件发生后独立演化，中性同义替换速率为 $r$（突变/位点/年），持续时间为 $T$（年），其线性关系满足：

$$K_s = 2rT \implies T = \frac{K_s}{2r}$$

- **谱系速率异质性**：植物核基因组中性速率在不同谱系间存在显著差异（例如禾本科作物常取 $r \approx 6.5 \times 10^{-9}$ substitutions/site/year；部分木本植物如葡萄、杨树演化速率偏慢，而一年生草本拟南芥演化较快）。分子钟定年应优先结合近缘物种化石校准点；
- **突变饱和效应**：当 $K_s > 1.5 \sim 2.0$ 时，多重突变与回复突变频繁发生，即使引入模型纠正，其估计方差也会急剧放大，导致 $K_s$ 谱右侧出现平坦长尾。因此，$K_s > 2.0$ 区间的定年推断需保持审慎，应结合系统发育树节点调和进行交叉验证。

### 2. $K_s$ 频率分布谱与混合解卷积模型（GMM / ELMM）

在全基因组所有旁系同源基因对的 $K_s$ 分布中，实际观测到的曲线是多种演化机制叠加的复合信号：

- **背景小规模复制（SSD）**：单基因串联复制或逆转录复制在漫长演化中持续以相对恒定的频率发生并快速衰减，在 $K_s$ 原始空间表现为指数衰减趋势：
  $$f_{\text{bg}}(K_s) = \lambda e^{-\lambda K_s}$$
- **全基因组加倍（WGD）**：在极短地质时间内成千上万个基因同时加倍，在后续中性累积突变中，由于突变过程累积效应，对数尺度变换后变量 $Y = \ln K_s$ 表现为正态分布：
  $$Y = \ln K_s \sim \mathcal{N}(\mu_k, \sigma_k^2)$$
  还原到原始 $K_s$ 变量空间，则对应于**对数正态分布（Lognormal distribution）**：
  $$f_{\text{WGD}}(K_s; \mu_k, \sigma_k^2) = \frac{1}{K_s \sigma_k \sqrt{2\pi}} \exp\left( -\frac{(\ln K_s - \mu_k)^2}{2\sigma_k^2} \right)$$

分析工具（如 [wgd v2](../../../methods/wgd/)，*Chen et al., Bioinformatics, 2024*）采用**对数尺度高斯混合模型**（log-GMM）或**指数-对数正态混合模型**（ELMM）对复合信号进行解卷积拟合：

$$P(K_s) = \pi_0 \lambda e^{-\lambda K_s} + \sum_{k=1}^K \pi_k \frac{1}{K_s \sigma_k \sqrt{2\pi}} \exp\left( -\frac{(\ln K_s - \mu_k)^2}{2\sigma_k^2} \right), \quad \left(\sum_{k=0}^K \pi_k = 1\right)$$

通过**期望最大化算法**（EM Algorithm）迭代求解各混合分量的参数，并结合赤池信息准则（AIC）或贝叶斯信息准则（BIC）作为加倍事件峰数量 $K$ 的模型选择参考。需要指出，混合模型的数学最优解不完全等同于真实的生物学演化事件，必须与共线性区块和基因树证据互相印证。

## 全基因组加倍的多维交叉证据框架

```
判定古多倍化事件的多维交叉证据框架：
├── 1. 序列证据 (Ks 分布谱): 呈现显著的混合正态加倍峰，排除单纯背景指数衰减
├── 2. 空间结构证据 (共线性深度): 染色体大尺度区域保留 1:2, 1:4 或 1:3 对应倍性块
└── 3. 谱系节点证据 (基因树调和): 大量单基因树的复制节点在物种树特定分支发生拓扑聚集
```

### 1. 共线性锚定排除串联假峰（Synteny-Anchored Ks）
全基因组盲筛同源对极易因局部转座子爆发产生假峰。利用 [MCScanX](../../../methods/mcscanx/) 仅提取位于共线性区块内部的锚点基因对（Syntenic paralogs）绘制 $K_s$ 谱，能有效富集多倍化全基因组信号，显著降低单基因串联复制与局部转座插入带来的连续背景底噪，使真正的 WGD 峰轮廓清晰呈现。

### 2. 物种分化对照基准（Ortholog Ks vs Paralog Ks）
为了确定 WGD 是发生在物种分化之前还是之后，必须将物种自身的**旁系同源加倍峰**（Paralog $K_s$）与该物种与近缘外类群之间的**直系同源分化峰**（Ortholog $K_s$）置于同一坐标系中比较：
- 若 Ortholog $K_s$ 峰位于 Paralog WGD 峰的**右侧**（数值更大），证明 WGD 发生在物种分化**之后**（该谱系特异加倍，如玉米特异性四倍化）；
- 若 Ortholog $K_s$ 峰位于 Paralog WGD 峰的**左侧**（数值更小），证明 WGD 发生在物种分化**之前**（两物种共享古加倍，如葡萄与拟南芥共享核心真双子叶 $\gamma$ 事件）。

## 植物演化史上标志性古多倍化事件参考

| 演化事件代码 | 事件地质时代 | 影响植物类群 | 典型参考基因组核型表现 |
| :--- | :--- | :--- | :--- |
| **$\epsilon$ 事件** | 约 3.0 ~ 3.2 亿年前 (石炭纪) | 所有种子植物共同祖先 | 所有被子植物与裸子植物共享的最古老全基因组加倍痕迹 |
| **$\gamma$ 古六倍化** | 约 1.2 亿年前 (早白垩世) | 核心真双子叶植物 (Core Eudicots) | 在葡萄（*Vitis vinifera*）中清晰呈现 1:3 染色体三联体结构 |
| **$\sigma / \rho$ 事件** | 白垩纪末期 (约 6500 万年前) | 禾本科/单子叶植物祖先 | 水稻、玉米、小麦共同继承的祖先全基因组重复 |
| **近期异源多倍化** | 现代农业驯化史 (数千年至数十万年) | 油菜 (AACC)、普通小麦 (AABBDD) | 各亚基因组保持高度完整共线性，发生部分同源重组抑制 |

## 实践规范与质控要点

| 分析环节 | 核心标准与参数建议 | 常见陷阱与科学纠正 |
| :--- | :--- | :--- |
| **同义密码子比对构建** | 必须由高质量蛋白比对逆转录反推密码子比对（如 PAL2NAL） | 直接对 CDS 进行核苷酸多重比对会导致移码和跨位点空位破裂 |
| **饱和区间过滤** | 严格剔除 $K_s > 2.0$ 或 $K_s < 0.01$ 的异常端点 | 将高 $K_s$ 饱和假峰误判为远古“前被子植物”新加倍事件 |
| **共线性块最小长度** | 提取共线性旁系对时，块内基因数建议 $\ge 5$ 个锚点 | 锚点数太少（如 2 个）会捕获转座子介导的局部微重排假共线 |
| **速率异质性校正** | 跨物种比较时必须考虑不同科植物演化速率的差异 | 忽略木本（慢速率）与草本（快速率）的时钟差异直接对比 $K_s$ 绝对值 |
