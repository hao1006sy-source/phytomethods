## 核心科学问题与植物演化特殊性

群体遗传学（Population Genetics）致力于揭示遗传变异在种群内部与种群之间的空间分布规律，以及等位基因频率在突变、自然选择、遗传漂变和基因流共同作用下的代际动态演化机制。在植物科研中，群体遗传分析广泛应用于作物驯化溯源、种质资源多样性评估、地方适应性（Local Adaptation）基因定位以及全基因组选择育种。

与动物群体相比，植物群体具有独一无二的生物学与演化特征：
1. **交配系统多样性（Mating Systems）**：植物涵盖严格自花授粉（如拟南芥、栽培水稻、大豆）、异花授粉（如野生玉米、黑麦）以及兼性无融合生殖（Apomixis）；
2. **多倍化与亚基因组不对称演化**：异源四倍体（如油菜、棉花）或异源六倍体（如普通小麦）包含两套以上同源染色体组，部分同源染色体间存在基因转换与配对偏差；
3. **高水平近交与超长连锁不平衡（LD）**：自交植物的自交率极高，导致群体实际杂合度极低，单倍型在物理空间上连续延伸数万至数百万碱基。

因此，直接套用动物经典的二倍体异交模型极易导致错误的统计推断，必须建立契合植物交配动力学的严谨群体遗传理论框架。

## 算法数学推导：核心平衡与漂变模型

### 1. Hardy-Weinberg 平衡定律与卡方适合度检验

在理想随机交配、无限大且无突变、选择与迁移的二倍体群体中，设双等位位点等位基因 $A$ 与 $a$ 的频率分别为 $p$ 与 $q$（满足 $p + q = 1$）。下一代的三种合子基因型频率恒定保持为二项展开式：

$$P(AA) = p^2, \quad P(Aa) = 2pq, \quad P(aa) = q^2$$

在实际基因组检验中，利用**皮尔逊卡方检验**（Pearson's $\chi^2$ Test）评估实测基因型频数与理论期望值的偏离：

$$\chi^2 = \sum_{g \in \{AA, Aa, aa\}} \frac{(O_g - E_g)^2}{E_g} \sim \chi^2(df=1)$$

其中 $O_g$ 为观测频数，$E_g$ 为在当前等位基因频率下的理论期望频数。在自然异交群体中，偏离 HWE（$p < 10^{-6}$）常用于过滤由基因组重复区错配导致的假阳性杂合 SNP。

### 2. 植物自交系统与近交系数（Inbreeding Coefficient $F$）

在自花授粉植物中，非随机交配打破了 HWE 平衡。定义**近交系数 $F$** 为一个个体内任意两个等位基因源自同一祖先拷贝（Identity by Descent, IBD）的概率。基因型频率修正为：

$$P(AA) = p^2 + Fpq, \quad P(Aa) = 2pq(1 - F), \quad P(aa) = q^2 + Fpq$$

设群体的自交率为 $S$（自花授粉比例），异交率为 $T = 1 - S$。在经过若干世代达到交配系统平衡后，近交系数 $F$ 趋向于稳定解：

$$F = \frac{S}{2 - S}$$

- 对于严格自交植物（$S \to 1$），$F \to 1$，杂合子比例趋近于 0（$P(Aa) \to 0$），绝大多数个体处于纯合状态；
- **有效种群规模修正**：自交显著削弱了等位基因在群体中的自由组合，使有效种群大小减半：
  $$N_e = \frac{N}{1 + F} \xrightarrow{F \to 1} \frac{N}{2}$$

### 3. Wright-Fisher 离散代际随机漂变模型

有限种群规模会导致等位基因频率因配子抽样误差产生随机波动（Genetic Drift）。在群体大小为 $N$ 的二倍体群体中（总等位基因拷贝数为 $2N$），设当前代等位基因 $A$ 的拷贝数为 $i$（频率 $p = i/(2N)$）。下一代中该等位基因拷贝数变为 $j$ 的转移概率服从**二项分布（Binomial Distribution）**：

$$P(X_{t+1} = j \mid X_t = i) = \binom{2N}{j} \left( \frac{i}{2N} \right)^j \left( 1 - \frac{i}{2N} \right)^{2N - j}$$

在纯随机漂变作用下，群体的平均期望杂合度 $H_t$ 按几何级数逐代衰减：

$$H_t = H_0 \left( 1 - \frac{1}{2N_e} \right)^t \approx H_0 e^{-\frac{t}{2N_e}}$$

该公式表明：有效群体规模 $N_e$ 越小（如驯化过程中的严重瓶颈），群体杂合度丧失越快，稀有有益突变越容易因随机漂变而偶然丢失。

## 植物群体遗传分析核心指标矩阵

```
群体内与群体间核心演化统计量体系：
├── 1. 群体内变异水平:
│   ├── 核苷酸多样性 (π): 任意两个随机抽样个体之间的平均核苷酸差异数
│   ├── Watterson 估计量 (θ_W): 基于多态性位点总数 (S) 的中性突变率估计
│   └── 中性检验 (Tajima's D): D = (π - θ_W) / SE(π - θ_W) 判别正负选择或瓶颈
├── 2. 群体间分化程度:
│   ├── Wright 固定指数 (FST): FST = (HT - HS) / HT 刻画亚群间等位基因频率隔离
│   └── 跨群体多样性降幅 (ROD): ROD = 1 - (π_cultivated / π_wild) 评估驯化瓶颈消耗
└── 3. 基因组关联与单倍型:
    └── 连锁不平衡 (LD, r^2): 染色体上非随机共分离位点对之间的相关系数
```

## 实践规范与质控要点

| 分析环节 | 核心标准与参数建议 | 常见陷阱与科学纠正 |
| :--- | :--- | :--- |
| **自交植物 HWE 过滤** | 严禁在自交植物中采用常规 $p < 10^{-6}$ 过滤偏离 HWE 位点 | 自交物种本身天然缺乏杂合子，盲目套用 HWE 过滤会误删 80% 的真实纯合 SNP |
| **多倍体基因型剂量** | 异源四倍体推荐使用能够输出等位基因剂量的工具（如 updog） | 将 AABB 四倍体强行按二倍体 0/1/2 分型，丢失部分同源染色体特异突变 |
| **次等位基因频率（MAF）**| 群体结构分析设 `maf 0.05`；稀有突变检测保留低频变异 | 过度严格的 MAF 过滤会人为抹去近期正选择与群体扩张信号 |
| **样本混杂与近亲排查** | 运行 [PLINK](../../../methods/plink/) `--genome` 计算亲缘系数 $\hat{\pi} > 0.5$ 剔除克隆或重复株系 | 混入同株重复取样材料会导致局部亚群虚假紧密聚类 |
