## 核心概念与植物演化复杂性

在植物比较基因组学中，准确识别跨物种间的对应基因是一切功能注释、系统发育推断、共线性分析与基因家族演化研究的基石。然而，植物基因组在漫长的演化史中普遍经历了全基因组加倍（Whole-Genome Duplication, WGD）、大片段串联复制（Tandem Duplication）、转座子介导的逆转录复制以及严重的亚基因组差异丢失（Fractionation）。这些事件导致序列相似度最高的两个基因未必对应物种分化时直接分化的对应基因。

```
同源基因 (Homologs): 源于单一祖先基因
├── 直系同源 (Orthologs): 由物种分化事件 (Speciation) 分离产生
│   ├── 一对一 (1:1): 在两个物种中均保持单拷贝（系统发育建树的核心骨架）
│   └── 一对多 / 多对多: 分化前后伴随独立基因复制（如多倍体衍生同源物）
└── 旁系同源 (Paralogs): 由基因复制事件 (Duplication) 分离产生
    ├── 共旁系同源 (In-paralogs): 物种分化后发生复制产生的拷贝
    └── 异旁系同源 (Out-paralogs): 物种分化前已发生复制产生的古老拷贝
```

传统的**双向最佳匹配**（Reciprocal Best Hit, RBH）方法在植物中极易失效：若物种 A 与 B 分化后，物种 A 经历了全基因组加倍保留了两个平行拷贝 $A_1$ 与 $A_2$，而物种 B 仅保留单拷贝 $B$，且 $A_1$ 演化速率加快导致序列相似度下降，则 RBH 会错误地将 $A_2$ 判定为 $B$ 的唯一直系同源，而遗漏 $A_1$ 的真正演化谱系。因此，现代比较基因组学必须依赖基于网络聚类与系统发育树调和（Reconciliation）的高维推断算法。

## 算法数学推导：OrthoFinder 2 计算架构

主流分析平台（如 [OrthoFinder](../../../methods/orthofinder/)）将同源推断划分为序列比对空间校正、图马尔可夫聚类与树拓扑调和三大阶段：

### 1. 序列比对打分的长度偏差归一化

在进行全对全（All-vs-All）Diamond 或 BLASTP 比对时，长蛋白质因比对命中片段更长，其原始比对得分（Bit Score $S_{ij}$）往往系统性偏高，导致结构域嵌合的长蛋白被错误聚入不相关的家族。OrthoFinder 引入了**比对长度归一化公式**：

$$S'_{ij} = S_{ij} \times \frac{\min(L_i, L_j)}{\max(L_i, L_j)}$$

其中 $L_i$ 与 $L_j$ 分别代表比对序列的氨基酸长度。当两序列长度差距极大时，比值趋近于 0，有效惩罚了仅因局部保守结构域重叠导致的假阳性高分。随后将归一化得分进一步转化为谱系相对距离矩阵。

### 2. 马尔可夫图聚类（MCL）与算子迭代

所有蛋白质对构成一个加权无向图，节点为基因，边权重为归一化相似度。将网络表示为按列归一化的马尔可夫转移概率矩阵 $M$，其中列和为 1：$\sum_i M_{ij} = 1$。MCL 算法通过两个交替算子的迭代实现图分割：

- **扩散扩展算子**（Expansion）：计算矩阵平方，模拟随机游走沿边向前扩散，增强簇内部连通性：
  $$M_{t+1/2} = M_t \times M_t$$
- **局部膨胀算子**（Inflation）：引入非线性膨胀系数 $r$（通常 $r = 1.5$），计算各元素的 $r$ 次幂并按列重新归一化：
  $$(\Gamma_r M)_{ij} = \frac{(M_{ij})^r}{\sum_k (M_{kj})^r}$$

该非线性运算放大了矩阵中高概率转移边（强连接），同时将低概率转移边压低至 0（弱边蒸发）。经过交替迭代，矩阵快速收敛为非连续的分块对角阵，从而自动完成**直系同源群**（Orthogroups, OG）的边界划定。

### 3. 无根基因树与物种树调和（DLCPar / Reconciliation）

划分 Orthogroup 仅确定了基因集合拥有共同的祖先，但一个 Orthogroup 内可能包含数十个发生多次复制的旁系拷贝。OrthoFinder 在各 Orthogroup 内构建 MSA 并估计无根基因树，进而采用 DLCPar 等最大简约调和模型，将基因树与物种树进行匹配映射：

- 设基因树节点为 $g$，物种树节点为 $s$。定义映射函数 $\mathcal{M}(g) = s$。
- 若基因树节点 $g$ 的两个子节点 $g_1, g_2$ 映射到物种树的不同分支，且满足 $\mathcal{M}(g_1) \cap \mathcal{M}(g_2) = \emptyset$，则判定 $g$ 为**物种分化事件**（Speciation）。
- 若 $\mathcal{M}(g_1)$ 与 $\mathcal{M}(g_2)$ 存在重叠或包含关系，则判定 $g$ 为**基因复制事件**（Duplication）。

通过该调和映射，基因树获得客观定根，并能精确厘清每个基因节点究竟源于何种演化事件，最终输出符合严谨生物学定义的成对直系同源与旁系同源列表。

## 植物科研典型场景与单拷贝基因筛选

### 1. 超矩阵物种树建树（Supermatrix Phylogenomics）
利用 OrthoFinder 输出的 `Orthogroups_SpeciesOverlaps.tsv` 与 `Orthogroups.GeneCount.tsv`，可快速筛选在全部输入植物物种中均严格仅有一份拷贝的**单拷贝直系同源群**（Single-Copy Orthogroups, SCOG）。
- 对每个单拷贝基因进行密码子感知多序列比对（如 PRANK / MAFFT）；
- 级联拼接（Concatenation）为长达数万碱基的超矩阵，供 [IQ-TREE 2](../../../methods/iqtree2/) 进行物种系统发育树构建。

### 2. 区分全基因组复制与局部串联复制
通过直系同源群内的基因拷贝分布，可以追踪特定植物谱系的爆发扩增：
- **串联重复**：同属于一个 Orthogroup 的拷贝在染色体物理坐标上连续排列（物理间隔 $\le 5$ 个基因），通常富集抗病受体（NBS-LRR）或次生代谢合成酶（CYP450）；
- **全基因组加倍拷贝**：散布在不同的同源共线性染色体块（Syntenic blocks）上，需进一步配合共线性分析工具 [MCScanX](../../../methods/mcscanx/) 联合验证。

## 实践规范与质控要点

| 分析环节 | 核心标准与参数建议 | 常见陷阱与科学纠正 |
| :--- | :--- | :--- |
| **输入代表蛋白提取** | 每个基因位点仅保留最长剪接异构体（Primary transcript） | 误将全剪接本全部输入，导致同一基因被算法误认为近期串联复制 |
| **短肽与低质量模型过滤** | 过滤长度 $< 50$ aa 或含内部终止密码子的伪基因 | 截短肽会形成高分局部比对，导致不相关的 Orthogroup 发生异常合并 |
| **Diamond 灵敏度** | 跨科植物比较推荐 `--ultra-sensitive` 模式 | 默认 fast 模式漏检深部分化（如被子植物与苔藓植物）的遥远同源 |
| **MCL 膨胀系数** | 植物基因组通常保持默认 `-I 1.5` | 过度增大膨胀系数会导致超大基因家族（如激酶）被切得过碎，破坏系统发育完整性 |
