## 核心科学问题：从基因组序列重构古气候与驯化历史

植物种群在漫长的地质演化与人类农业驯化进程中，经历了剧烈的气候震荡（如更新世冰期旋回、末次盛冰期 LGM 气候骤冷）、生境破碎隔离与人类定向驯化瓶颈。这些历史事件深刻重塑了物种的**有效群体大小**（Effective Population Size, $N_e$）与基因流（Gene Flow）动态。

传统的群体统计量（如单一的 $\pi$ 或 $F_{ST}$）仅能提供时间跨度压缩的平均化概貌。近年来基于**顺序马尔可夫溯祖理论**（Sequentially Markovian Coalescent, SMC）的方法，能够利用单样本或少量重测序个体全基因组上杂合位点的空间分布模式，精确反演该物种自数百万年前至数千年前的连续有效种群规模演变曲线，成为连接分子演化、地质古气候学与农业考古学的核心纽带。

## 算法数学推导：溯祖理论与序列隐式马尔可夫模型

### 1. 溯祖理论与最近共同祖先时间（TMRCA）

在经典溯祖理论中，从二倍体常染色体中随机抽取的两个单倍体等位基因，向历史深处逆向追溯至其最近共同祖先（Time to Most Recent Common Ancestor, TMRCA）的等待时间 $t$ 是一个随机变量。在可变种群规模 $N_e(t)$ 下，等待时间的生存函数满足非齐次泊松过程：

$$P(T > t) = \exp\left( -\int_0^t \frac{1}{2N_e(u)} du \right)$$

- 当群体规模 $N_e$ 庞大时，谱系碰撞合并的概率极低，TMRCA 显著推迟；
- 当群体经历剧烈收缩瓶颈时，谱系迅速发生合并，形成密集的共祖节点。

### 2. 顺序马尔可夫共祖模型（SMC 架构，McVean & Cardin, 2005）

染色体在物理空间上由于同源重组事件的存在，不同位点拥有不同的局部谱系拓扑和 TMRCA。沿染色体移动时，邻近位点的 TMRCA 呈现高度自相关，直至发生减数分裂重组，局部树拓扑切换至新的 TMRCA。

将全基因组划分为离散的物理网格，并设置 $K$ 个离散的历史时间区间：
- **隐藏状态（Hidden State）**：当前物理位点所属的离散共祖时间等级 $S_i \in \{t_1, t_2, \dots, t_K\}$；
- **发射概率（Emission Probability）**：在给定的共祖时间 $t_k$ 条件下，观测到该位点为杂合（发生突变）或纯合的概率：
  $$P(\text{Heterozygous} \mid t_k) \approx 1 - e^{-2\mu t_k} \approx 2\mu t_k$$
- **转移概率（Transition Probability）**：相邻网格间由重组率 $r$ 控制的共祖时间状态转移矩阵 $P(S_{i+1} = t_l \mid S_i = t_k)$。

### 3. SMC++ 算法对传统 PSMC 的核心飞跃

[SMC++](../../../methods/smcpp/)（Terhorst et al., 2017）克服了传统 PSMC（Li & Durbin, 2011）仅能利用单个体且在近期（$< 2$ 万年）完全失去分辨率的致命缺陷：
1. **结合条件位点频率谱（CSFS）**：引入一个“区分个体”（Distinguished individual）提供物理连续的单倍型杂合态信息，同时结合同一群体中数十个甚至上百个未定相个体的群体位点频率谱（SFS）；
2. **样条函数惩罚正则化（Spline Regularization）**：在极大似然优化中引入二阶导数光滑度惩罚项，防止过度拟合局部随机重组噪声；
3. **两群体清洁分裂模型（`smc++ split`）**：通过比较群体内成对共祖率与跨群体成对共祖率，在假定分裂后无持续强基因流的条件下，高精度解析两植物类群（如野生稻与栽培稻、籼稻与粳稻）的完全物理隔离时代。

### 4. 物理时间与人口尺度绝对标定公式

SMC++ 输出的原始结果是以突变尺度和溯祖单位计量的无量纲数值。转化为绝对物理年代必须代入两个生物学物理常数：
- **单碱基每世代突变率（$\mu$）**：植物核基因组常取 $\mu \approx 6.5 \times 10^{-9}$ substitutions/site/generation；
- **世代时间（$g$）**：植物一年繁殖的世代数（如一年生作物 $g=1$ 年/代，木本林木 $g=15 \sim 30$ 年/代）。

参数换算公式：

$$T_{\text{years}} = g \times \frac{t_{\text{coal}}}{2\mu}, \quad N_e(t) = \frac{\theta(t)}{4\mu}$$

## 植物自交系统与“伪二倍体”（Pseudo-Diploid）核心策略

在拟南芥、大豆、栽培水稻等严格自花授粉植物中，长期的近交使得基因组天然处于高度纯合状态（杂合率 $< 0.1\%$）。单个个体的同源染色体几乎完全相同，直接输入 PSMC 会导致算法因缺乏杂合发射信号而产生严重错误。

- **对策：构建“伪二倍体”（Pseudo-Diploid）**
  - 从同一自然亚群中随机选取两个不同的纯合品系（单倍体基因型 $H_1$ 与 $H_2$）；
  - 编写脚本人工合并为一个虚拟的二倍体基因组：凡两品系基因型不同处标记为杂合，完全一致处标记为纯合；
  - 该伪二倍体所反映的 TMRCA，严格对应于该亚群内部两个独立谱系合并的时间分布，完美规避了自交引起的杂合度枯竭。

## 生产环境实操命令行指南

```bash
# 步骤 1：利用 vcf2smc 将全基因组 VCF 转换为 SMC++ 专用格式 (结合可调用掩码 mask.bed)
smc++ vcf2smc \
  --mask callable_mask.bed.gz \
  cohort.vcf.gz \
  chr01.smc.gz \
  chr01 \
  pop1:sample1,sample2,sample3,sample4

# 步骤 2：多染色体联合估计有效种群大小历史轨迹 (设定突变率 6.5e-9)
smc++ estimate \
  --base my_pop \
  -o smcpp_results/ \
  --spline cubic \
  --threads 16 \
  6.5e-9 \
  chr*.smc.gz

# 步骤 3：绘制历史人口演化轨迹图 (设定世代时间 g = 1 年)
smc++ plot \
  --csv smcpp_results/my_pop.csv \
  -g 1 \
  -u 6.5e-9 \
  smcpp_results/plot.pdf \
  smcpp_results/model.final.json
```

## 植物应用案例与真实文献证据

1. **非洲栽培稻（*Oryza glaberrima*）驯化历史推断**：
   在 246 份非洲栽培稻及其野生祖先（*O. barthii*）研究中，作者采用“伪二倍体”设计，结合 SMC++、PSMC 与 MSMC2 交叉比对历史有效群体大小。SMC++ 清晰揭示出野生稻与栽培稻在约 15,000 年前共同经历了剧烈的环境诱导收缩，但在约 3,400 年前，非洲栽培稻经历了一个极其尖锐的驯化瓶颈（最低跌至 $N_e \approx 1,000$），随后在约 1,800 年前人口迅速回升，与非洲西部的农业考古定年完美吻合（[Cubry et al., *Current Biology*, 2018](https://doi.org/10.1016/j.cub.2018.03.011)）。
2. **美洲黑杨（*Populus trichocarpa*）重复序列遮罩对人口史的显著影响**：
   在林木基因组研究中，作者对比了重复序列屏蔽对 PSMC 与 SMC++ 曲线的影响，证实未遮罩的转座子区会因错配引入虚假的深古老杂合信号，而严格遮罩后揭示出黑杨在末次盛冰期（LGM，约 2 万年前）经历的严重瓶颈收缩（[Patil & Vijay, *BMC Genomics*, 2021](https://doi.org/10.1186/s12864-021-07923-0)）。

## 实践规范与质控要点

| 分析环节 | 核心标准与参数建议 | 常见陷阱与科学纠正 |
| :--- | :--- | :--- |
| **可调用区域掩码（Masking）**| 必须加载严密过滤的 `callable_mask.bed`（屏蔽重复与超高读深区） | 忽略掩码，算法将测序缺口当成极长纯合块，导致远古 $N_e$ 被人为严重高估 |
| **突变率与世代敏感性** | 必须在报告中声明突变率 $\mu$ 假定，并提供 $\pm 20\%$ 的敏感性区间 | 误将人类突变率（$1.2 \times 10^{-8}$）套用至植物，导致全树年代整体缩水一半 |
| **自交近交校正** | 严格自交物种优先采用伪二倍体策略或校正自交系数 $F$ | 对纯合自交植物强行运行单样本 PSMC，输出无意义的一平直线 |
| **深部分化假象排查** | 曲线在 $> 10^6$ 年前的极端上扬常因深度群体亚结构引起 | 盲目将远古 $N_e$ 暴涨解释为超级人口膨胀，忽视谱系不完全混合的模拟验证 |
