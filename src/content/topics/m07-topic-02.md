## 核心科学问题：从单碱基转化化学到全基因组甲基化分型

在常规高通量测序（Illumina/MGI）中，DNA 聚合酶在体外 PCR 扩增过程中无法识别胞嘧啶 5 位碳上的甲基修饰（5mC），会将所有的甲基化胞嘧啶与未甲基化胞嘧啶一律均等复制为常规的胞嘧啶（C），从而导致表观修饰信号在测序中彻底丢失。

**全基因组重亚硫酸氢盐测序**（Whole-Genome Bisulfite Sequencing, WGBS）利用化学特异性转化，将不可测的表观修饰差异转化为可被测序仪直接读取的初级核酸 $C \to T$ 序列多态性，并依赖计算生物学算法在单碱基分辨率下精确重构全基因组 mCG、mCHG 与 mCHH 甲基化图谱。

## 算法数学推导：化学转化、四链比对与误差校正

### 1. 重亚硫酸氢盐（Sodium Bisulfite）脱氨基化学原理

在酸性条件下，重亚硫酸氢钠对单链 DNA 中的胞嘧啶发生三步级联化学反应：
1. **磺化反应（Sulfonation）**：重亚硫酸氢根离子进攻未甲基化胞嘧啶的第 6 位碳原子，形成胞嘧啶-6-磺酸盐加合物；
2. **水解脱氨基（Hydrolytic Deamination）**：在第 4 位碳原子发生水解脱氨，生成尿嘧啶-6-磺酸盐中间体；
3. **碱性脱磺化（Alkaline Desulfonation）**：在碱性条件下（高 pH）脱去磺酸基团，最终生成**尿嘧啶（Uracil, U）**。在后续 PCR 反应中，DNA 聚合酶将尿嘧啶识别为胸腺嘧啶，互补链掺入腺嘌呤（A），最终测序读取为 **T**；
4. **甲基化保护性抵抗**：当胞嘧啶第 5 位碳原子存在甲基化基团（5-methylcytosine, 5mC 或 5hmC）时，甲基的空间位阻与富电子云强烈阻碍了磺化进攻，5mC 几乎百分之百抵抗重亚硫酸氢盐水解脱氨，在后续 PCR 中依然被保真复制为 **C**。

### 2. 传统比对器的失效与 Bismark 四链转换算法

经重亚硫酸氢盐转化后，未甲基化的 C 大量转变为 T，导致测序 Reads 与参考基因组之间产生海量的 $C \to T$ 错配（非甲基化链中的 C 含量剧降，形成近乎三字母“A, G, T”的退化序列），传统比对工具（如 Bowtie2、BWA）会将其判定为过度变异而拒绝比对。

Bismark（Krueger & Andrews, 2011, Bioinformatics）发明了**双向三字母重构与四链比对算法**：

对于一条双链基因组 DNA，PCR 扩增后理论上会衍生出四条性质迥异的测序链：
1. **原始顶链（Original Top, OT）**：$5' \to 3'$ 链，所有非甲基化 C 转换为 T；
2. **互补顶链（Complementary to OT, CTOT）**：以 OT 为模板 PCR 扩增的产物，原先转化生成的 T 在此链被扩增为 A（表现为 $G \to A$ 转换）；
3. **原始底链（Original Bottom, OB）**：$3' \to 5'$ 链，该链上的非甲基化 C 同样转换为 T；
4. **互补底链（Complementary to OB, CTOB）**：以 OB 为模板的扩增产物，表现为 $G \to A$ 转换。

**Bismark 建库与比对步骤**：
- **参考基因组三字母转换**：Bismark 将参考基因组同时制备两份变换版本：一份将所有 C 转换为 T（$C \to T$ 基因组），另一份将所有 G 转换为 A（$G \to A$ 基因组）；
- **测序 Reads 三字母转换**：将测序 Reads 同样执行完全三字母化，分别与上述两份参考基因组执行快速严格比对；
- **回溯原始碱基**：确定唯一比对位置后，将 Reads 与未经转化的真实参考基因组进行逐位比对：
  - 若参考位点为 C，Reads 实际呼叫为 **C**，判定为**甲基化胞嘧啶（Methylated Cytosine, 5mC）**；
  - 若参考位点为 C，Reads 实际呼叫为 **T**，判定为**未甲基化胞嘧啶（Unmethylated Cytosine）**。

### 3. 植物叶绿体基因组作为天然无偏非转化率对照

由于化学反应不完全，极少数未甲基化的 C 可能未被脱氨基，直接作为 C 被读取，形成假阳性甲基化误差。其比例称为**非转化率（Non-conversion Rate, $\eta$）**。

在植物 WGBS 实验中，存在一个无与伦比的天然生物学对照：**叶绿体基因组（Chloroplast Genome）**。
- 植物叶绿体起源于蓝细菌内共生，细胞核内编码的 DNA 甲基转移酶（MET1、CMT3、DRM2）均携带核定位信号，**绝不进入叶绿体基质**；
- 叶绿体基因组 DNA 的真实生理甲基化水平严格恒等于 0；
- 因此，在比对至叶绿体基因组的所有胞嘧啶位点中，测出的 C 信号百分之百来自化学转化不完全误差。

精确计算非转化率 $\eta$：

$$\eta = \frac{\sum C_{\text{chloroplast}}}{\sum C_{\text{chloroplast}} + \sum T_{\text{chloroplast}}}$$

**工业级质控红线**：高标准植物 WGBS 测序文库的叶绿体非转化率必须满足 $\eta < 0.5\%$（即化学转化率高于 $99.5\%$）。

### 4. 单碱基甲基化水平计算与二项分布检验

对于核基因组上第 $i$ 个胞嘧啶位点，设支持甲基化的 Reads 覆盖数为 $C_i$，支持未甲基化的 Reads 覆盖数为 $T_i$，有效总测序深度 $N_i = C_i + T_i$。

- **观测甲基化水平（Observed Methylation Level, $ML_{\text{obs}}$）**：
  $$ML_{\text{obs}} = \frac{C_i}{C_i + T_i}$$
- **背景校正后真实甲基化水平估计**：
  利用非转化率 $\eta$ 消除假阳性基线：
  $$\hat{\theta}_i = \max\left(0, \frac{ML_{\text{obs}} - \eta}{1 - \eta}\right)$$
- **单碱基显著性二项检验（Binomial Test）**：
  检验零假设 $H_0: \theta_i = 0$（即该位点观测到的 C 计数纯粹由转化误差 $\eta$ 导致）：
  $$p_i = P(X \ge C_i \mid X \sim \text{Binomial}(N_i, \eta)) = \sum_{k=C_i}^{N_i} \binom{N_i}{k} \eta^k (1 - \eta)^{N_i - k}$$
  对全基因组数千万个位点的 $p$ 值执行 Benjamini-Hochberg FDR 校正，判定显著甲基化胞嘧啶位点（mC）。

## 植物三大修饰环境在 Bismark 中的分类提取

Bismark 的 `bismark_methylation_extractor` 脚本根据参考基因组紧邻位点的上下游碱基环境，自动将所有测得的 mC 输出至三个独立的统计通道：

```
植物三大序列环境提取规则：

序列通道      5' -> 3' 核心模序              植物全基因组平均水平 (拟南芥)  生物学功能定位
─────────────────────────────────────────────────────────────────────────────────────────────
CpG context   5'-CG-3' (后一位紧邻 G)        ~ 24.0%                        基因体与转座子均富集
CHG context   5'-CHG-3' (第二位为 G, H≠G)    ~ 6.7%                         转座子与抑制性异染色质
CHH context   5'-CHH-3' (后两位均不含 G)     ~ 1.7%                         短转座子边缘与小RNA导向区
```

## 第三代测序（Nanopore）直接修饰检测前沿

近年来 Oxford Nanopore（ONT）单分子长读长测序技术开辟了免化学转化的全新检测范式：
- 天然修饰碱基（5mC 与 6mA）穿过生物纳米孔时，产生的特征离子阻断电流（Picoampere Current）与未修饰胞嘧啶存在细微特征偏差；
- 利用深度残差神经网络（如 Remora 或 DeepSignal-plant）直接对原始电信号（Fast5/POD5）进行解码；
- **核心颠覆性优势**：无需重亚硫酸氢盐化学破坏，保持原始长片段（N50 > 30 kb），可跨越着丝粒超级转座子重复区，直接实现长单倍型相位的表观修饰分型。
