## 研究问题
二倍体样本具有两套同源染色体；同源位点的等位差异提供区分单倍型的线索。相位解析的目标是把同一条染色体上的变异组合起来。

## 从变异到路径
识别杂合位点，使用跨位点 reads 或亲本信息连接等位基因，再选择支持一致的图路径。缺少连接信息的位置可能发生相位切换。

## 植物特色挑战
自交与异交植物的杂合程度不同；多倍体包含多套同源或部分同源染色体，区分不同拷贝需要考虑倍性与遗传背景。Hi-C、亲本测序等数据可提供额外相位信息。

## 示意路径
示意数据：共同片段 A 之后，路径一为 B1–C1，路径二为 B2–C2。跨越 B 和 C 的 reads 可以帮助识别一致组合。

## 生物学背景：同源染色体与相位
基因型描述位点上的等位基因，相位描述多个等位基因在染色体上的组合。例如两个杂合位点均为 A/G 与 C/T，仅凭单个位点的基因型无法确定同一条染色体携带 A–C 还是 A–T。能跨越两个位点的 reads 可以建立局部连接；较远位点需要更长分子、亲本或染色体构象信息。

## 计算流程与相位错误
先从高准确度 reads 发现杂合差异，再在组装图中保留候选分支。图中的分支可能表示等位序列，也可能由重复或错误造成；软件结合 reads 重叠、覆盖和额外数据进行判别。将可连接的分支串成路径，得到相位块。两条路径在相邻区段发生错误交换时称为 switch error；缺少信息的区域会造成相位块中断。

## 技术路线比较
仅使用 HiFi reads 可以依据长重叠和杂合位点解析局部相位；亲本特异 k-mer 可对后代序列提供亲本来源标签；Hi-C 可提供远距离关联。Hifiasm 支持不同数据模式；Verkko 支持利用亲本 k-mer 或 Hi-C 的扩展相位流程。每种方法的可解析范围取决于数据覆盖和样本结构。

## 植物应用与评估
异交物种可能具有较高杂合度，自交材料的等位差异可能较少。多倍体拥有多套同源或部分同源染色体，二倍体工具输出的两条路径不应直接解释为完整多倍体相位结果。四倍体马铃薯研究展示了多倍体单倍型解析的生物学价值：[Sun 等，2022](https://doi.org/10.1038/s41588-022-01015-0)。使用亲本标记、相位块连续性和 switch error 等指标评估，并将不同方法的评估范围明确记录。

## 一个可手算的相位例子
考虑两个杂合位点，基因型分别为 $A/G$ 和 $C/T$。两个位点之间若没有任何跨越分子，局部基因型只说明每个位点有两个等位状态，无法判定同一条染色体究竟是 $A-C/G-T$ 还是 $A-T/G-C$。如果长 read 片段支持 $A-C$、另一片段支持 $G-T$，则两位点可以形成相位连接；读段方向相反时，先按照比对方向归一化再判断等位组合。

设相邻杂合位点 $i,j$ 的 read 支持计数为 $n_{AC}, n_{AT}, n_{GC}, n_{GT}$。在简化的无错误二倍体模型中，$n_{AC}$ 与 $n_{GT}$ 较多支持一种相位，$n_{AT}$ 与 $n_{GC}$ 较多支持另一种。真实数据需考虑测序错误、比对偏差、重复和 allele dropout；软件不会只按多数读段决定，而会结合重叠图、可信重叠、覆盖与分子相位信息。此手算模型仅用于理解相位信号。

## 从杂合位点到单倍型路径
1. 先做 read 质量检查与样本倍性确认；近交、异交或多倍体样本产生的变异模式不同。
2. 依据高准确长读段和重叠比对识别可靠杂合差异，排除明显测序错误与重复比对。
3. 在组装图中保留两个或多个等位候选分支，并把携带多个变异的 read 作为路径连接证据。
4. 将局部 phase block 沿长 reads、亲本特异 k-mer 或 Hi-C 信息连接。亲本数据常提供来源标签，Hi-C 提供染色质尺度关联；两者信号及可解析尺度不同。
5. 输出候选 haplotype contig/scaffold，并使用 Merqury spectra-cn、亲本标记、长 read 回贴及 Hi-C 联系图评估缺失、切换和结构错误。

## 图气泡与生物学解释
组装图中的 bubble 可以表示两个同源染色体在变异区域的不同路径，两支共享上游与下游序列。气泡也可能由错误、结构变异、旁系同源拷贝或重复造成；只有与支持 reads 的分相模式一致时才能解释为等位分支。若两个位点间距大于任何可用分子跨度，本地证据无法唯一确定它们是否位于同一条单倍型上，结果会拆为不同相位块或依赖长程数据推断。

## 相位质量与多倍体限制
相位块 N50 衡量相位连续区段长度；switch error 统计相邻杂合位点间等位路径切换错误，评估需要可信的真值或父母标记。较长相位块不自动意味着碱基准确或结构无误。二倍体通常有两条同源路径；四倍体至少需要区分四套染色体拷贝。自交多倍体中的同源拷贝可能高度相似，异源多倍体的亚基因组来源与剂量差异也影响算法假设。不能把二倍体工具输出的两条路径称作完整四倍体解析。

## 软件实现比较与植物案例
Hifiasm 使用 HiFi reads 构建相位感知的组装图，可通过 trio 模式使用亲本特异 k-mer；其图清理和路径输出由软件自身启发式完成。Verkko 利用 HiFi 图上的连接与超长 ONT reads 跨越难解重复，并支持 Hi-C 或 trio 等后续分相模式；其架构强调多阶段图解析。工具输出名和参数需按安装版本文档核验。四倍体马铃薯工作展示多个单倍型组装与等位变异分析的应用背景；该论文针对其样本和数据策略报告的结果不能直接作为其他多倍体的精度保证。[Sun 等 2022](https://doi.org/10.1038/s41588-022-01015-0)。
