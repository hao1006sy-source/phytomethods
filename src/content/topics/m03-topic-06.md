## 问题与数据结构
在线性参考中，一个 reads 比对位置可用参考名称、起点和相对参考的操作描述。图参考含有共享节点、替代节点和连接，reads 可能支持图中的多条候选路径；比对器需要在图结构中定位序列，同时处理方向、分叉、重复与多重匹配。

图索引对图中序列、路径或子串建立可搜索表示，用于快速寻找候选位置。不同工具的索引针对不同操作设计，并不意味着所有图格式都能直接互换。GFA 可描述序列、连接和路径；GBZ 是 vg 生态使用的一种图和单倍型路径相关表示。运行前必须核对软件版本及具体索引要求。

## 从序列到图路径
一个概念流程是：构建图及其索引；从 reads 提取候选种子，查找图中匹配位置；在邻近图结构中延伸和评分，选择一个或多个候选比对；评估映射质量；按样本汇总支持图分支或变异位点的 reads；最后基于明确的模型推断基因型并输出可解释坐标。种子落在重复序列上时可能匹配多个位置，长 reads 或配对信息可提供额外约束。

示例：图有共同片段 A、D，中间有替代片段 B 和 C；一条覆盖 A–B–D 特有序列的 read 为 B 路径提供支持。若 read 只覆盖共同片段 A，则它不能区分 B 与 C。实际软件会考虑测序错误、片段长度、样本倍性和多重匹配；该示例不涉及真实分型概率。

## 软件职责与方法差异
vg 提供图参考构建、索引、映射及变异分析等工具，具体子命令和格式随版本变化。[vg 官方仓库](https://github.com/vgteam/vg)和[方法论文](https://doi.org/10.1038/nbt.4227)列出适用流程。ODGI 侧重泛基因组图的存储、操作、统计和可视化，不应把它的每项功能都描述为 reads 比对器；[ODGI 方法论文](https://doi.org/10.1093/bioinformatics/btac308)说明支持的操作。

线性比对对成熟流程和指定坐标体系有优势；包含合适替代序列的图可能帮助部分非参考 reads 的定位。图是否改善某个样本的准确性需要在输入组装、比较数据、算法及评价标准相同的条件下验证。没有纳入图中的新序列依然可能无法得到良好表示。

## 植物研究与质量控制
植物多倍体、近期复制和重复序列使图中存在多条相似路径。构图应区分样本、单倍型和重复拷贝，避免误把共享重复视为等位分支。检查 reads 映射质量、比对分布、路径覆盖和候选位点的支持深度；对重要候选可回查线性组装及独立测序数据。用图分析育种材料时应报告图的输入材料、版本和坐标参照。

[Minigraph-Cactus 论文](https://doi.org/10.1038/s41587-023-01793-w)描述从组装构图并对接下游映射和分型；[水稻泛基因组研究](https://doi.org/10.1038/s41588-018-0041-z)提供植物样本多样性背景。此处不将该水稻研究标记为 vg 或 ODGI 的应用案例。

## 图比对结果怎样转为分型
图上的比对记录描述 read 所经过的节点、方向以及在各节点中的位置；其坐标和线性染色体坐标并不天然相同。若下游要与基因注释或 VCF 联合分析，需要指定参考路径并投影，记录图版本及投影规则。一个图分支还可能对应多个相互嵌套的变异，因而不能把每个节点一律当作一个独立变异。

分型通常以候选等位路径为单位，汇总能够区分它们的片段支持，并根据测序误差和覆盖深度计算不同基因型的相对可能性。对于二倍体样本，两个候选等位路径可以形成纯合或杂合基因型；多倍体需要考虑更多剂量状态。只命中共享序列的 reads 可以支持该区域存在，却不一定能决定分支归属。报告低覆盖、冲突支持或多重匹配时，应保留不确定状态，而不是强行输出纯合参考。

## 索引选择与计算代价
索引结构应匹配软件及分析任务：例如，vg 官方文档将 Giraffe 的 GBZ 图与单倍型索引、距离索引和 minimizer 索引组合使用；短读长与长读长的索引参数并非完全相同。`vg autoindex` 可按指定工作流程组织相关索引，运行前仍应检查输入路径信息、磁盘空间、内存和对应版本文档。图中路径数量和复杂重复越多，索引及后续计算的成本可能增加；针对具体样本缩减路径时，要说明删去哪些可能的变异表示，避免把计算方便误写成生物学结论。[vg 索引文档](https://github.com/vgteam/vg/wiki/Index-Construction)。

## 如何比较线性与图参考
使用相同样本、测序数据和可信评估区域，分别统计可比位置的定位、变异召回和错误结果；要说明各方法采用的参考与坐标投影。对于图参考，纳入测试样本自身的已知答案可能使评估偏乐观，应报告图包含哪些材料，并使用独立样本或适当留出方案。总比对率只是一个概要数字；重复序列的多重匹配、假阳性和难以投影的读段需要单独分析。结果解释应回到区域证据与研究问题，而不是把任一参考结构视为普遍优胜。
