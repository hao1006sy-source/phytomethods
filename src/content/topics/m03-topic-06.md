## 问题与数据结构
在线性参考中，一个 reads 比对位置可用参考名称、起点和相对参考的操作描述。图参考含有共享节点、替代节点和连接，reads 可能支持图中的多条候选路径；比对器需要在图结构中定位序列，同时处理方向、分叉、重复与多重匹配。

图索引对图中序列、路径或子串建立可搜索表示，用于快速寻找候选位置。不同工具的索引针对不同操作设计，并不意味着所有图格式都能直接互换。GFA 可描述序列、连接和路径；GBZ 是 vg 生态使用的一种图和单倍型路径相关表示。运行前必须核对软件版本及具体索引要求。

## 从序列到图路径
一个概念流程是：构建图及其索引；从 reads 提取候选种子，查找图中匹配位置；在邻近图结构中延伸和评分，选择一个或多个候选比对；评估映射质量；按样本汇总支持图分支或变异位点的 reads；最后基于明确的模型推断基因型并输出可解释坐标。种子落在重复序列上时可能匹配多个位置，长 reads 或配对信息可提供额外约束。

示例：图有共同片段 A、D，中间有替代片段 B 和 C；一条覆盖 A–B–D 特有序列的 read 为 B 路径提供支持。若 read 只覆盖共同片段 A，则它不能区分 B 与 C。实际软件会考虑测序错误、片段长度、样本倍性和多重匹配；该示例不涉及真实分型概率。

## 软件职责与方法差异
vg 提供图参考构建、索引、映射及变异分析等工具，具体子命令和格式随版本变化。[vg 官方仓库](https://github.com/vgteam/vg)和[方法论文](https://doi.org/10.1038/nbt.4227)列出适用流程。ODGI 侧重泛基因组图的存储、操作、统计和可视化，不应把它的每项功能都描述为 reads 比对器；[ODGI 方法论文](https://doi.org/10.1093/bioinformatics/btac308)说明支持的操作。

### Giraffe 的单倍型感知映射

Giraffe 是 vg 中用于图上 reads 比对的组件；其方法论文重点介绍短读段映射，当前索引文档区分短读段和长读段模式。它用图 Burrows–Wheeler 变换（Graph Burrows–Wheeler Transform，GBWT）索引已知单倍型路径；先以最小化器（minimizer）索引寻找候选种子，再按图距离聚类种子，沿单倍型路径延伸为无缺口局部比对，剩余缺口由带 gap 的比对处理。把搜索限制在已知或构造的单倍型路径，可缩小图中组合路径的搜索空间。[Giraffe 原始论文](https://doi.org/10.1126/science.abg8871)给出该流程；[vg 索引文档](https://github.com/vgteam/vg/wiki/Index-Construction)说明工作流需要 GBZ 图（含 GBWT 单倍型索引与 GBWTGraph）、距离索引（distance index）和 minimizer 索引，短读段和长读段索引参数不同。

上述步骤描述读段映射，输出的是对图路径的比对证据。基因型判定还要整合覆盖、变异表示和适配倍性的 caller 或下游统计模型。Giraffe 方法论文中的 5,202 份个体及 167,000 个结构变异为人类短读段评估，不作为植物应用案例；植物研究中的 vg 映射也应与后续 SV 分型步骤分开记录。

线性比对对成熟流程和指定坐标体系有优势；包含合适替代序列的图可能帮助部分非参考 reads 的定位。图是否改善某个样本的准确性需要在输入组装、比较数据、算法及评价标准相同的条件下验证。没有纳入图中的新序列依然可能无法得到良好表示。

## 植物研究与质量控制
植物多倍体、近期复制和重复序列使图中存在多条相似路径。构图应区分样本、单倍型和重复拷贝，避免误把共享重复视为等位分支。检查 reads 映射质量、比对分布、路径覆盖和候选位点的支持深度；对重要候选可回查线性组装及独立测序数据。用图分析育种材料时应报告图的输入材料、版本和坐标参照。

[Minigraph-Cactus 论文](https://doi.org/10.1038/s41587-023-01793-w)描述从组装构图并对接下游映射和分型；[水稻泛基因组研究](https://doi.org/10.1038/s41588-018-0041-z)提供植物样本多样性背景。此处不将该水稻研究标记为 vg 或 ODGI 的应用案例。

Kang 等对 32 份拟南芥材料使用独立 Minigraph 构建图，并以 vg toolkit v1.40.0 将 1,135 个体重测序 reads 映射到该图，结合过滤开展 SV 基因型分析；作者报告过滤后 1,073 个体、20,326 个 SV 位点。[原文方法](https://doi.org/10.1038/s41467-023-42029-4)。这一案例连接图构建与 read mapping 两个不同步骤；数据和结论以论文设定为限。

## 图比对结果怎样转为分型
图上的比对记录描述 read 所经过的节点、方向以及在各节点中的位置；其坐标和线性染色体坐标并不天然相同。若下游要与基因注释或 VCF 联合分析，需要指定参考路径并投影，记录图版本及投影规则。一个图分支还可能对应多个相互嵌套的变异，因而不能把每个节点一律当作一个独立变异。

分型通常以候选等位路径为单位，汇总能够区分它们的片段支持，并根据测序误差和覆盖深度计算不同基因型的相对可能性。对于二倍体样本，两个候选等位路径可以形成纯合或杂合基因型；多倍体需要考虑更多剂量状态。只命中共享序列的 reads 可以支持该区域存在，却不一定能决定分支归属。报告低覆盖、冲突支持或多重匹配时，应保留不确定状态，而不是强行输出纯合参考。

## 索引选择与计算代价
索引结构应匹配软件及分析任务：例如，vg 官方文档将 Giraffe 的 GBZ 图与单倍型索引、距离索引和 minimizer 索引组合使用；短读长与长读长的索引参数并非完全相同。`vg autoindex` 可按指定工作流程组织相关索引，运行前仍应检查输入路径信息、磁盘空间、内存和对应版本文档。图中路径数量和复杂重复越多，索引及后续计算的成本可能增加；针对具体样本缩减路径时，要说明删去哪些可能的变异表示，避免把计算方便误写成生物学结论。[vg 索引文档](https://github.com/vgteam/vg/wiki/Index-Construction)。

## 如何比较线性与图参考
使用相同样本、测序数据和可信评估区域，分别统计可比位置的定位、变异召回和错误结果；要说明各方法采用的参考与坐标投影。对于图参考，纳入测试样本自身的已知答案可能使评估偏乐观，应报告图包含哪些材料，并使用独立样本或适当留出方案。总比对率只是一个概要数字；重复序列的多重匹配、假阳性和难以投影的读段需要单独分析。结果解释应回到区域证据与研究问题，而不是把任一参考结构视为普遍优胜。

## 从路径支持到基因型
如果某个候选位点有 $H$ 条等位路径，读段 $r_i$ 对路径 $a$ 的匹配证据可用概念似然 $P(r_i\mid a)$ 表示。对一个基因型 $G$（包含 $c$ 条单倍型路径），在简化的独立读段模型中：

$$
\log L(G)=\sum_i \log\left[\frac{1}{c}\sum_{a\in G}P(r_i\mid a)\right].
$$

这只是解释“把每条 read 的序列与候选等位匹配，再汇总基因型支持”的教学模型，不是 Giraffe 或 vg 的确切 caller 实现。现实流程还需要处理比对质量、read 错误、局部拷贝数、覆盖差异、路径先验、多重比对和倍性；只覆盖所有候选路径共有的节点的 reads 对等位区分贡献很小。若某一等位几乎没有能区分路径的读段，合适结果是低置信或缺失基因型，而不是仅依据参考路径补成纯合。

对于二倍体，概念候选有 $AA$、$AB$、$BB$ 等剂量状态；四倍体需要考虑 $AAAA$ 到 $BBBB$ 的多剂量组合。软件是否能对目标倍性给出校准后的 genotype likelihood，应根据其明确支持的输入与模型核查，不能用“支持图比对”代替“支持多倍体分型”。

## 比对输出、分型输出和植物基准
GAM、GAF 等文件承载 read 在图节点或路径上的比对；VCF 等变异表则汇总候选位点和样本基因型。二者之间还要经过变异表示、样本路径投影和基因型判定步骤。读取比对率、MAPQ、read-depth 或单个位点的 call count 时，应说明是图比对统计还是分型结果，以及采用的图、样本路径和参考坐标。

若下游工具需要线性参考 BAM，可用 `vg surject` 将图比对投射到明确指定的参考路径。长读段宜使用 vg 1.73.0 及之后版本提供的 `--read-length long`，或按当前官方说明使用低复杂度剪枝选项；这会在低复杂度区段重新对线性目标序列计算比对。必须指定与图路径命名相匹配的参考路径清单，并检查投射后 BAM 的染色体名称、方向和低复杂度区间。GAM/GAF 到 BAM 的投射会丢失部分图路径信息，因此保留原始图比对和图版本以供追溯。[vg 长读段映射与投射说明](https://github.com/vgteam/vg/wiki/Mapping-long-reads-with-Giraffe)。

高粱图基准中，作者用真实组装和模拟组装构建图，并分别评估模拟 reads 与公开真实 paired-end reads。模拟 reads 由泛基因组图生成，Giraffe 将其映射至 Minigraph 与 Minigraph-Cactus 图，再与 Minimap2 线性参考映射及生成真值比较；真实 paired-end reads 也映射到这两类图和线性参考。PGGB 因图索引所需计算和内存未进入 read-mapping 比较。真实 reads 部分报告总比对率和完美比对比例，不能与模拟真值定位准确率混为一类指标。[基准论文](https://doi.org/10.1093/gigascience/giaf121)。

## 主要方法之间的功能边界
`vg giraffe` 是使用图和单倍型索引进行 read 映射的组件；vg 工具集还包含图转换、索引和下游变异操作。ODGI 读取、转换、统计和可视化已有图，不替代 mapping caller。Minigraph 构造参考引导的图，也可将序列映射到图；Minigraph-Cactus 与 PGGB 是构图流程。工作流要把“构图、索引、映射、基因型推断、可视化”作为独立步骤记录版本和输入输出，避免把功能名称相近的工具视为同一个算法。
