## 核心概念：同线性（Synteny）与共线性（Collinearity）

在植物比较基因组学中，染色体结构的变迁记录了物种分化与适应性演化的全过程。准确解析染色体演化依赖于两个层次的保守性度量：

- **同线性（Synteny）**：严格定义为两个或多个基因在祖先或现生基因组中位于同一条染色体（Linkage group）上，并不要求局部排列顺序严格一致。
- **共线性（Collinearity）**：在同线性的基础上，进一步要求同源基因对沿染色体轴的物理排列顺序（Linear order）与方向保持同向递增或反向连续。

植物经历多轮全基因组加倍（WGD）后，大量的双断裂重组、染色体易位、倒位以及假基因化丢失会严重打碎原始染色体。利用算法在全基因组海量基因对中滤除随机散在的噪音，恢复出连续的**共线性区块**（Collinear blocks），是推断祖先核型（Ancestral Karyotype）与古多倍化历史的核心基础。

## 算法数学推导：MCScanX 动态规划共线链搜索

主流工具 [MCScanX](../../../methods/mcscanx/) 将共线性检测抽象为加权有向无环图（DAG）上的二维最长路径动态规划搜索：

### 1. 锚点定义与搜索空间构建

设两个比较基因组分别为基因组 $A$ 与 $B$。通过全蛋白质比对（BLASTP / Diamond）获得所有显著匹配的同源基因对。每个基因对对应于网格空间中的一个**锚点**（Anchor）：

$$u_i = (x_i, y_i, s_i)$$

其中 $x_i$ 与 $y_i$ 分别为同源基因在染色体上的排序位次（Gene rank / index），$s_i$ 为比对得分（Bit-score 或其对数变换）。

### 2. 动态规划状态转移方程

算法沿染色体坐标递增方向依次遍历所有锚点，寻找使得累计得分最大的单调递增锚点序列链。设前 $i$ 个锚点中以 $u_i$ 结尾的最优共线链累计得分为 $S(i)$：

$$S(i) = s_i + \max_{j < i, \, x_j < x_i, \, y_j < y_i} \left[ S(j) - G(j, i) \right]$$

其中 $G(j, i)$ 为从前序锚点 $u_j$ 跳转到 $u_i$ 所付出的**间隙惩罚代价**（Gap penalty）。若两锚点之间插入了无关基因或发生局部小片段缺失，间隙代价随物理位次距离线性增加：

$$G(j, i) = g \times \left( |x_i - x_j - 1| + |y_i - y_j - 1| \right)$$

- $g$ 为单个非共线基因插入的惩罚常数；
- 算法预设**最大间隙阈值**（Max gap, 默认 25 个基因）：若 $|x_i - x_j| > 25$ 或 $|y_i - y_j| > 25$，则禁止转移，链条断裂。

### 3. 反向共线链与倒位识别

对于倒位（Inversion）区段，染色体 $B$ 上的基因位次呈递减趋势。算法在第二轮计算中设置相反的单调性约束条件：

$$x_j < x_i \quad \text{且} \quad y_j > y_i$$

同样利用动态规划打分搜索，若累计得分超过显著性阈值，则将该链标记为反向共线性块（Inverted block）。

### 4. 统计显著性评估

为了排除随机基因分布形成的伪共线链，MCScanX 计算共线块包含 $m$ 个锚点的理论联合概率。对于由 $m$ 个锚点构成的候选块，在全基因组基因总数背景下，计算其基于几何分布或二项分布的期望出现频次：

$$P(\text{Block}) = 2 \times \binom{N_A}{m} \binom{N_B}{m} \left( \frac{K}{N_A N_B} \right)^m$$

仅保留 $E$-value $< 10^{-5}$ 且锚点数 $m \ge 5$ 的共线块作为真实演化衍生区段。

## MCScanX 五大基因复制机制分类体系

在共线性块构建完成后，MCScanX 进一步将全基因组的所有基因精确归类为五种演化发生学机制：

```
全基因组所有基因分类
├── 1. 全基因组加倍 / 片段复制 (WGD / Segmental): 位于显著共线性块内的同源基因
├── 2. 串联重复 (Tandem): 位于同一染色体且物理排序紧邻 (间隔 ≤ 1 个基因)
├── 3. 近端重复 (Proximal): 位于同一染色体且相距极近 (间隔 2 ~ 10 个基因)
├── 4. 转座重复 (Transposed): 基因对中一个锚定在共线性块中，另一个散落在非同源区
└── 5. 散在重复 (Dispersed): 无任何共线性特征且物理距离极远或位于不同染色体
```

这一分类为植物抗病抗逆基因的串联扩张与全基因组复制亚基因组分化提供了最直接的数理统计证据。

## 宏观共线性点图与植物多倍化核型比例

在跨物种比较中，二维共线性点图（Collinearity Dotplot）能直接揭示物种间的染色体倍性关系：

```
染色体倍性比率在点图中的宏观表现：
• 1:1 共线性直带: 物种分化后各自未经历额外全基因组加倍（如水稻 vs 假稻）
• 1:2 共线性分枝: 目标物种经历了额外的全基因组四倍化加倍（如葡萄 vs 杨树）
• 1:3 对应关系: 核心真双子叶植物古六倍化 (γ-WGT) 在葡萄参考基因组上的 3 套同源染色体对应
• 1:4 深度覆盖: 目标物种经历了连续两轮全基因组加倍（如拟南芥对木瓜）
```

当一条染色体对应物种 B 的两组完全互补的共线性块时，表明发生了**染色体融合与断裂**（End-to-end joining / Nested chromosome insertion），这是植物祖先核型重构（Proto-chromosomes）的关键判据。

## 实践规范与质控要点

| 分析环节 | 核心标准与参数建议 | 常见陷阱与科学纠正 |
| :--- | :--- | :--- |
| **GFF 坐标与排序** | 基因在 GFF 文件中必须严格按染色体与起始坐标从小到大升序排序 | 未排序输入会导致动态规划遍历提前跳出，共线性块被截断为碎块 |
| **基因 ID 匹配** | BLAST 输出中的 Query/Subject ID 必须与 GFF 第一列 ID 完全一致 | 带有 `.t1` 转录本后缀而 GFF 为基因 ID 会导致大量锚点匹配丢失 |
| **最大容许间隙** | 近缘种设 `-m 25`；远缘跨科物种推荐设 `-m 10` ~ `15` | 跨度过大时过度放宽间隙会导致局部散在转座基因被误串入共线链 |
| **最小锚点数** | 默认 `-s 5`；研究微重排可降至 `-s 4`，宏观演化推荐 `-s 8` | 锚点数设得过低（如 $\le 3$）会在高重复基因组中引入大量随机假阳性 |
