## L3 / L4 证据复核

当前 63 篇专题均为 L3、L4 为 0。评级分别接受字段完整性验证和人工内容复核，二者证据不可互相替代。

**自动化字段与关联验证：** `npm run validate` 对 Astro 内容 Schema、必填字段、状态、DOI 唯一性、受控标签和可解析的关联 ID 进行构建检查；关系脚本核对双向稳定 ID；`npm run coverage` 核对专题正文及工具/文献/教程覆盖。这些检查不判断算法解释正确性，也不证明植物案例确实应用了关联工具。

**人工科学内容复核：** `docs/content-quality-audit-v2.1.md` 对每篇专题逐篇记录 B/A/M/C/P/R/O/F/T/K 十个维度的 0–2 分、正文证据、缺项及改进措施。领域证据文件记录关键方法论文、植物案例和工具归属来源。L3 只在专题具备算法/方法比较、可核查方法来源和真实植物案例证据时评定。交互图、教程或页面存在本身不作为 L3 依据。每篇具体审核结论见 63 行专题表；成熟度表对应 `src/data/topic-metadata.json`。

**L4 尚未满足：** 没有专题同时具备真实植物数据上的端到端复现、可检查的完整输入/命令/环境/输出与结果解释，以及对应步骤的完整科研图解。CAFE5、EDTA、Hifiasm 仍为命令核对或模板状态；多个已运行教程采用合成、模拟或上游官方样例。不得据此将其评为真实植物流程 L4。另有 39/58 个工具版本未核实、17/58 个工具缺少直接植物应用论文关联，130 篇文献虽完成 Crossref 元数据核对，仍未全部逐篇全文精读。
