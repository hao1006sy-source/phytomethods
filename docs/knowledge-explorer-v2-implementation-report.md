# PhytoMethods｜科研知识关联图 V2 开发与交付报告

## 一、任务概述

本轮开发将已验收通过的《科研知识关联图 V2 视觉设计预览方案》全面落地为可交互、高性能、接入真实科研数据的生产级系统。

- **系统定位**：科研知识关联图（Scientific Knowledge Explorer V2）
- **路由路径**：`/knowledge/`
- **开发分支**：`feat/knowledge-explorer-v2`
- **核心目标**：从原有的静态两列连线布局全面升级为“种子展开式交互拓扑网络 + 三级科学证据追溯抽屉 + 多维检索过滤控制台”。

## 三、组件架构与技术实现

项目遵循模块化与轻量化设计原则，避免引入厚重的第三方大型图引擎，采用**“确定性几何辐射拓扑 + 原生 SVG + 客户端响应式状态机”**方案：

```text
src/
├── components/knowledge-v2/
│   ├── KnowledgeHeader.astro        # 顶栏全局图谱指标与当前视图动态统计微标
│   ├── KnowledgeFilterPanel.astro   # 左侧控制台（全图多维搜索、领域筛选、实体类型可见性、预设入口）
│   ├── KnowledgeCanvas.astro        # 中间交互视口（SVG画布、背景网格、缩放控制栏、图例、无障碍列表容器）
│   ├── KnowledgeInspector.astro     # 右侧抽屉（未选中概览、实体档案、科学证据列表、站内链接）
│   └── knowledge-v2.css             # 统一白绿学术视觉样式表与响应式媒体查询
├── lib/knowledge/
│   ├── graph-client.ts              # 客户端拓扑计算、事件总线、视口漫游与状态管理
│   ├── graph-types.ts               # 严格 Schema 类型定义
│   └── graph-validator.ts           # 图谱完整性校验器
└── pages/
    └── knowledge/index.astro        # 页面聚合路由与数据内联接入
```

### 核心亮点：
1. **种子展开式探索（按需渐进加载）**：默认以 `Hifiasm` 为中心呈现 1~2 度局部关联子图（14 个节点、21 条边），防止全量 303 个节点造成视觉认知过载与浏览器渲染掉帧。
2. **稳定分层几何拓扑算法**：不同实体类型分配到独立角度扇区（领域在上、专题在左上、教程在左下、物种在正下、奠基与应用论文在右侧），零物理引擎抖动，排布工整规整。
3. **精准路径与边关联高亮**：悬停或选中节点时，直接关联边高亮，非关联背景透明度降至 0.18 并自动禁用指针穿透。
4. **科学证据深度溯源**：点击任意连线或关系标签，右侧面板即刻展示该条连线的起始实体、目标实体、关系类型、DOI 链接、来源类型与详细验证说明。
5. **无障碍双模式切换**：支持点击工具栏在「图形网络」与「结构化语义表格」间一键切换，为屏幕阅读器及小屏设备提供等效的无障碍访问能力。
6. **全站 BASE_URL 兼容**：自动识别并拼接生产环境 `/phytomethods/` 基础路径，所有站内详情页直达按钮 100% 正确跳转。
