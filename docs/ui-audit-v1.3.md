# PhytoMethods v1.3 页面视觉审查

审查对象：本地构建预览，首页、M01 领域、单倍型专题、Hifiasm、文献索引和教程；1440px 与 375px，完整截图见 `outputs/v1.3-ui/before/`。

- 首页的标题、介绍、搜索、领域卡片与资源清单均处于同一视觉层级；搜索控件较小，品牌识别和入口引导不足。
- 顶栏中的品牌、副标题与导航在移动端堆叠为多行，首屏可用空间减少；当前页面缺少清晰的活动状态。
- 九大领域、工具与文献都采用相同卡片语言；文献英文标题较长，手机端形成大量留白和重复边框。
- 文章页虽有三栏，但目录与正文缺少边界和层级；标题、摘要、元数据、正文缺少出版物式排版区分。侧栏顺序与七个专题的实际顺序不一致。
- 公式、表格、代码、图解缺少统一的版面规则；复制按钮与代码块分离，图注和按钮缺乏一致的视觉结构。
- 移动端页面未发现文档级横向溢出；长导航和筛选区较高，图解通过局部横向滚动呈现。

改造重点：保留内容和路径；以深蓝品牌区突出检索，领域入口采用编号和线性图标；工具与文献改为信息列表；统一文章三栏、侧栏、图表、筛选和代码组件。配色使用 #17324D、#197B73、#F5F7FA、#FFFFFF、#243447、#E3E9EF，字体采用系统无衬线及 Noto Sans SC 后备。桌面主容器 1320px，正文上限 780px，间距基于 8px。
