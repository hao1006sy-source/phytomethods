## 分阶段发布步骤

1. 只把审核通过且其所有公开链接目标都可访问的实体标为 `published`；保留尚未审核关系为草稿并由前端隐藏对应链接。
2. 运行 `npm run coverage`、`npm run validate`，检查论文/工具/专题/教程 ID 和状态依赖。
3. 在本地静态预览逐一检查首页→领域→专题→工具→论文→教程的关键路径；覆盖 375、768、1280、1440px。
4. 检查 Pagefind 语言和词条、搜索结果 URL、站点地图及 `/phytomethods/` 子路径资源。
5. 生成本领域 release note，提交变更并推送既有分支。
6. 使用现有仓库流程合并/部署，检查 GitHub Actions 结果与生产页面实际响应，再记录线上链接和截图。
7. 只有完成上述事项后，才将本领域标记“已公开发布”；继续下一领域。
