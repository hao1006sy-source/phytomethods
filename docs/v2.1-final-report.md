## 交付概览

本轮对九大领域 63 篇专题逐篇进行十维证据审查，记录每项评分、正文依据、缺口和后续措施。专题当前成熟度为 **L3 63 篇、L4 0 篇**。内容覆盖包括 58 个方法工具、130 条论文记录和 10 篇教程。论文数较 v2.1 初始任务清单中的 127 条增加 3 条，源自 M01 补入的组装案例。

主要内容返工覆盖 M01–M09。M02 深化结构注释、重复序列识别、基因预测和功能注释方法；M09 深化 WGCNA、GENIE3、MOFA+、AgroNT、PlantCAD2 算法解释；M01 补充组装流程、图算法、单倍型、Hi-C、T2T 和 Merqury 质量评估。M03–M08 分别完成七篇专题的科学评分、定向返工、案例归属复核和浏览器回归。M05 新增 π 与 LD-$r^2$ 的频率代入算例。各篇分数及局限详见 [内容质量审计表](content-quality-audit-v2.1.md) 和领域证据文件。

## 工具、论文与教程审查

- **工具：58 条。** Schema 和 ID 关系校验通过；官方资源 URL、方法论文 ID、领域/专题/算法/输入数据字段完整性已检查。19 条具结构化版本字段，另 39 条版本没有统一核实。41 条关联直接植物应用论文；17 条没有可确认的直接植物使用证据，未以领域相邻论文补关联。
- **论文：130 条。** Crossref REST API 对 DOI、题名、出版年份、作者和期刊字段进行了逐条对照。DOI、题名、至少一个出版日期年份和列出作者均 130/130 匹配。3 条刊名差异属于缩写/格式差异。发现 GRNBoost2 作者条目错误，已按 Oxford Academic 期刊页更正并复核。逐条结果存于 `outputs/v2.1/bibliography-audit/crossref-full.json`。API 元数据核对不等同于 130 篇论文正文精读。
- **教程：10 篇。** 7 篇有运行记录，3 篇保持模板/命令核对状态（CAFE5、EDTA、Hifiasm）。已运行的流程注明输入是模拟数据、合成数据、官方样例或植物材料。WGCNA、PLINK、Scanpy 等模拟/合成数据运行不表述为植物真实样本验证；SyRI 实际使用官方拟南芥测试集。未执行的教程没有伪造成功日志或输出。
