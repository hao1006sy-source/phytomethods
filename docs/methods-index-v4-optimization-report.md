# PhytoMethods 算法与工具目录 V4：方案 B 高密度学术目录优化报告

## 一、项目与设计背景

- **目标页面**：`/methods/`（算法与工具索引）
- **选定设计**：**方案 B——高密度学术工具目录（紧凑列表）**
- **设计初衷**：在保持 PhytoMethods 严谨科研风格的前提下，将原有多列混杂卡片模式彻底重构成面向学术研究者高频检索的专业数据库体验。全面提升海量工具的快速纵向浏览效率、科研用途可读性、多维筛选联动与移动端单列体验。

---

## 二、视觉结构与实现对照

依据《V4 对比预览图》右上角方案 B 的布局规范，新页面结构划分为三个清晰层次：

### 1. 顶部介绍区 (Methods Intro)
- **紧凑布局**：保留 `METHODS & TOOLS`、`算法与工具` 主标题及经典导引说明，去除多余留白；
- **动态方法指标**：通过模板服务端数据动态计算总收录数（当前为 59 个方法与工具），彻底杜绝静态数字硬编码。

### 2. 左侧专业筛选面板 (Filters Sidebar, 宽度 240px)
- **简洁白色面板**：具备清晰边框与标题分组；
- **四维精准筛选**：
  1. **研究领域**（9 大核心领域）；
  2. **研究专题**（与所选研究领域深度联动，动态过滤所属专题，切换领域自动清除失效条件）；
  3. **算法原理**（根据当前收录工具真实涉及的底层计算原理动态列出）；
  4. **输入数据**（涵盖 PacBio HiFi、短读段、变异数据、单细胞多组学等）；
- **重置筛选**：提供一键恢复初始状态按钮。

### 3. 右侧高密度学术检索结果区 (Methods Main)
- **顶部搜索卡片**：支持工具名称、科研用途、计算原理、数据类型中英文实时模糊搜索，提供即时清空按钮；
- **已选条件标签栏 (Active Filters Bar)**：清晰列出当前生效的所有筛选条件与搜索词，支持单个条件独立移除及一键“清除全部”；
- **结果统计与排序条**：实时反馈 `找到 X 条结果（共 Y 条）`，支持方法名称 A–Z 与 Z–A 确定性双向排序；
- **高密度学术列表 (Methods List Table)**：
  - **序号徽章**：排序后自适应动态重新编号（`01`, `02`...）；
  - **方法名称**：采用深绿色加粗（`#0e6548`），作为核心视觉锚点；
  - **综合学术信息**：首行呈现科研用途与核心摘要，次行呈现轻量领域胶囊标签、输入数据提示及计算原理；
  - **操作按钮**：行尾固定呈现直观可点击的“查看详情 →”链接，整行悬停具备淡雅浅绿反馈（`#f3f9f5`）；
  - **空状态**：无匹配结果时显示专业学术空状态提示，并提供快速重置入口。

## 三、移动端响应式与单列高密度设计

针对手机端（视口宽度 $\le$ 640px）：
1. **单列紧凑目录**：自动隐藏序号列与桌面表头，卡片呈现方法名称、科研用途描述、领域与数据标签、计算原理以及底部快捷跳转；
2. **折叠筛选栏**：在搜索框上方提供轻量抽屉式“展开/收起筛选条件”切换按钮，展开时流畅操作，收起时将最大屏幕空间留给工具浏览；
3. **彻底杜绝横向溢出**：在 390×844 与 375×812 真实设备尺寸下，严格保证 `scrollWidth === clientWidth`，无横向滚动条，文字自动优雅折行。
