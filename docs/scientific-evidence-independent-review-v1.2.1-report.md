# PhytoMethods 科研证据独立复核与 MSMC 历史版本纠偏审计报告 V1.2.1

## 一、审计概述

本轮任务（版本代号 **V1.2.1**）在 PR #36（植物应用论文与算法使用关系科学证据核验 V1.2）的基础上，重点完成了两项核心科研质量保障工作：
1. **科研证据的全面独立复核与原文穿透溯源**：对前期新增的 55 条植物应用论文与算法使用关系及 11 条重点策展关系开展了深度原文复核，补齐章节、段落、页码、图表及观察到的软件名称与确切版本号（`sourceLocator`, `observedSoftwareName`, `observedSoftwareVersion`, `supportingTextSummary`），生成了 5 个规范化复核输出文件。
2. **MSMC 与 MSMC2 算法代际与历史版本专项纠偏**：彻底厘清了 2014 年初代 MSMC（联合隐状态马尔可夫共祖模型）与 2016/2020 年 MSMC2（成对共祖率复合似然模型）的方法学差异与软件演进历史；新建独立的 `msmc` 方法实体，纠正了非洲稻群体演化研究（Cubry et al., *Current Biology* 2018）对 `msmc2` 的误绑，并在时序模型、关联解析引擎与知识图谱中完成了完整闭环。

## 二、MSMC 与 MSMC2 历史演进与科学纠偏细节

### 1. 算法与软件历史考证

| 项目 | MSMC (初代) | MSMC2 (第二代) |
| :--- | :--- | :--- |
| **奠基/规范文献** | Schiffels & Durbin, *Nature Genetics* 46:919–925 (2014). DOI: `10.1038/ng.3015` | Schiffels & Wang, *Methods in Molecular Biology* 2090:147–166 (2020). DOI: `10.1007/978-1-0716-0199-0_7` |
| **首发/开源时间** | 2014 年 | 2016 年 5 月 16 日 (GitHub Release v2.0.0) |
| **核心算法原理** | 联合拟合 $k$ 条单倍型首次共祖时间状态转移矩阵 | 基于所有单倍型对的成对共祖率进行复合似然估计 |
| **计算瓶颈与样本** | 复杂度随单倍型数量呈指数爆炸，受限于 4~8 条单倍型 | 去除指数状态爆炸限制，支持数十条单倍型联合比较 |
| **命令行与参数特征** | `msmc -p "..." -R <multihetsep>` | `msmc2 -p "..." -I 0,1,2,3 -o <prefix> <multihetsep>` |
| **官方代码仓库** | `https://github.com/stschiff/msmc` | `https://github.com/stschiff/msmc2` |

### 2. 非洲稻研究 (Cubry et al., 2018) 考证与纠偏

- **原文事实**：Cubry et al. 发表在 *Current Biology* (2018, 28:2156–2167, DOI: `10.1016/j.cub.2018.05.066`)。在论文 **STAR Methods** 的 `Method Details: MSMC and PSMC` 章节（pp. e4-e5）中明确记载：
  > *"We ran MSMC (v1.1.0) with four haplotypes per run... bootstrap replicates were generated by sampling chromosomes with replacement."*
- **纠偏前异常**：因知识库中缺少独立的初代 MSMC 实体，该研究被错误关联至 `msmc2`（对应 2020 年协议文献），导致时序校验器判定论文早于软件协议发表，产生了一条 `needs_review` 警告。
- **纠偏措施**：
  1. 新建 `src/content/methods/msmc.md`（完整符合 V3 排版规范，收录于 M05 研究专题）；
  2. 修改 `src/content/methods/msmc2.md`，将 `paper` 关联明确为 `msmc2-protocol`，阐明其为操作协议并说明与初代 MSMC 的继承关系；
  3. 修改 `src/content/papers/african-rice-246-genomes.md`，将 `methodIds` 由 `[psmc, msmc2, smcpp]` 修正为 `[psmc, msmc, smcpp]`；
  4. 修改 `src/content/papers/msmc-paper.md`，将其关联工具修正为 `[msmc]`；
  5. 在 `src/lib/knowledge/chronology.ts` 中分别为 `msmc` 与 `msmc2` 建立独立的时序演进模型；
  6. 在 `src/lib/knowledge/verified-application-methods.ts` 中正式登记 `african-rice-246-genomes` ➔ `msmc`（使用版本 v1.1.0，证据状态 `source_checked`）；
  7. 移除 `src/lib/knowledge/relation-resolver.ts` 中针对非洲稻设置的特殊补丁逻辑，使图谱解析完全遵循通用证据链。
