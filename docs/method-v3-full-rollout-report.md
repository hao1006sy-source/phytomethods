## 页面实现

其余工具页使用通用的三栏页面结构：标题与分类信息、按原始 Markdown 二级标题生成的侧边导航、论文和案例资源栏。正文由现有 Markdown 原文渲染，支持 KaTeX、表格、代码块及长内容滚动。

资源关系从当前内容集合读取：方法论文取自工具元数据；应用论文通过 `methodIds` 关联；专题从已发布专题的 `methodIds` 读取；教程按工具 ID 关联并沿用来源中已有的验证状态。没有数据来源的图表、命令、方法输出示例不自动生成。

Hifiasm 页面单独使用 `HifiasmPageV3.astro` 与 `config/hifiasm.ts`，保留其 V3 原型的计算原理图、步骤、输入输出、命令和资源栏。Verkko 与 Merqury 继续显示各自原有图表，其他工具不注入 Hifiasm 专属内容。
